今天，我们推出 28 项与知名安全与合规工具的集成。现在，IT 和安全团队可以像管理其技术栈中的其他应用程序一样，在我们的平台和产品套件中对 Claude 进行治理。

## 工作原理

所有这些新集成均由 Claude 合规 API 驱动，该 API 为企业安全与合规团队提供对两类数据的编程式访问：

* **来自 Claude Enterprise 的对话内容**——包括聊天、上传文件和项目——以便管理团队能够对 Claude 应用其已在其他工作场所应用程序中使用的相同安全、监控和 DLP 策略。
* **来自 Claude Enterprise 和 Claude Platform 的活动事件**——用户登录、管理员操作和配置更改——以便安全团队能够统一了解 Claude 在整个组织中的使用情况。
