# Claude on Amazon Bedrock 现已面向所有 AWS 客户开放 | Claude by Anthropic

**日期：** 2023-09-28 00:00 UTC
**链接：** https://claude.com/blog/amazon-bedrock-general-availability

---

Claude 现已在 [Amazon Bedrock](https://aws.amazon.com/bedrock/claude/) 上全面可用。Amazon Bedrock 是一项完全托管服务，为 Amazon Web Services (AWS) 客户提供安全的云端访问基础模型和构建生成式 AI 应用的工具。

这意味着每位 AWS 客户现在都可以使用 Claude 进行构建，并且很快将获得一系列激动人心的新体验，包括 [Agents for Amazon Bedrock](https://aws.amazon.com/blogs/aws/preview-enable-foundation-models-to-complete-tasks-with-agents-for-amazon-bedrock/)——我们的团队在这一功能的开发中发挥了关键作用。

目前处于预览阶段的 Agents for Amazon Bedrock 能够使用流行的 [AWS Lambda](https://aws.amazon.com/lambda/) 函数编排并执行 API 调用。通过这一功能，Claude 可以承担更广泛的代理角色：理解用户请求、将复杂任务分解为多个步骤、通过对话收集更多细节、查找信息并执行操作以完成请求。例如，一个使用 Claude 构建的聊天助手的电商应用，不仅可以查询产品库存，还能实际帮助客户更新订单、进行换货以及查找相关的用户手册。

我们最近还宣布，将通过该服务提供对 Claude 模型的安全定制和微调。这项技术利用 AWS 客户的专业知识和专有数据来优化 Claude 的性能，从而获得更相关的结果，同时限制有害输出的可能性。

Claude 在 Amazon Bedrock 上的全面可用性推动了我们在帮助企业负责任地集成变革性 AI 方面的工作。在接下来的几个月里，我们将宣布更多应用层解决方案，帮助组织从 Claude 中获得最大价值。

自四月份宣布与 Amazon Bedrock 集成以来，Claude 已获得包括 **LexisNexis**、**Lonely Planet** 和 **Ricoh USA** 在内的领先企业的强烈自然采用。

顶级资产管理公司 **Bridgewater Associates** 也在利用我们最先进的模型 Claude 创建一款新颖的、由 AI 驱动的投资分析师助手，以支持其团队中的初级成员。

Bridgewater 致力于从根本上理解经济，揭示驱动全球市场的永恒且普遍的因果关系。为了揭示这些关系，Bridgewater 的分析师们花费大量时间来理解并系统性地对假设进行压力测试，通常通过代码进行。

例如，分析师可能会通过创建关键数据可视化（包括图表和表格）来研究美联储收紧大宗商品价格的影响，从而测试假设、综合发现并分享其研究。Bridgewater 团队正在与 Amazon Bedrock 上的 Claude 合作，使这一过程更加高效和可扩展。

Bridgewater Associates 的 CTO（AI/ML）Aaron Linsky 表示：“Claude 是我们即将在 Amazon Bedrock 上推出的投资分析师助手背后非常强大的模型。它能够根据基本指令生成 Python 代码、处理错误并输出图表和表格，就像一两年经验的分析师一样。当投资分析师助手对执行路径不确定时，它会在尝试执行之前提出澄清性问题。”

Linsky 继续说道：“我们的投资分析师助手还支持就地编辑代码，这让我们的分析师可以选择何时利用 Claude，或者何时自己进行简单的修改。这实现了更快的循环，并让投资分析师助手在更新后的代码基础上进行迭代——这是许多其他聊天式助手所不具备的功能。”

**开始使用 Amazon Bedrock 上的 Claude**
我们很高兴让更多 AWS 社区成员能够访问 Claude，并贡献我们技术团队的专业知识，推动 Amazon Bedrock 服务上的负责任创新。立即开始使用 [Amazon Bedrock 上的 Claude](/amazon-bedrock)。
