计算机操作、技能 API 和文件 API 现已在 Claude 平台上全面开放。计算机操作还新增了一项浏览器操作工具，供在 Web 应用中运行的智能体使用。三者协同，让你能够构建可以操作软件、应用团队专业知识并返回成品文件的智能体。

### **在 Claude 平台上构建智能体**

**计算机操作**让你能够构建可以操作其可见软件的智能体。给定一张屏幕截图，智能体就会像坐在键盘前的人一样点击、输入和滚动。这使得它能够在那些从未为自动化而设计的应用中工作。全新的**浏览器操作工具**将这一能力延伸至 Web 领域。除了屏幕截图，智能体还能读取页面结构，针对特定的字段或按钮进行操作，而非仅仅依据屏幕上的像素位置。

**技能 API** 和**文件 API** 让你能够将该智能体与团队的专业知识和文档相结合。技能是一个包含指令、脚本和模板的文件夹，Claude 仅在任务需要时才加载它。通过**技能 API**，你可以上传并管理自有技能的版本，然后将其附加到任何请求中。它们在 Claude 的代码执行沙箱中运行，因此你无需自行托管。**文件 API** 是智能体读写文档的存储层：只需上传一次 PDF 或电子表格，后续请求中通过 ID 引用即可，无需重复发送，还可以下载智能体生成的文件。

假设你正在构建一个理赔智能体。它从文件 API 读取理赔受理文件，按照编码了团队申报流程的技能执行操作，通过浏览器操作工具在保险商的网页门户中完成提交，并将确认回执保存为文件。已经全面开放的代码执行和网页搜索功能，同样可以融入这一流程。

### **全面开放带来的新特性**

* **计算机操作：** 更新后的计算机操作工具允许 Claude 在每个轮次中执行多个操作，而非每次模型调用仅执行一个操作，因此任务可以用更少的调用次数和更短的时间完成。计算机操作现在也适用于我们 BAA（商业关联协议）框架下受 HIPAA 监管的工作负载。
* **浏览器操作工具：** 计算机操作中今日新增的功能。它采用相同的多操作轮次机制，并增加了页面结构信息，使智能体能比仅凭像素定位更可靠地操作 Web 元素。
* **技能 API：** 更简洁的 API，用于上传和管理自有技能的版本。
* **文件 API：** 自动文件过期、速率限制提升 5 倍，以及每个组织 1 TB 的存储空间。
