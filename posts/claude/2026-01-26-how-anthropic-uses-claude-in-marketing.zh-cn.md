# Anthropic 如何在市场营销中使用 Claude

            **日期：** 2026-01-26 00:00 UTC
            **链接：** https://claude.com/blog/how-anthropic-uses-claude-marketing

            ---

            在 Claude Code 出现之前，Austin Lau 一生从未写过一行代码。当这款产品首次发布时，他不得不去谷歌搜索如何在电脑上打开终端。

"Claude Code 发布时我的第一反应是，我完全不知道这款产品是干什么用的，"Anthropic 的增长营销人员 Austin 说道。"作为一名营销人员，我当时就是没搞明白——它的使用场景对我来说还不明显。"

但好奇心占了上风。

一位 Anthropic 的同事在公司的 Slack 工作区发布了一篇指南，介绍非技术员工如何安装 Claude Code。Austin 决定按照指南操作。

一周后，Austin 构建了两个从根本上改变了他工作方式的工作流：一个 Figma 插件，只需单击一下即可生成广告创意变体；以及一个 Google Ads 文案工作流，帮助他构思和优化广告文案，然后将其导出为可直接上传的 CSV 文件。过去每个广告需要 30 分钟，现在只需 30 秒。

以下是他如何做到的，以及营销人员可以从他使用 Claude Code 的经验中学到什么。

‍

## **问题：淹没在文案和创意变体中**

大规模运行效果营销需要持续产出新鲜创意。仅 Google 的响应式搜索广告就要求 15 个独特的标题。每隔几周，这些文案就需要刷新——同时还要保持品牌调性并传达价值主张。

"这方面具有挑战性的是，当你在这个级别运作时，你需要非常频繁地刷新你的文案，"Austin 解释道。"而且由于严格的字符数限制，Google 的文案要求灵活性较低。"

旧流程是这样的：打开 Google Sheets，构思标题和描述，手动检查字符数，复制粘贴到 Google Ads，然后重复。

对于视觉广告，流程更加复杂。Austin 会打开 Figma，多次复制现有框架，切换到 Google Doc 获取标题文案，再切换回 Figma 粘贴文案，重复操作——跨越十个或更多变体以及多种宽高比。

"所有这些时间加起来非常非常快，"Austin 说。

## **解决方案：消除营销琐碎工作的两个工作流**

使用 Claude，Austin 最终构建了两个改变他日常生活的工流。但 Austin 的第一个项目是构建一个简单的计算器应用。

"我实际上让 Claude 做的第一件事是给我做一个非常简单的计算器应用，只是为了看看它会如何响应，"他回忆道。"Claude 基本上创建了后端，以及一个简单的简易前端。然后它基本上告诉我，'这是你实际运行它的方法。'"

那个小实验改变了他对自己在工作任务中能实现什么的看法。

### **用于创意变体的 Figma 插件**

创建广告变体意味着无休止的复制、粘贴以及在 Figma 和 Google Docs 之间切换。

于是 Austin 用 Claude Code 构建了一个 Figma 插件，这个项目花了大约 45 分钟到一小时来构建，但现在每次他在多个宽高比下更新大批量创意时，能为他节省近 30 分钟。

开始时，他打开 Claude Code 并通过一个提示描述了他的问题："Claude，我在 Figma 中工作。我真的很想解决这个重复复制粘贴的挑战。你能帮我构建一个 Figma 插件来解决我的挑战吗？"

Claude 进行了研究，评估了如何最好地构建插件、有哪些限制，然后开始制作原型。经过一些故障排除后，Austin 在 Figma 中安装了一个可用的插件。

*Austin 的插件让他可以从 Google Sheet 粘贴标题文案，并通过单击一下生成数十个广告变体。*

"我所要做的就是指定创意的框架，然后只需复制粘贴一次所有我想要更新的不同变体和文案，点击一个按钮，Figma 插件就会为那张图片创建所有不同的排列组合，"Austin 解释道。

### **Google Ads 文案生成**

对于响应式搜索广告，Austin 构建了一个工作流，利用现有的广告系列和广告效果数据来帮助构思和创建可直接上传的广告文案，以帮助了解哪些类型的消息能引起潜在客户的共鸣。这个工作流每周在文案创建和字符验证上节省数小时。由于节省了在机械性任务上的时间，Austin 现在可以运行更多的文案实验，并更快地迭代实际表现最好的内容。

要开始，他在 Claude 中输入 `/rsa`，这是他专门为响应式搜索广告创建的自定义斜杠命令。Claude Code 会询问广告系列数据、现有文案和关键词，然后将他输入的内容与他为 Anthropic 品牌调性和语气、产品准确性以及 Google Ads RSA 最佳实践创建的 [Agent 技能](https://claude.com/blog/skills) 进行交叉引用。

但输出只是一个起点。

"Claude 是一个很棒的头脑风暴伙伴，但有时它第一次尝试时并不完全正确，"Austin 解释道。"我所做的很多工作就是即兴发挥，反复来回，以帮助随着时间的推移完善文案。"

这种完善很重要，因为 Austin 会根据他所了解的与 Anthropic 受众产生共鸣的内容来评估每个标题。价值主张是否到位？语气是否正确？是否从竞争对手中脱颖而出？一旦文案感觉合适，Claude Code 会将所有内容合并到一个 CSV 文件中，准备上传。

而这一切都建立在人工基础上。"我们提供给 Claude 的所有文案和示例都是与产品营销和文案团队合作编写的，"Austin 说。这个坚实的起点意味着在 Claude 开始头脑风暴之前，就已经融入了人类的判断。

*该工作流将相关的广告系列和广告组列，以及每个广告 15 个标题和 4 个描述导出到一个 CSV 文件中，准备直接上传到 Google Ads（经过人工审核后）。*

## **构建自己的工作流的最佳实践**

Austin 的经验为营销人员——或者实际上任何没有技术背景的人——提供了实用指导，帮助他们使用 Claude Code 构建自定义工具。

**从小而重复的步骤开始**

"我的建议是：如果你想尝试像 Claude Code 这样的工具，只需思考一下，你工作中哪些领域是你认为重复的，或者你认为可以自动化的，然后从一个非常非常小且简单的事情开始，"Austin 解释道。

例如，Austin 的第一个项目是构建他的计算器应用，先看看 Claude 是如何工作的。

**让好奇心驱动你的工作**

Austin 形容自己是"那种类型的人，如果我对某件事非常好奇，它会达到近乎固执的程度，我必须找到答案。"这种坚持将一个他不知道如何交互的空白终端变成了他每天使用的功能性工作工具。

**像向同事解释问题一样与 Claude 对话**

"你不需要知道如何编码。你只需要知道如何以非常清晰简洁的方式解释你的挑战和你试图解决的问题，"Austin 说。

非技术员工已经是自己领域的主题专家。他们了解自己的工作流，感受到痛点，并且确切知道他们需要什么样的输出。Claude Code 让他们有能力自己修复任何重复出现的技术问题。

**建立在已有资源的基础上**

对于 Figma 插件，Austin 将 Claude Code 指向现有的 Figma API 文档。利用现有文档，Claude 进行了自己的研究，并为 Austin 构建了一个原型进行实验。一个几乎无法运行的原型足以证明 Austin 心中的概念，最终形成了一个功能性的产品。

**更大的图景**

在他职业生涯的大部分时间里，Austin 认为某些事情是他无法企及的。如果他需要安装跟踪像素，他必须请工程师来安装。如果他需要构建自定义工作流，他必须向支持部门提交工单。

"我会说几年前，如果你有一个想法要构建像这样的工作流，你可能需要一个工程师团队来支持你，"Austin 说。"现在，有了像 Claude Code 这样的工具，作为一个非技术营销人员，我可以实际去构建这些东西。所以'我希望这个存在'和'我实际上可以自己构建这个'之间的差距比人们意识到的要小得多。"

他现在已经向同事和客户演示了他的工作流，他们都有同样的反应：为什么我们*没有*做这个？

## **营销人员的下一步是什么**

Austin 认为增长营销人员的角色正在迅速演变。"我认为增长营销正在走向几乎像产品经理一样，"Austin 说。"我们不仅能够执行广告系列，我们实际上能够构建产品来帮助我们实现目标。"

Austin 不是 Anthropic 唯一使用 Claude 进行构建的营销人员。在整个营销组织中，团队正在发现类似的结果：

* **影响者营销** 使用 Claude 为影响者和播客撰写脚本，每月释放 100 多个小时用于专注于更高价值的工作
* **客户营销** 在 30 分钟内起草案例研究，而不是 2.5 小时，每周节省 10 小时
* **数字营销** 构建了 Web 开发工作流，使团队生产力同比提高了 5 倍
* **产品营销** 使用技能和项目创建发布简报，每次发布节省 5-10 小时
* **合作伙伴营销** 为销售团队构建了自助式活动支持，将贸易展准备时间减少了 40%

"大多数营销人员可能以相同的方式对待 AI，他们只是将其视为一种简化写文案或头脑风暴等事情的方法，"Austin 说。"但他们还没有真正思考过哪些实际领域可以真正将像 Claude 这样的工具嵌入到他们的工作流中。"

对于采用像 Claude Code 这样的工具的团队来说，一个机会正在出现，让他们花更少的时间在重复执行上，而花更多的时间在他们工作中真正重要的事情上。
