自托管环境现已进入公测阶段，让您能够在自己的基础设施上运行 Claude Code 会话。您可以从网页、移动端、桌面端或定时任务中启动会话，该会话将在您的网络内部运行，紧邻您的内部服务、工具链和安全控制，而非运行在 Anthropic 托管的基础设施上。

对于大多数企业，我们强烈推荐使用我们的托管服务，因为它在运维方面更为简便，无需自行运行或维护任何基础设施。自托管环境适用于那些因网络、工具或合规要求而需要将智能体执行保留在自身可控基础设施上的团队。如果选择此方案，请规划安排工程人员负责搭建及后续维护工作。

### **为何选择自托管**

我们在预览计划中观察到，各组织采用自托管环境主要基于以下几个关键原因：

* **网络访问：** 会话在您的网络内部运行，可以访问内部服务、数据库和注册中心，而无需将其暴露于公共互联网
* **可定制性：** 在您的环境中预装编译器、SDK 和内部 CLI 工具，使每个会话启动后即可立即投入构建
* **合规性：** 源代码和构建产物保留在您可控制的基础设施上
