**链接：** https://claude.com/blog/how-the-product-designer-who-built-claude-design-uses-it-to-explore-ideas-before-building-them

2025 年秋季，我是 [VS Code 的 Claude Code](https://code.claude.com/docs/en/vs-code) 的唯一产品设计师，与两位工程师合作，重新构想 Claude Code 在终端之外通过友好界面所能做的一切。我们在 9 月底 [发布了测试版](https://www.anthropic.com/news/enabling-claude-code-to-work-more-autonomously)，11 月 [Opus 4.5 问世](https://www.anthropic.com/news/claude-opus-4-5)，Claude Code 团队开始快速且激进地发布版本。工程师们的产出远超以往，而我的交付速度却一如既往。我需要找到一种方法来追赶进度。

Claude Code 在终端中运行，所有内容都是基于文本的，而我的第一次尝试也沿用了这种方式：我将输出复制到 Claude 中，添加截图，然后问：“这是我们想添加的一个功能。你为什么不设计一下？”结果并不理想。大约一个月的时间里，作为一项副业，我一直在寻找改进 Claude 设计输出的方法。

## **给 Claude 一个 HTML 游乐场**

最终我偶然发现了答案：Claude 非常擅长 HTML。我们通常将 HTML 视为网站格式，但它也是一种丰富的交互式视觉媒介：你在幻灯片、视频文件或 PDF 中能做出的任何东西，都可以在网页中实现。于是我提示 Claude 制作 HTML，并给它一个分屏界面，左边可以聊天，右边看到输出。

这很有用，但产品设计是由对产品和品牌的了解驱动的，因此下一步我花了一些时间将 Anthropic 品牌的核心要素（我们产品使用的字体、颜色、资源和原则）提炼成提示词。这样一来，当我在工具中输入提示词时，输出就符合 Anthropic 的品牌指南。

我把所有这些放入一个小型内部原型中，并与团队分享。产品设计师们立即将其用于交互式原型。在传统设计工具中制作可点击的原型，意味着要手动模拟每个屏幕的每个状态并将它们连接起来。而在这里，你把资产交给 Claude 然后说：让它工作起来。它交付的每个作品都会附带一个链接，你可以像分享文档一样分享它。

## **Claude Design 如何成为视觉工作的媒介**

我第一次真正意识到 Claude Design 有多强大，是在一次 [Anthropic Labs](https://www.anthropic.com/news/introducing-anthropic-labs) 团队外出活动的创意提案会上：在场的每个人都用它快速拼凑幻灯片，甚至是在会议中途、轮到他们展示之前。那次会议让 Labs 团队决定正式投入资源，Claude Design 从一个副业项目变成了一个真正的项目。

我们不再把它描述为产品原型工具。Claude Design 变成了一个用于制作任何类型视觉沟通的工具：幻灯片、落地页、可打印为 PDF 的单页文档、电子邮件、动画、社交媒体视觉内容。我认为它比产品设计高一个层次：你与 Claude 协作制作视觉内容，其主要任务是沟通和构思。

随着模型在视觉能力上的提升，Claude Design 所能完成的工作范围和质量也在提高。我们最新的 Opus 级模型 [Claude Opus 5](https://www.anthropic.com/news/claude-opus-5) 在读取图表、示意图和截图方面比之前的 Opus 模型更出色，因此与 Claude Design 搭配使用时，在制作适合演示的幻灯片和备忘录方面更加强大。

## **Claude Design 不适合做什么**

Claude Design 没有图像模型，也不是为图像生成而设计的，因此它不适合做 Logo 设计——尽管这并没有阻止人们去尝试。更好的方法是使用你已有的 Logo 和资产。产品的其余部分也以同样的方式工作：Claude 创建选项和起点，这样你就不必面对空白画布发呆，你可以选择那些本身就很好的版本，或者多个版本的组合。

如果你正在发布生产级软件，请坚持使用 Claude Code。Claude Code 用于编码；Claude Design 用于设计工作的其他部分：早期构思、协作，或在任何人承诺开始构建之前获得方向的认可。两者可以循环配合使用，这样你可以将 Claude Code 中开始的原型同步到 Claude Design 进行迭代和画布编辑，或者将 Claude Design 中准备构建的原型移交到 Claude Code。随着模型在构建生产级软件方面的能力越来越强，最重要的工作会转移到流程的更早期：拥有好想法、让所有人对齐、在想法尚处于早期阶段时收集反馈。

## **我如何在日常工作中使用 Claude Design**

我每天都会使用 Claude Design 进行所谓的基础设计工作：绘制早期想法的线框图，或者生成 15 个版本的流程以收集同事的反馈。以下是我自己工作中最近的一些例子：

* **Claude Design 的入门动画。** 当你注册 Claude Design 时播放的动画就是用这个工具本身制作的，但并非直接制作：我不是动画师，所以我先让 Claude Design 为我构建一个定制的视频编辑器，然后用那个编辑器制作了动画。

* **一个地铁时刻应用**，带有可调节的动画控件，用于精细调整运动的物理效果。

* **Instagram 风格的颜色控件。** 我要求 Claude 让我通过滑块和预设来调整应用的颜色方案，而不是用文字描述颜色。

* **Claude Design 自身的重新设计。** 我和两位同事 Helen 和 Andrew 一直在工具内对编辑器进行新的设计构思。我们不会按原样发布它，但这是我们探索产品可能发展方向的方式。

## **使用 Claude Design 的最佳实践**

1. **在提示之前先进行思考。** 获得符合你愿景的最佳且最高效的方法是，一开始就告诉 Claude 你需要什么。我会在设计之前花很多时间来写提示词。有时我会在 Claude Design 中用语音按钮口述它们。其他时候我会在沙发上用手机上的备忘录应用输入，或者在散步时录下语音笔记，稍后粘贴转录文本。无论你偏爱哪种沟通方式，都要在远离电脑时想好你想要什么，这样当你坐下来时，Claude 就能执行你的确切愿景。
2. **告诉 Claude 它应该长什么样。** 如果不加以引导，Claude 会选择它最喜欢的某种美学。[你可能认得出这些风格。](https://www.newyorker.com/the-ai-design-aesthetic-thats-taking-over-the-internet) 通过指定字体和颜色，或提供情绪板图片作为灵感，或者让 Claude 头脑风暴字体和颜色的搭配并来回沟通直到感觉合适，来避免这种情况。
3. **将重复性工作转化为设计系统。** 上传你的品牌文件和资产，如 Logo、幻灯片、截图、排版规范以及任何你重复使用的内容，Claude 会分析它们并[生成一个设计系统](https://support.claude.com/en/articles/14604397-set-up-your-design-system-in-claude-design)。这样，你之后制作的每个作品都会从你的选择开始，而不是从空白画布开始。
4. **要求十个选项，然后混搭。** 大部分选项不会很好，这没关系；会有一两个好的。然后说：“我喜欢选项 B 和选项 D 的一小部分。给我五个把两者揉合在一起的变体。”
5. **画出你无法描述的东西。** 如果你脑海中有个布局但找不到合适的词语，把它画在纸上并上传一张照片。
6. **指点和说话。** 不必写一段话来指明你说的是哪个元素，而是点击它并说出你的想法。你需要启用设备上的听写功能，然后选择“评论”并点击进入评论框。你的话会像打字一样出现在评论框中。
7. **当保真度不重要时，先画线框图。** 要求线框图要快得多，并且能让 Claude 专注于设计的高层结构而非视觉效果。这是快速尝试多种不同想法的好方法。
8. **最后一公里手动完成。** 使用直接编辑工具（重新排列、删除、编辑文本、调整大小、更改颜色）进行最终润色，而不是通过提示词来操作。直接编辑不消耗 tokens，而且像尺寸和对齐这样的小调整最好还是用眼睛来判断。
9. **给 Claude 你的真实上下文。** 如果你正在为现有应用或网站设计功能，可以连接 GitHub：Claude 将获取你的组件和现有屏幕并将其作为起点，经过几次尝试就能以相当高的保真度重现你现有的设计。当设计依赖外部信息时，Claude Design 也能使用网页搜索和 MCP 连接。
10. **继续与 Claude 协作。** 你不必等到 Claude 交付完整体结果后再提示新的更改或任务。你可以一次排队多条消息，或者当 Claude 还在处理上一轮工作时继续说话。

## **让它活起来**

有一场 Bret Victor 的演讲，每个设计师都应该在某个时候看看，叫做 [Stop Drawing Dead Fish](https://vimeo.com/64895205)。简介说：“我们画的所有东西默认都应该是活的。”

我鼓励设计师们，无论是在 Claude Design 还是其他工具中，都要思考如何让自己的创作活起来。我最喜欢的 Claude Design 创作是那些无法归入现有框架的作品：带有交互式模拟的文档、会跟你说话的幻灯片、同时也是视频的图表、同时也是自身编辑器的设计。代码，特别是 HTML，是一种绝佳的创意媒介，而且设计师终于可以相对容易地用它进行创作了。

Claude Design 之所以成为现在的样子，是因为 Anthropic 的人们不断发现我未曾计划过的用途；它现在以测试版形式在 Claude Pro、Max、Team 和 Enterprise 计划中可用。[试试看](https://claude.com/product/design)，把它带到我们还没想到的地方去。
