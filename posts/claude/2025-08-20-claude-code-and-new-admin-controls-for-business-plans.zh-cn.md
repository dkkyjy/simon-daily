# Claude Code 及面向商业计划的全新管理员控制功能

            Enterprise 和 Team 客户现在可以升级到高级席位，这些席位包含更多使用量和 Claude Code——将我们的应用和强大的编码代理整合到一个订阅下。用户可以在构思与实施之间无缝切换，而管理员则能获得所需的可见性和控制力，以便在其组织内扩展 Claude 的应用。

我们还推出了一款全新的合规 API，为组织提供对使用数据和客户内容的编程式访问，以实现更好的可观测性、审计和治理。

## 将 Claude Code 添加到您的计划中

管理员拥有完全的灵活性，可以根据个人用户需求和组织角色分配标准席位或高级席位。高级席位让用户能够同时使用 Claude 和 Claude Code，从而在整个开发生命周期中与 Claude 合作。

例如，开发人员可以通过与 Claude 的交互式聊天来研究不熟悉的框架，然后在终端中使用 Claude Code 实现生产就绪的代码。他们可以在 Claude 对话中探索架构方法并评估权衡，然后切换到 Claude Code 来构建所选架构。

像 Behavox 这样的早期客户（一家合规与安全公司）已经看到了立竿见影的效果。“自从将 Claude for Enterprise 与 Claude Code 捆绑后，我们已将其推广给数百名开发人员，它迅速成为了我们的首选结对编程伙伴，”机器学习运营高级经理 Artem Pikulin 分享道。“它的编码辅助始终优于其他代理，每天都提供卓越的结果和价值。”

Altana，这个连接全球供应链的 AI 驱动产品网络，也经历了类似的变革性成果。“Claude Code 和 Claude 将 Altana 的开发速度提升了 2 到 10 倍，改变了我们构建复杂 AI/ML 系统的方式，这些系统促进了全球供应链大规模知识图谱上的多方协作，”联合创始人兼首席科学官 Peter Swartz 表示。“因此，我们正在承担更具雄心的项目。”

## 灵活的定价，可预测的成本

Claude 席位包含足够一个典型工作日使用的用量，但当您的团队需要访问更多智能以及与 Claude 进行更多对话时——管理员可以为个人用户启用额外用量，按标准 API 费率计费。管理员可以控制用户使用额外用量的最大金额，以确保用户获得灵活性，同时管理员获得可预测的账单。

这种方法提供了一种与 Claude 一起扩展的简单方式，同时在每一步都提供集中计费、管理和企业级管理控制。

## 管理员控制与管理

我们构建了全新的全面控制功能，为组织提供所需的可见性和管理能力，使员工能够高效地与 Claude 协作。

*   **自助式席位管理**：通过管理面板购买新席位、直接管理席位分配以及配置用户。
*   **精细的支出控制**：在组织和个人用户级别设置支出限制，以保持在预算范围内，同时为关键项目保持灵活性。
*   **使用分析**：在 Claude 中查看 Claude Code 分析，包括接受的代码行数、建议接受率和使用模式等指标。
*   **托管策略设置**：在所有 Claude Code 用户中部署和强制执行与内部策略相匹配的设置，包括工具权限、文件访问限制和 MCP 服务器配置。

## 合规 API

企业组织现在可以通过我们全新的合规 API 更好地满足监管要求。合规团队无需手动导出和定期审查，即可获得对 Claude 使用数据和客户内容的实时编程式访问，从而能够构建持续监控和自动化策略执行系统。

管理员可以将 Claude 数据集成到现有的合规仪表板中，自动标记潜在问题，并通过选择性删除功能管理数据保留。这提供了组织在扩展 AI 采用的同时满足监管义务所需的可见性和控制力。
