# 一句话总结

Anthropic 推出 Citations API，让 Claude 能够引用源文档中的具体句子，提升 AI 输出的可验证性和可信度。

# 主要观点

1. Citations 是 Anthropic API 的新功能，支持引用源文档。
2. 它可引用源文档中的确切句子和段落。
3. 该功能现已在 Anthropic API 和 Vertex AI 上可用。
4. 内置引用比自定义实现召回准确率提高 15%。
5. 支持文档摘要、复杂问答和客户支持等用例。
6. 处理 PDF 和纯文本文件，自动分句并引用。
7. 用户也可提供自定义分块用于源文档。
8. 引用文本不收取输出 token 费用。
9. Thomson Reuters 和 Endex 已成功使用该功能。
10. 适用于 Claude 3.5 Sonnet 和 Claude 3.5 Haiku。

# 要点总结

1. 使用 Citations 可减少提示工程投入，提升引用一致性。
2. 内置引用功能显著降低幻觉风险，增强输出可信度。
3. 支持多种文档格式，无需文件存储，集成简单。
4. 引用文本不计费，仅按标准 token 定价模型收费。
5. 企业客户已验证该功能可消除源幻觉并提高引用率。
