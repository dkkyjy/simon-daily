# 改进技能创建器：测试、衡量和优化智能体技能

            **日期：** 2026-03-03 00:00 UTC
            **链接：** https://claude.com/blog/improving-skill-creator-test-measure-and-refine-agent-skills

            ---

            技能创建器现在可以帮助您编写评估、运行基准测试，并在模型演进时保持技能正常工作。这些更新现已可在 Claude.ai 和 Cowork 中使用，作为 [Claude Code 的插件](https://github.com/anthropics/claude-plugins-official/tree/main/plugins/skill-creator)，以及 [在我们的代码库中](https://github.com/anthropics/skills/tree/main/skills/skill-creator) 获取。

自去年十月[推出智能体技能](https://claude.com/blog/skills)以来，我们注意到大多数作者是领域专家，而非工程师。他们了解自己的工作流程，但缺乏工具来判断技能是否仍能与新模型配合使用、是否能在应该触发时触发，或者编辑后是否真的得到了改进。

今天我们宣布技能创建器的增强功能，帮助作者更自信地构建技能。我们将软件开发中的一些严谨方法（测试、基准测试、迭代改进）引入技能创作中，且无需任何人编写代码。

## **两种技能**

技能通常分为两类：

**能力提升**技能帮助 Claude 完成基础模型无法做到或无法持续做到的事情。我们的[文档创建技能](https://github.com/anthropics/skills/tree/main/skills)就是很好的例子。它们编码了能够比单纯提示产生更好输出的技术和模式。

**编码偏好**技能记录了 Claude 已经能够完成每个环节的工作流程，但技能根据您团队的流程对它们进行排序。例如：一个按照设定标准进行保密协议审查的技能，或者一个利用各种 MCP 数据起草每周更新的技能。

这种区分很重要，因为这两种类型的技能可能需要出于不同原因进行测试：

* 随着模型改进，能力提升技能可能变得不那么必要。评估会告诉您这种情况何时发生。
* 编码偏好技能更加持久，但其价值取决于对实际工作流程的忠实程度。评估验证了这种忠实度。

无论哪种方式，测试都将一个*看似*有效的技能转变为一个您*知道*有效的技能。

## **使用评估来测试和改进技能**

技能创建器现在帮助您编写评估，这些测试用于检查 Claude 是否对给定提示执行了您期望的操作。如果您编写过软件测试，会对此感到熟悉：定义一些测试提示（如果需要还包括文件），描述什么样的结果是好的，然后技能创建器会告诉您技能是否经得起考验。

例如，我们的 PDF 技能之前在处理不可填写表单时遇到困难。Claude 必须在没有定义字段引导的情况下将文本放置在精确坐标上。评估隔离了故障，我们发布了一个修复，将定位锚定到提取的文本坐标上。

评估在许多方面都有帮助，但两个重要的用途是捕捉质量回归和理解模型进展。

首先，**捕捉质量回归。** 随着模型及其周围基础设施的演进，上个月运行良好的技能今天可能会有不同的表现。针对新模型运行评估会在问题影响团队工作之前给您一个早期信号。

其次，**了解通用模型能力何时已经超越您的技能。** 这主要适用于能力提升技能。如果基础模型*在没有*加载技能的情况下开始通过您的评估，这表明该技能的技术可能已被纳入模型的默认行为中。技能没有损坏，只是不再需要了。

我们还增加了一个**基准测试模式**，使用您的评估运行标准化评估。您可以在模型更新后或在对技能本身进行迭代时运行此模式。它会跟踪评估通过率、耗时和令牌使用量。

您的评估和结果由您自己保留。可以本地存储、集成到仪表板或接入 CI 系统。

## **通过多智能体支持实现更快、更一致的评估**

顺序运行评估可能很慢，且累积的上下文可能会在测试运行之间产生交叉污染。技能创建器现在通过**多智能体支持**启动独立智能体并行运行评估——每个智能体在干净的上下文中运行，拥有自己的令牌和计时指标。结果更快，无交叉污染。

我们还增加了用于 A/B 比较的**比较智能体**：两个技能版本，或技能与无技能对比。它们在不了解哪个是哪个的情况下判断输出，这样您就能知道某项更改是否真的有所帮助。

## **让技能在正确的时间触发**

评估衡量输出质量，但这只有在您的技能在应该触发时触发才有意义。随着技能数量的增长，描述精确度变得至关重要：描述太宽泛会导致误触发，太狭窄则永远不会触发。技能创建器现在帮助您调整描述以实现更可靠的触发——它会根据样本提示分析您当前的描述，并建议既能减少误报又能减少漏报的编辑。

我们在文档创建技能上运行了此功能，看到 6 个公开技能中有 5 个的触发得到了改善。

## **展望未来**

随着模型的改进，"技能"和"规范"之间的界限可能会变得模糊。今天，SKILL.md 文件本质上是一个实施计划，提供详细指令告诉 Claude *如何*做某事。随着时间的推移，对技能*应该做什么*的自然语言描述可能就足够了，由模型自行解决其余部分。

我们今天发布的评估框架是朝这个方向迈出的一步。评估已经描述了"做什么"。最终，这个描述本身可能就是技能。

## 开始使用

所有技能创建器的更新现在都可在 Claude.ai 和 Cowork 上使用。让 Claude 使用技能创建器开始操作。

Claude Code 用户可以安装[插件](https://github.com/anthropics/claude-plugins-official/tree/main/plugins/skill-creator)或从我们的[代码库](https://github.com/anthropics/skills/tree/main/skills/skill-creator)下载。
