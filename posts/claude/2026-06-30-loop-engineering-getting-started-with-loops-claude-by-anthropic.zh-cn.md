## 循环入门

现在有很多关于循环工程或“设计循环”而非为你的编码代理编写提示的讨论。如果你在X上花些时间试图弄清楚循环到底是什么，你会遇到多种不同的答案。

在 Claude Code 团队，我们将**循环定义为代理重复工作循环直到满足停止条件**。我们根据以下标准对几种不同类型的循环进行分类：

* 如何触发
* 如何停止
* 使用什么 Claude Code 原语
* 哪种类型的任务最适合每种循环。

我们将介绍主要的循环类型、何时使用每种类型，以及如何在管理令牌使用量的同时保持代码质量。并非所有任务都需要复杂循环；从最简单的解决方案开始，并有选择地使用这些模式。
