# 一位非技术项目经理如何用 Claude Code 在六周内构建并发布了一款压力管理应用

## 一句话摘要

一位零编程经验的项目经理借助 Claude Code，在六周内独立构建并发布了基于科学呼吸法的 iOS 压力管理应用 Respiro。

## 主要观点

1. 创始人 Kostiantyn Vlasenko 有十年项目管理经验，但从未写过代码。
2. Respiro 能实时检测用户压力信号并主动引导呼吸练习。
3. 应用架构包含 15 多个由 Vlasenko 构建的专业子代理。
4. 他用 Claude Code 在 72 小时内完成初始版本，无团队无编程背景。
5. 项目管理经验比编码技能更重要，管理代理如同管理人。
6. Claude 的视觉能力被低估，能通过截图指导复杂操作流程。
7. Claude 帮助从 React Native 迁移到 Swift，仅用几小时重写。
8. Claude 建议联系心理学家推广，该策略成功获得推荐。
9. Vlasenko 现在也在日常工作中使用 Claude 提交代码和发布功能。
10. 他认为 Claude Code 是“新瘾”，消除了可能性的界限。

## 收获

1. 非技术人员可借助 AI 工具独立完成从构想到发布的完整产品开发。
2. 项目管理技能（分解任务、协调资源）在 AI 开发中比编码能力更关键。
3. Claude 的视觉和引导功能能有效降低技术门槛，简化复杂操作。
4. 快速迭代和灵活切换技术栈（如从 React Native 到 Swift）成为可能。
5. 营销和增长策略同样可借助 AI 生成，包括内容创作和合作伙伴拓展。
