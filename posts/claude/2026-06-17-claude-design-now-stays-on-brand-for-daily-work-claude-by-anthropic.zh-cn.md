[Claude Design](https://claude.com/product/design) 现在能够在整个项目中遵循你的设计系统，与 Claude Code 流畅协作，让你直接在画布上编辑，并连接到更多你已有的工具。它在 Claude 桌面应用的侧边栏中有了新家；https://claude.com/product/design

我们的目标一如既往：让你在截止日期通常允许的范围之外探索更多方向，并尽可能无缝地完成交付打磨或构建。如今，这个目标服务于更多人。超过一百万人在第一周内使用了 Claude Design，你们的反馈正塑造着我们下一步的构建方向。

## 使用你的设计系统组件进行构建

我们重建了设计系统导入功能，以提供更大的灵活性和更高的精确度。可以从 GitHub 仓库、设计文件或原始上传中导入一个或多个设计系统。Claude 会使用你的组件进行构建，对照你的设计系统检查输出结果，并在你看到之前进行修正。对于较大的团队，新的管理员角色可以批准一个标准系统并锁定编辑权限，从而确保作品始终符合公司规范。

## 在设计代码之间切换

现在，在 Claude Design 和 Claude Code 之间切换工作变得更加容易，同时保持你的工作同步，相关更新已于今日推出。使用 `/design-sync` 拉入你的设计系统，这样你在 Claude Design 中构建的一切都从现有组件开始。当设计准备好转化为软件时，你可以将其交接给 Claude Code，它会从你已有的工作继续，而不是从截图重新开始。

更喜欢从 Claude Code 开始？你无需离开终端，即可使用 `/design` 创建、编辑和同步设计项目。将设计导入你的代码库，将代码转化为实时原型，或者让 Claude 把项目一直推进到底。

## 日常使用更稳定

我们的新编辑器让你能直接、精细地控制设计中的每个元素。全新的丰富布局控制功能让你可以拖拽、调整大小并对齐元素。数百项稳定性修复使编辑器在实际使用中表现得更加可靠。

此外，Claude Design 现在与聊天、Claude Cowork 和 Claude Code 共享使用额度，因此大多数人将获得更多的创作空间，而遇到额度限制的情况也会减少。平均运行次数现在用更少的 token 就能达到同样的效果，错误率也大幅下降。

## 从画布到你常用的工具

可稳定导出为 PDF 和 PowerPoint，或将作品发送到你已有的应用程序——目前连接器列表包括 Adobe、Base44、Canva、Gamma、Lovable、Miro、Replit、Vercel 和 Wix，更多目的地即将推出。
