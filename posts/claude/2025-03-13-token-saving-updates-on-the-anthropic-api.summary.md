# 一句话摘要

Anthropic API 更新为 Claude 3.7 Sonnet 带来缓存感知速率限制、简化提示缓存和高效工具调用，显著提升吞吐量并降低成本。

# 主要观点

1. 缓存感知速率限制使提示缓存读取令牌不再计入输入令牌每分钟限制。
2. 简化缓存管理让 Claude 自动读取最长先前缓存前缀，无需手动追踪。
3. 令牌高效工具调用可减少高达 70% 的输出令牌消耗。
4. 新文本编辑器工具支持对代码、文档和研究报告进行精准编辑。
5. 提示缓存可为长提示降低高达 90% 成本并减少 85% 延迟。
6. 缓存感知 ITPM 限制仅适用于 Anthropic API 上的 Claude 3.7 Sonnet。
7. 令牌高效工具调用目前处于测试阶段，支持 Anthropic API 和主要云平台。
8. 早期用户使用令牌高效工具调用平均减少 14% 输出令牌消耗。
9. 文本编辑器工具适用于用户与 Claude 协作处理文档的应用场景。
10. 所有功能即日起对 Anthropic API 客户开放，代码更改极少。

# 核心启示

1. 优先利用缓存感知速率限制优化提示缓存使用，最大化现有速率限制吞吐量。
2. 实施令牌高效工具调用需添加特定 beta 标头，并确保使用相应 SDK 版本。
3. 集成文本编辑器工具可提升文档协作效率，同时降低令牌消耗和延迟。
4. 提示缓存特别适合文档分析、代码辅助和客户支持等高上下文应用场景。
5. 立即通过三步操作开始使用：启用缓存、添加标头、集成文本编辑器工具。
