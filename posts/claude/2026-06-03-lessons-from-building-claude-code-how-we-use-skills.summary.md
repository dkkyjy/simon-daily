# 中文摘要

## 一句话总结
技能是Claude Code中最强大的扩展点，通过九种分类和最佳实践可显著提升AI代理的开发效率。

## 核心要点
1. 技能是包含指令、脚本和资源的文件夹，而非单纯的Markdown文件。
2. 九种技能分类包括库参考、产品验证、数据分析等。
3. 产品验证技能对Claude输出质量影响最大。
4. 避免陈述Claude已知的常识性内容。
5. 构建“注意事项”部分记录常见失败点。
6. 利用文件系统和渐进式披露提供上下文。
7. 为模型而非人类编写技能描述。
8. 通过日志文件帮助Claude记住历史操作。
9. 存储脚本让Claude专注于组合而非重构。
10. 使用按需钩子仅在需要时激活特定功能。

## 关键启示
1. 从少量规则和单个注意事项开始，逐步迭代完善技能。
2. 将技能检查到仓库或通过插件市场分发。
3. 通过PreToolUse钩子记录技能使用情况以衡量效果。
4. 技能可相互引用实现组合，无需原生依赖管理。
5. 优先投资产品验证技能以最大化Claude输出质量。
