# Claude 与您的生产力平台 | Anthropic 的 Claude

**日期：** 2025-10-16 00:00 UTC
**链接：** https://claude.com/blog/productivity-platforms

---

Claude 现已与 Microsoft 365 集成，并支持跨已连接工具的企业搜索。

Claude 与您日常使用的生产力工具协同工作，将文档、邮件和日历中的上下文直接引入您的对话。减少信息收集的时间，将更多精力投入到推动成果的关键决策和工作中。

## Claude 的 Microsoft 365 连接器

通过我们的 MCP 连接器将 Claude 与 Microsoft 365 连接。Claude 可以访问您的文档、通信记录和日历，从而获得更充分的协作上下文——帮助您分析复杂问题、做出明智决策并更快采取行动。

Claude 支持以下工具：

* **Microsoft SharePoint 和 OneDrive**：跨站点和文档库搜索并分析文档，从项目规范到战略规划，无需手动将文件上传至 Claude。
* **Microsoft Outlook**：访问邮件线程，分析沟通模式，从往来邮件中提取洞察，以了解项目状态、客户反馈或团队协调情况。
* **Microsoft Teams：** 搜索聊天对话、频道讨论和会议摘要，以梳理决策、跟踪项目更新并了解团队近期讨论的内容。

## 企业搜索

我们还在通过一个专用的共享项目来简化获取公司知识的流程，该项目以您的公司名称进行个性化定制。该项目包含自定义提示，帮助 Claude 有效地跨公司工具进行搜索，同时提供了连接核心工作应用的简易设置步骤。管理员完成配置并连接核心工具后，组织中的每位成员均可自动获得该项目的访问权限。

当您向 Claude 提问时，它可以在一个地方搜索公司所有已连接的数据源，因此您获得的答案源自组织的集体知识，而不仅仅是您个人的文件。例如，询问 Claude 公司关于远程办公的政策，即可获得一份综合详细报告，内容涵盖 SharePoint 中的人力资源文档、Outlook 中的邮件讨论以及来自各渠道的团队指南。

企业搜索对于新员工入职融入、回答战略性问题（如分析客户反馈中的趋势）以及快速锁定任何主题下合适的内部专家尤为有价值。

## 开始使用

Microsoft 365 连接器现已面向所有 Claude 团队版和企业版计划客户开放。管理员须先为其组织启用该连接器，之后个人用户方可使用其账户完成身份验证。

企业搜索已面向所有团队版和企业版组织启用。管理员需在团队使用之前完成项目自定义并为组织整理数据源。
