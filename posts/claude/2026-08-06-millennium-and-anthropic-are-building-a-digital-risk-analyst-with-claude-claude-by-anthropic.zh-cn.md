# Millennium 与 Anthropic 携手打造基于 Claude 的数字风险分析师 | Anthropic 出品 Claude

**日期：** 2026-08-06 00:00 UTC
**链接：** https://claude.com/blog/millennium-and-anthropic-are-building-a-digital-risk-analyst-with-claude

---

Anthropic 正与全球最大另类投资管理机构之一的 Millennium 合作，共同开发一款数字风险分析师：一位 AI 协作伙伴，将在 Millennium 风险经理的协作与监督下工作，挖掘新的风险洞察，并就跨资产类别的风险敞口形成判断。

Claude 和 [Claude Code](https://claude.com/product/claude-code) 如今已在 Millennium 内部得到广泛应用——从交易台和工程团队到核心业务职能。Millennium 的数字风险分析师进一步拓展了其对 Claude 的应用，帮助风险经理加快并深化对风险头寸的分析。

## 借助 Claude 评估金融风险

数十年来，投资机构一直在利用技术提升风险度量能力，从传统评估方式逐步过渡到更为复杂的实时情景分析。Millennium 的数字风险分析师旨在应对关键工作流程，依托 Millennium 的专有数据和 Claude 的前沿智能能力驱动。

数字风险分析师能够随时间积累和调取信息，运用新的推理能力帮助解释每日风险变动。这些发现随后由 Millennium 的人类风险经理进行验证和补充完善。

"在 Millennium，我们相信 AI 能够帮助我们的团队突破能力上限、树立新的标杆，"Millennium 首席信息官 Vlad Torgovnik 表示。"我们与 Anthropic 的合作正是这一理念的绝佳例证，展现了 AI 如何在核心业务领域推动创新，同时确保人类判断始终处于决策的核心。我们期待与这一行业领导者继续携手，探索 AI 为业务创造更多价值的新途径。"

## Millennium 员工如何使用 Claude

Millennium 是 Claude 和 Claude Code 的早期采用者。员工使用 Claude Code 编写软件、构建产品并优化工作流程，涵盖 Millennium 旗下 340 多个投资团队。

数字风险分析师通过记录推理过程、在沙盒环境中测试操作，并要求人类专家评估和审批其决策，从而提供安全、可审计的分析结果。Millennium 的风险专家正与 Anthropic 的研究及应用 AI 团队在 Millennium 的 AI 实验室中协同合作，共同构建这一系统。

Millennium 正利用其内部 AI 实验室持续突破前沿，以富有雄心的应用场景对 Anthropic 最新的 Claude 模型进行压力测试，并在快节奏的环境中推动 Claude 实现创新应用。

"金融服务领域需要的是在复杂、严苛的环境中依然值得信赖的 AI，"Anthropic 金融服务业务董事总经理 Belinda Neal 表示。"Millennium 一直是 Claude 和 Claude Code 的早期采用者，我们与 Millennium 风险团队的合作将展示 AI 如何为 Millennium 风险经理的日常分析提供支撑。"

"Claude 能够对风险头寸进行推理分析，解释每日变动，并将所获知识延续到下一个问题中，"Anthropic 资产与财富管理业务负责人 Peter Nolan 表示。"Millennium 的风险经理将借助前沿智能能力提供自动化建议，以节省宝贵的时间。"
