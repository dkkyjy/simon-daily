# 一句话总结

Anthropic 的 Claude 模型现已在 Microsoft Foundry 正式可用，支持 Azure 环境部署与数据驻留。

# 主要观点

1. Claude 模型在 Microsoft Foundry 中正式推出，托管于 Azure。
2. 支持在 Azure 环境中运行，使用现有身份验证和计费控制。
3. 提供美国数据区域选项，满足数据驻留需求。
4. Anthropic 负责推理操作并作为数据处理方。
5. 初始提供 Claude Opus 4.8 和 Claude Haiku 4.5 模型。
6. 支持提示缓存和扩展思考等核心功能。
7. 涵盖编码、代理工作和复杂推理等用例。
8. 提供两种运行方式：Azure 托管或 Anthropic 托管。
9. 符合条件的 Microsoft 企业协议客户可抵扣 Azure 承诺额度。
10. 未来将逐步实现功能与模型在两种托管方式间的对等。

# 核心启示

1. 通过 Azure 账户即可直接使用 Claude 模型构建应用。
2. 利用现有 Azure 身份和网络控制，降低集成门槛。
3. 数据驻留选项满足企业合规与隐私需求。
4. 单一合并账单简化费用管理流程。
5. 企业协议客户可优化 Azure 预算使用效率。
