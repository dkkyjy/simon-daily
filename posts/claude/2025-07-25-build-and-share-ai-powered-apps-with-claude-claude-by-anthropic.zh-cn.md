今天，我们推出了直接在 Claude 应用中构建、托管和分享交互式 AI 驱动应用的能力。现在，开发者可以更快地迭代他们的 AI 应用，而无需担心为不断增长的受众进行扩展所带来的复杂性和成本。

### 构建并托管由 Claude 驱动的应用

这是我们所构建的：Claude 现在可以创建通过 API 与 Claude 交互的 artifact——将这些 artifact 转变为 AI 驱动的应用，其经济模式真正适合分享。

当有人使用你的 Claude 驱动应用时：

* 他们使用自己现有的 Claude 账户进行身份验证
* 他们的 API 使用量计入*他们自己*的订阅，而非你的
* 你无需为他们的使用付费
* 任何人都无需管理 API 密钥

Claude 编写真正的代码来编排复杂的 AI 功能。你可以查看它、修改它，并自由分享。

### 社区创意

早期用户已经使用交互式 artifact 构建了：

* **AI 驱动的游戏**，其中 NPC 能记住对话并根据玩家选择作出调整
* **学习工具**，可根据个人技能水平调整并提供个性化指导
* **数据分析应用**，用户上传 CSV 文件并用自然语言提出后续问题
* **写作助手**，帮助完成从脚本到技术文档的各种内容
* **代理工作流**，为复杂任务编排多次 Claude 调用

### 开始使用

通过在 Claude 应用中启用这项新的交互功能即可开始构建。只需描述你想要创建的内容，Claude 就会为你编写代码。

在你们共同协作的过程中，Claude 可以根据你的反馈调试和改进自己的代码。一旦你的应用准备就绪，你可以通过链接立即分享——无需任何部署流程。Claude 会处理提示工程、错误处理和编排逻辑等技术细节，让你完全专注于将创意变为现实。

**你可以做什么：**

* 在你的 artifact 中使用 Claude API
* 处理文件并使用 React 创建丰富的用户界面
* 查看、复刻并自定义任何 artifact

**当前限制：**

* 不支持外部 API 调用（尚不支持）
* 无持久化存储
* 仅限于基于文本的补全 API

此功能已面向 Free、Pro 和 Max 套餐用户开放 Beta 版本。
