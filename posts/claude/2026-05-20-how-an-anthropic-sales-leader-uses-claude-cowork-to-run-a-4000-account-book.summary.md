# ONE SENTENCE SUMMARY:
一位Anthropic销售主管利用Claude Cowork自动化数据整合与报告生成，将每周节省的数十小时用于战略决策和客户沟通。

# MAIN POINTS:
1. 销售主管负责4000个账户，涵盖中端科技与行业客户。
2. 日常工作包括每日客户通话准备、每周预测汇总和季度区域规划。
3. Claude Cowork通过日程任务自动扫描日历并预订会议室。
4. 客户通话前自动从BigQuery和Salesforce提取数据生成简报。
5. 每周预测报告节省约三小时，自动整合多系统数据。
6. 报告以领导层偏好的格式生成，周一仅需添加评论。
7. 季度账户评分项目一夜完成，传统需数百小时。
8. 评分维度包括AI机会、内部转型、行业匹配等五项指标。
9. 评分结果生成交互式仪表盘，支持按区域和账户深入分析。
10. 非技术用户可通过自然语言提示调整评分权重和维度。

# TAKEAWAYS:
1. 将重复性数据任务设为自动调度，消除记忆负担。
2. 把大型战略项目作为夜间自动化流程运行，释放团队时间。
3. 评分仪表盘将数据转化为可操作的销售工具，提升优先级排序效率。
4. 人类审核循环确保自动化输出符合业务判断标准。
5. 从标准化技能模板开始定制，快速匹配团队实际工作流程。
