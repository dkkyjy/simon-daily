**要点总结**：

* Claude 模型选择决定了模型的固定权重集合，即模型的整体能力范围。虽然可以为模型提供上下文或引导，但模型的整体知识库和能力是固定的。
* 努力不仅仅意味着“思考时间”。它控制 Claude 在完成你的请求时总体投入的工作量，包括读取的文件数量、使用的工具数量，以及在向你反馈之前所经历的步骤数。
* 对于常规任务选择较小的模型，对于更复杂或模糊的任务选择较大的模型。从每个模型的默认努力水平开始，然后根据你从事的工作类型而非单个任务来调整总体偏好。
* 如果 Claude 拥有所有相关上下文，已经明确尝试过但仍出错，说明需要选择更强大的模型。如果 Claude 因跳过某个文件、未运行测试或中途放弃重构而犯错，则应选择更高的努力水平。

## **Claude Code 的努力水平与模型选择**

Claude Code 提供了两种看似能“让答案更好”的设置：模型设置和努力水平。你可能会认为，像 Claude Fable 5 这样更大的模型会比 Claude Sonnet 提供更智能的输出，而更高的努力水平意味着 Claude 在回答前思考得更久。

第一个假设是正确的。根据行业标准基准测试，我们最大的模型能力更强。

但努力不仅仅意味着“思考时间”。努力水平控制着 Claude 在完成你的请求时总体投入的工作量。这确实包括模型思考的时间长度，但还包括：

* 它读取了多少文件；
* 它验证了多少内容；
* 以及它在向你反馈之前，在多步骤任务中推进了多少步。

在更高的努力水平下，Claude 会在返回结果之前采取更多上述操作（例如，读取文件、运行测试和双重检查）。在较低的努力水平下，它宁愿向你询问更多上下文，也不愿花费代币自行解决。
