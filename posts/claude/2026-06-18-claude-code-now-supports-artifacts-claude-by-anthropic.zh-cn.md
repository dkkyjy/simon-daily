# Claude Code 现已支持工件 | Anthropic 的 Claude

**日期：** 2026-06-18 00:00 UTC  
**链接：** https://claude.com/blog/artifacts-in-claude-code

---

从今天起，Claude Code 可以将工作进度捕获为工件，将 Claude Code 的工作转化为实时、可分享的可视化页面——包括 PR 走查、系统说明、仪表盘和发布检查清单——这些页面会在你的会话进行过程中自动更新。

一次 Claude Code 会话可以涵盖从调查事件到重构服务，再到分析数月数据的各种场景。工件将工作内容转化为任何人都可以打开并探索的网页，例如拉取请求走查、可筛选排序的仪表盘，甚至是一个随着工作完成而自动填充的发布检查清单。工件使得在共享工作上进行协作更加容易，因此团队可以花更多时间构建，减少花在沟通状态更新上的时间。

## **基于你会话中的上下文构建**

Claude Code 使用你会话的完整上下文来构建工件，包括你的代码库、你的连接器以及对话本身。一个单一的事件页面可以同时呈现来自代码的失败测试及其背后的函数、来自连接监控工具的错误峰值，以及你刚刚运行的会话中的根因分析。借助工件，你无需连接数据源或搭建基础设施。你只需请求一个页面，Claude Code 就会从已有的内容中构建出来。

## **实时页面，原位更新**

当 Claude Code 更新一个工件时，打开的页面会原位刷新，团队成员会在发布后立即看到更新。每次发布都是同一链接下的新版本，并带有版本历史记录，以便你随时恢复；还有一个画廊，让你可以浏览和管理所有已创建的工件。

根据我们的内部测试，我们最常见的用例之一就是调试。这些调试通常看起来是这样的：一名工程师在晨会前开始调查一个事件。Claude Code 处理日志并发布一个工件：时间线、可疑提交和错误率图表。她从页面标题处将链接分享给团队。到晨会开始时，随着调查的推进，Claude 已经重新发布了两次工件，整合了最新信息。有了工件，团队成员和利益相关者无需“听我们介绍代理发现了什么”，因为他们都在查看同一个视图，拥有相同的上下文。

## **对你的组织保持私密**

每个工件默认仅对其创建者可见。当你准备好后，可以从页面直接分享给你的团队成员和你的组织。工件仅可通过组织内经过身份验证的成员查看，并且不能公开。管理员通过组织级开关和基于角色的范围来控制访问，设置保留策略，并通过合规 API 获得组织范围内的可见性。

## **开始使用**

向你的会话请求一个工件——或者直接请求一些可视化内容，以下是一些按角色划分的想法：

* **法务/开源**：对每个依赖项进行许可证审计，直接从仓库中标记出 Copyleft 许可证。*“构建一个工件，列出每个第三方依赖项及其许可证，并标记任何 Copyleft 许可证。”*
* **隐私**：一张数据流图，显示个人信息在代码中被收集、存储和记录的位置。*“将代码库中我们触及个人数据的位置追溯到一个工件，供隐私审查使用。”*
* **安全**：发现结果链接到确切代码行，使修复明确无误。*“构建一个工件，包含本次审查中的身份验证发现，每个发现都链接到相关代码。”*
* **财务运营/平台财务**：从你的基础设施即代码中映射云资源和成本驱动因素。*“将 Terraform 中的云资源映射到一个工件，按服务分组，并标明主要的成本驱动因素。”*
* **软件工程师**：一个审查者能够真正跟进的 PR 或 Bug 走查，从差异比较及周围代码中提取。*“制作一个工件，走查这个 PR——差异比较、推理过程以及我测试的内容。”*
* **设计师与前端工程师**：一个屏幕的多种 UX 方向，每种都使用你的真实组件构建，以便你选择的那个可以直接发布。*“给我一个工件，包含这个注册表单的 5 种 UX 变体，均使用我们的组件库构建。”*
* **高级工程师与架构师**：一张服务实际如何组合的地图，从真实的导入图中绘制，而非白板。*“将支付服务如何组合在一起映射到一个工件，从代码出发。”*
* **SRE 与值班人员**：一个事件页面，随着调查的深入而增长，并最终成为事后总结。*“将此次事件转换为一个工件——时间线、可疑提交、来自监控的错误峰值——并在排查过程中重新发布。”*
* **工程经理**：一张实际交付内容的页面，从已合并的 PR 中构建。*“构建一个工件，包含本周我团队中从 PR 合并的内容，按项目分组。”*

Claude Code 构建页面并为你提供一个链接。在你的浏览器或桌面应用中打开它，从页面标题处分享——更新会自动发布到同一个 URL。

## **可用性**

工件目前以 Beta 版本提供给 Claude Team 和 Enterprise 组织，可通过 Claude Code CLI 和桌面应用使用，页面可在任何浏览器中查看。
