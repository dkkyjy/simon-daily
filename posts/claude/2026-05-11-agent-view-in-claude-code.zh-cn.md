# Claude Code 中的代理视图

            **日期：** 2026-05-11 00:00 UTC
            **链接：** https://claude.com/blog/agent-view-in-claude-code

            ---

            今天我们推出 Claude Code 中的代理视图：一个管理所有 Claude Code 会话的集中位置。

在此之前，当并行运行代理时，您可能不得不管理多个终端标签页、一个 tmux 网格，以及一个过载的心理记录，记录着接下来需要处理什么。

借助 Claude Code 中的代理视图，您可以启动新代理、将其发送到后台，并且仅在 Claude 需要您时介入。一目了然地查看哪些代理正在等待您、哪些仍在工作、哪些已完成，从而轻松同时引导多个代理。

## 工作原理

代理视图改进了在 CLI 中可视化和交互 Claude Code 会话的方式。

### 同时查看所有内容

从任何会话按左箭头键，或在终端中运行 `claude agents` 以打开代理视图。每一行显示会话、是否需要您的输入、其最后响应的内容，以及您上次与之交互的时间。

### 无需离开即可预览和回复

选择一个会话以预览最后一轮交互。如果某个会话正在等待决策，请内联回答，该会话将恢复运行。按回车键直接附加到您想要探索完整记录的会话。

### 将任何内容置于后台

最后，用户可以使用 `/bg` 将任何现有会话添加到代理视图，或完全跳过前台，使用 `claude --bg [task]` 启动一个新会话。

## 开发者如何使用代理视图

以下是我们从早期用户中看到的一些模式：

* **扩展并发会话数量：** 同时发起多个想法，每个可选配技能，然后返回一个可供审查的拉取请求列表。
* **管理长时间运行的代理：** PR 守护程序、仪表板更新程序和其他循环任务会在列表中显示其下一次运行时间。
* **在独立会话之间导航：** 当您在一个会话中时，按左箭头键，启动一个相关任务或快速代码库问题，然后按右箭头键返回您正在做的事情。预览会在答案出现时显示。
* **查看已交付的内容：** 每行的状态指示器加上预览中的标题，使扫描哪些会话产生了 PR 变得容易。

## 入门指南

代理视图今天作为研究预览版在 Pro、Max、Team、Enterprise 和 Claude API 计划中提供。通过运行 `claude agents` 选择加入。适用常规速率限制。请参阅[文档](https://code.claude.com/docs/en/agent-view)了解更多信息。
