今天，我们推出了一项新功能：您可以直接在 Claude 应用中构建、托管和分享交互式 AI 驱动应用。现在，开发者可以更快地迭代他们的 AI 应用，而无需担心为不断增长的用户群体进行扩展所带来的复杂性和成本。

### 构建和托管 Claude 驱动的应用

这是我们构建的功能：Claude 现在可以创建通过 API 与 Claude 交互的 artifact——将这些 artifact 转变为 AI 驱动的应用，其经济模式真正适用于分享。

当有人使用您的 Claude 驱动应用时：

* 他们使用现有的 Claude 账户进行身份验证
* 他们的 API 使用量计入*他们自己*的订阅，而不是您的
* 您无需为他们的使用付费
* 无需任何人管理 API 密钥

Claude 会编写真实的代码来编排复杂的 AI 功能。您可以查看、修改并自由分享这些代码。

### 社区创意

早期用户已经使用交互式 artifact 构建了：

* **AI 驱动的游戏**，其中包含能记住对话并适应玩家选择的 NPC
* **学习工具**，可根据个人技能水平进行调整并提供个性化辅导
* **数据分析应用**，用户可上传 CSV 文件并用自然语言提出后续问题
* **写作助手**，可帮助完成从剧本到技术文档的各种内容
* **代理工作流**，可编排多个 Claude 调用来处理复杂任务

### 开始使用

在 Claude 应用中启用这一新的交互功能即可开始构建。只需描述您想要创建的内容，Claude 就会为您编写代码。

在您与 Claude 协作的过程中，Claude 可以根据您的反馈调试和改进自己的代码。应用准备就绪后，您可以通过链接即时分享——无需任何部署流程。Claude 会处理诸如提示工程、错误处理和编排逻辑等技术细节，让您能够完全专注于将创意变为现实。

**您可以做到：**

* 在 artifact 中使用 Claude API
* 处理文件并使用 React 创建丰富的用户界面
* 查看、分叉和自定义任何 artifact

**当前限制：**

* 不支持外部 API 调用（暂未开放）
* 无持久化存储
* 仅限于基于文本的完成 API

此功能现已面向免费版、专业版和 Max 版计划用户提供 Beta 版本。
