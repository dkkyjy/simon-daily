## 将 Claude Code 添加到您的计划中

管理员可以完全灵活地根据个人用户需求和组织角色分配标准席位或高级席位。高级席位让用户可以同时使用 Claude 和 Claude Code，从而在整个开发生命周期中与 Claude 协作。

例如，开发者可以通过与 Claude 的交互式聊天来研究不熟悉的框架，然后在终端中使用 Claude Code 实现生产就绪的代码。他们可以在 Claude 对话中探索架构方法并评估权衡，然后切换到 Claude Code 来构建所选架构。

## 灵活定价，成本可预测

Claude 席位包含足够一个典型工作日使用的用量，但当您的团队需要更多智能能力和与 Claude 进行额外对话时——管理员可以为个人用户启用额外用量，按标准 API 费率计费。管理员可以控制用户通过额外用量花费的最大金额，从而确保用户获得灵活性，而管理员获得可预测的账单。

这种方法提供了一种随着 Claude 扩展的简单方式，同时在整个过程中提供集中计费、管理和企业级管理控制。

## 管理员控制与管理

我们构建了全新的全面控制功能，为组织提供所需的可见性和管理能力，使员工能够高效地使用 Claude 工作。

* **自助席位管理**：通过管理面板购买新席位、直接管理席位分配并为用户配置权限。
* **精细费用控制**：在组织和用户级别设置支出上限，以控制预算，同时为关键项目保留灵活性。
* **用量分析**：在 Claude 中查看 Claude Code 分析数据，包括接受的代码行数、建议接受率和使用模式等指标。
* **托管策略设置**：在所有 Claude Code 用户中部署并强制实施符合内部策略的设置，包括工具权限、文件访问限制和 MCP 服务器配置。

## 合规 API

企业组织现在可以通过我们的新合规 API 更好地满足监管要求。合规团队无需手动导出和定期审查，即可实时以编程方式访问 Claude 的用量数据和客户内容，从而构建持续监控和自动化策略执行系统。

管理员可以将 Claude 数据集成到现有的合规仪表板中，自动标记潜在问题，并通过选择性删除功能管理数据保留。这为组织提供了扩展 AI 采用同时满足监管义务所需的可见性和控制力。
