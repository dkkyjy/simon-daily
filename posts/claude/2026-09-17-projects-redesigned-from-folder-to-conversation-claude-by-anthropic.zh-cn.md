# 项目重新设计：从文件夹到对话 | Claude by Anthropic

**日期：** 2026-09-17 00:00 UTC
**链接：** https://claude.com/blog/projects-redesigned

---

过去，管理一次构建过程中的多个会话需要您分割工作、协调交接，并将结果重新整合。现在，在 Claude Code 项目中，您只需描述需要完成的任务，Claude 就会管理工作。

Claude 会界定请求范围、委派工作、协调并行线程、审查输出，并组装最终成果。您可以全程引导进度，甚至从手机上操作，在您离开电脑后它仍会继续工作。

例如，您可以配置一个项目，设定目标是降低应用结账流程的 p75 延迟。然后让 Claude 对每个端点进行性能分析、测试优化方案，并在并行线程中提交 PR。或者，您可以连接 API、Web 和移动端仓库，设定目标是淘汰已废弃的 v1 端点。Claude 会为每个仓库创建线程以迁移调用方、运行测试、提交 PR，然后告诉您哪些需要优先合并。

从今天起，更新后的项目将以 beta 版本向部分使用 Claude Code 云端会话且未在网页或桌面端拥有现有项目的 Claude Pro 和 Max 订阅用户开放。

在接下来的几周里，我们将向更多使用这些套餐的 Claude Code 用户扩展访问权限。随后，更新后的项目将在 Claude 的所有套餐以及 Team 和 Enterprise 套餐中推出。如果您使用的是 Pro 或 Max 套餐但尚未获得访问权限，可以加入[等待列表](https://claude.com/form/projects)。

Pro 和 Max 套餐上的现有项目将继续按当前方式运行。随着推广扩展到聊天和 Cowork，我们将对它们进行升级。

## 线程执行工作，Claude 指挥调度

项目包含执行工作的线程和指挥它们的协调器。

当您启动一个项目时，您需要选择目标以及仓库或上下文。Claude 会首先建议可以立即接手的工作。您可以配置项目的云端环境、连接器、插件、指令和模型。

您可以在项目主聊天中监控和引导进度，也可以深入每个单独线程以检查和引导细节。您可以像向幕僚长交代工作一样向项目中的 Claude 交代任务，它会将工作路由到新线程或现有线程。

Claude 还会检查并跟进工作进展。连接仓库后，线程会提交拉取请求并运行您的测试；处理文档时，它会阅读文档并起草内容。

在底层，每个线程都是一个 Claude Code 云端会话，在自己的分支和仓库副本上工作。协调器会保持工作有序，但如果任何线程处理相同代码，重叠部分将像任何其他 PR 一样作为合并冲突解决。

每个线程还可以根据需要利用子代理、循环和工作流进一步分割其委派的工作，从而加快大型任务的完成速度。

## 上下文随时间积累

项目专为长时间运行或代理式工作流设计：耗时超过一次回复且包含多个部分的工作。

随着时间推移，Claude 会了解更多项目细节并将其应用于工作。每个线程现在都会为共享记忆增添内容并从中汲取信息，减少了对复杂提示工程的需求。

例如，Claude 可以记住发布已改到周五、为何取消导出功能，或在修改计费服务前应与谁沟通。

*一周内的一个项目。每个请求在右侧打开一个线程；记忆、决策和结果在下方不断积累。*

Claude 还会记住您的工作和沟通风格。您可以要求它调整检查频率、启动新线程的频率，或每次更新的详细程度。

除了记忆功能外，项目现在还包括一个库，用于收集您添加的文件和 Claude 生成的成果。这使得查找相关材料更加容易，也让新工作能够建立在过去的努力之上。

## 后续计划

项目可以同时运行多个线程，每个线程都是一个完整的 Claude Code 会话。因此，项目可能更快地达到使用限制。您可以查看项目特定使用情况，并为协调器聊天以及工作线程选择使用的模型和努力程度。

线程目前在云端运行；在您的机器上与您本地工具和代码一起运行并在您的网络后面运行的功能即将推出。
