# ONE SENTENCE SUMMARY:
Claude 推出 Skills 功能，允许用户创建可复用的指令、脚本和资源包，以提升特定任务的执行效率。

# MAIN POINTS:
1. Skills 是包含指令、脚本和资源的文件夹，Claude 按需加载。
2. Skills 仅在相关任务时自动调用，保持 Claude 快速响应。
3. Skills 具有可组合、可移植、高效和强大的特性。
4. Skills 支持跨 Claude 应用、Claude Code 和 API 使用。
5. 用户可通过“skill-creator”技能交互式创建自定义技能。
6. 开发者可通过 Messages API 和 `/v1/skills` 端点管理技能。
7. Skills 需要代码执行工具（Code Execution Tool）提供安全运行环境。
8. 团队可通过版本控制共享技能，支持插件市场安装。
9. 官方提供 Excel、PPT、Word 和 PDF 等预建技能。
10. 使用 Skills 需注意数据安全，仅从可信来源获取。

# TAKEAWAYS:
1. Skills 让 Claude 成为特定领域的专家，无需手动切换模式。
2. 企业可打包工作流和品牌规范，实现标准化自动化。
3. 开发者能通过 API 精细控制技能版本和调用逻辑。
4. 技能可包含可执行代码，弥补纯语言模型在计算上的不足。
5. 未来将简化创建流程并支持企业级跨团队部署。
