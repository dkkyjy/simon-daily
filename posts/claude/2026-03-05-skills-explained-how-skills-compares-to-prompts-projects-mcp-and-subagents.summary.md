# 一句话摘要

Claude的Skills、提示词、Projects、子代理和MCP是互补的构建模块，可组合用于创建强大的智能代理工作流程。

# 主要观点

1. Skills是包含指令、脚本和资源的文件夹，Claude在相关任务时动态加载。
2. 提示词是对话中的自然语言指令，临时且反应式，不跨会话持久。
3. Projects是自包含工作区，拥有200K上下文窗口和持久知识库。
4. 子代理是具有独立上下文窗口和工具权限的专门AI助手。
5. MCP是连接AI应用与外部工具和数据源的通用标准协议。
6. Skills使用渐进式披露，先加载元数据，再按需加载完整指令。
7. 当重复使用相同提示词时，应将其转换为Skills以节省时间。
8. Projects提供背景知识，Skills提供程序性知识，两者互补。
9. 子代理可访问和使用Skills，实现专门化与可移植专业知识的结合。
10. MCP负责数据连接，Skills负责教授如何使用数据。

# 要点

1. 将重复提示词转换为Skills，确保跨会话一致执行。
2. 使用Projects为特定项目提供持久上下文和知识库。
3. 结合MCP和Skills：MCP连接数据源，Skills教授处理流程。
4. 子代理可同时处理不同任务，保持主会话专注。
5. 根据需求选择工具：一次性任务用提示词，重复流程用Skills。
