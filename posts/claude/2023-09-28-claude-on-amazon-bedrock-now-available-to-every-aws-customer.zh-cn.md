# Claude 现已在 Amazon Bedrock 上对所有 AWS 客户开放

            **日期：** 2023-09-28 00:00 UTC
            **链接：** https://claude.com/blog/amazon-bedrock-general-availability

            ---

            Claude 现已在 [Amazon Bedrock](https://aws.amazon.com/bedrock/claude/) 上全面上市，这是一项完全托管的服务，为 Amazon Web Services (AWS) 客户提供对基础模型和构建生成式 AI 应用工具的安全云访问。

这意味着每位 AWS 客户现在都可以使用 Claude 进行构建，并且很快将获得一系列令人兴奋的新体验——包括 [Amazon Bedrock 的 Agents](https://aws.amazon.com/blogs/aws/preview-enable-foundation-models-to-complete-tasks-with-agents-for-amazon-bedrock/)，我们的团队在开发该功能中发挥了关键作用。

目前处于预览阶段的 Amazon Bedrock 的 Agents 可以使用流行的 [AWS Lambda](https://aws.amazon.com/lambda/) 函数编排和执行 API 调用。通过这一功能，Claude 可以扮演更广泛的代理角色，理解用户请求、将复杂任务分解为多个步骤、进行对话以收集更多细节、查找信息并采取行动来满足请求。例如，一个使用 Claude 构建的提供聊天助手的电子商务应用，不仅可以查询产品库存——它实际上可以帮助客户更新订单、进行换货以及查找相关的用户手册。

我们最近还分享过，我们将通过该服务提供 Claude 模型的安全定制和微调。这项技术利用 AWS 客户的专业知识和专有数据优化 Claude 的性能，以驱动更相关的结果，同时限制有害输出的可能性。

Claude 在 Amazon Bedrock 上的全面上市推进了我们在帮助企业负责任地整合变革性 AI 方面的工作。在未来几个月内，我们将宣布更多应用层解决方案，帮助组织从 Claude 中获得最大价值。

自今年四月宣布与 Amazon Bedrock 集成以来，Claude 已获得包括 **LexisNexis**、**Lonely Planet** 和 **Ricoh USA** 在内的领先企业的强烈自发采用。

顶级资产管理公司 **Bridgewater Associates** 也在利用我们最先进的模型 Claude 创建一种新颖的、由 AI 驱动的投资分析师助手，以支持其团队中的初级成员。

Bridgewater 致力于以基本方式理解经济，揭示驱动全球市场的永恒且普遍的因果关系链。为了揭示这些关系，Bridgewater 的分析师花费大量时间理解并系统性地对假设进行压力测试，通常通过编写代码来完成。

例如，分析师可能会通过创建关键数据可视化（包括图表和表格）来调查美联储收紧对大宗商品价格的影响，以测试假设、综合发现并分享其研究。Bridgewater 的团队正在与 Amazon Bedrock 上的 Claude 合作，使这一过程更加高效和可扩展。

"Claude 是我们即将在 Amazon Bedrock 上推出的投资分析师助手背后的高能力模型，它能够接收基本指令、生成 Python 代码、处理错误并输出图表和表格，就像第一年或第二年的分析师一样，"Bridgewater Associates 的 CTO - AI/ML Aaron Linsky 表示。"当投资分析师助手不确定要采取什么路径时，它还会在执行之前提出澄清性问题。"

Linsky 继续说道："我们的投资分析师助手还支持原地编辑代码，这让我们的分析师可以选择何时利用 Claude，或者何时自己进行简单修改。这实现了更快的循环，并让投资分析师助手能够基于更新后的代码库进行迭代；这是许多其他聊天式助手根本不提供的功能。"

**开始使用 Amazon Bedrock 上的 Claude**
我们很高兴为更多 AWS 社区成员提供 Claude 的访问权限，并贡献我们技术团队的专业知识，以在 Amazon Bedrock 服务上实现负责任的创新。立即开始使用 [Amazon Bedrock 上的 Claude](/amazon-bedrock)。
