# 一句话总结

Claude Agent SDK 通过赋予代理计算机访问权限，使其能像人类一样迭代工作，从而构建通用型自主代理。

# 主要观点

1. Claude Agent SDK 源自 Claude Code SDK，现已更名以反映更广泛的代理愿景。
2. 核心设计原则是给代理一台计算机，使其能像人类一样工作。
3. 代理遵循反馈循环：收集上下文 → 采取行动 → 验证工作 → 重复。
4. 文件系统作为上下文工程，允许代理使用 bash 脚本搜索信息。
5. 语义搜索更快但准确性较低，建议优先使用代理式搜索。
6. 子代理支持并行化和隔离上下文窗口，提高处理效率。
7. 压缩功能自动总结历史消息，防止上下文窗口溢出。
8. 工具是代理执行任务的主要构建块，应精心设计。
9. Bash 和代码生成提供灵活、精确且可复用的执行能力。
10. MCP 提供标准化外部服务集成，无需编写自定义代码。

# 收获

1. 优先使用代理式搜索而非语义搜索，除非需要更快结果或更多变体。
2. 利用子代理进行并行任务处理，并保持上下文窗口隔离。
3. 为代理提供具体规则和视觉反馈，使其能自我验证和改进。
4. 设计工具时注重上下文效率，使其成为代理的主要行动选项。
5. 通过分析失败案例并优化工具和规则来迭代改进代理性能。
