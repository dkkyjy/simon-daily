# 一句话总结

Claude Code 伦敦大会宣布了企业级托管代理的新功能，让编程回归“从想法到运行”的纯粹体验。

# 主要观点

1. 编程正回归“从想法到运行”的即时体验，如同使用计算器。
2. Claude 托管代理现支持自托管沙箱和 MCP 隧道功能。
3. 自托管沙箱将工具执行置于用户控制的基础设施中。
4. MCP 隧道允许代理安全访问私有网络内的服务器。
5. 代理编排、上下文管理和错误恢复仍由 Anthropic 处理。
6. 文件和数据不会离开用户的安全边界。
7. 用户可控制计算资源大小和运行时镜像。
8. MCP 隧道无需入站防火墙规则或公共端点。
9. 该功能适用于托管代理和 Messages API。
10. 下一站 Code w/ Claude 将于 6 月 5-6 日在东京举行。

# 收获

1. 企业可安全部署 AI 代理，同时保持对数据和基础设施的控制。
2. 自托管沙箱解决了企业对安全性和合规性的核心担忧。
3. MCP 隧道简化了私有网络内 AI 代理的集成。
4. 编程复杂性正在降低，使开发者能更专注于创意实现。
5. 通过将编排与执行分离，实现了安全与灵活性的平衡。
