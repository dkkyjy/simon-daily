# ONE SENTENCE SUMMARY:
Claude Code通过本地化、无索引的智能体搜索在大型代码库中高效导航，其性能取决于围绕模型构建的扩展层配置。

# MAIN POINTS:
1. Claude Code像工程师一样遍历文件系统、读取文件和搜索，无需建立代码库索引。
2. 基于RAG的AI工具在大规模场景下因索引更新滞后而失败。
3. 智能体搜索避免了嵌入管道问题，但依赖良好的起始上下文。
4. 扩展层（CLAUDE.md、钩子、技能、插件、MCP）比模型本身更重要。
5. CLAUDE.md文件提供项目级和子目录级上下文，需保持精简。
6. 钩子用于自动化行为和持续改进，而非仅阻止错误。
7. 技能按需加载专业知识，避免每次会话都膨胀上下文。
8. LSP集成让Claude按符号而非字符串搜索，提高导航精度。
9. 子代理将探索与编辑分离，提高复杂任务的效率。
10. 成功的部署需要专用团队负责配置管理和组织推广。

# TAKEAWAYS:
1. 优先配置精简的分层CLAUDE.md文件，而非一次性加载所有上下文。
2. 在子目录而非仓库根目录启动Claude，以自动加载相关上下文。
3. 每三到六个月审查配置，以适应模型演进并移除过时的限制。
4. 为Claude Code管理指定负责人或团队，集中推广最佳实践。
5. 先建立基础扩展层（CLAUDE.md、钩子），再构建MCP和高级功能。
