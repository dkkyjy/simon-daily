# Claude 现已正式在 Microsoft Foundry 中推出

            **日期：** 2026-06-29 00:00 UTC
            **链接：** https://claude.com/blog/claude-in-microsoft-foundry

            ---

            自今日起，Claude 模型已在 Microsoft Foundry 中正式推出，并托管于 Azure 平台。Claude 可在您的 Azure 环境中运行，并沿用您的团队已在使用中的身份验证、计费及治理控制机制。您可以选择推理处理的运行地点，包括为有数据驻留要求的团队提供美国数据区域。Anthropic 负责运行推理服务，并担任数据处理方。

### **通过您的 Azure 账户使用 Claude 进行构建**

首先，Claude Opus 4.8 和 Claude Haiku 4.5 现已在 Messages API 中提供，具备提示缓存和扩展思考等核心功能，可支持从编码和智能体工作到复杂推理等多种使用场景。我们将持续扩展 Foundry 中可用的功能。

Microsoft Foundry 中的 Claude 是 Azure 原生服务，可与您现有的 Azure 身份、网络和治理控制机制配合使用。您将收到一份合并账单，对于符合条件的 Microsoft 企业协议客户，使用 Claude 将计入 Microsoft Azure 承诺用量。

### **在 Azure 上运行由 Anthropic 运营的 Claude**

在 Microsoft Foundry 中有两种运行 Claude 的方式。当需要在您的 Azure 环境中运行时，请选择 *托管于 Azure*，该选项提供 Azure 身份验证、计费、治理机制以及美国数据区域。当您需要完整的 API 功能集或尚未在 Azure 上提供的模型时，请选择 *托管于 Anthropic*（即之前的 Foundry 预览版）。随着时间的推移，我们的目标是让托管于 Azure 的版本与 Anthropic 托管的版本在功能和模型上实现一致。

### **开始使用**

Microsoft Foundry 中的 Claude 现已正式推出。要开始使用，请打开 [Microsoft Foundry 中的 Claude](https://learn.microsoft.com/en-us/azure/foundry/foundry-models/how-to/use-foundry-models-claude?tabs=python) 或浏览[文档](https://platform.claude.com/docs/en/build-with-claude/claude-in-microsoft-foundry)。
