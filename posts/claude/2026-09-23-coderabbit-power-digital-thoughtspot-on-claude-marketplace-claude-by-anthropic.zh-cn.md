# CodeRabbit、Power Digital、ThoughtSpot 亮相 Claude Marketplace | Anthropic 旗下 Claude

**日期：** 2026-09-23 00:00 UTC
**链接：** https://claude.com/blog/how-coderabbit-power-digital-and-thoughtspot-scale-with-snowflake-and-vercel-on-claude-marketplace

---

使用 Claude 构建产品的公司也依赖其他软件来完成工作，例如使用 Snowflake 存储和分析数据，或使用 Vercel 运行应用。Claude Marketplace 让拥有 Anthropic 承诺预算的公司可以将其中一部分用于团队已经依赖的工具，因此一项投资可以覆盖团队日常使用的更多内容，而无需新的预算申请。

以下是 CodeRabbit、Power Digital 和 ThoughtSpot 如何利用 Claude Marketplace 扩大与 Vercel 和 Snowflake 合作的方式。

## **Power Digital 在 Snowflake 上运行客户数据**

[Power Digital](https://powerdigitalmarketing.com/) 是一家营销机构，构建了 Nova 平台供其团队和客户使用。客户通过 Nova 连接其数据，Nova 运行在 Snowflake 上，为报告、内部工具和提升营销绩效的模型提供动力。Snowflake 让 Power Digital 能够快速为每个客户设置安全的数据环境，并通过 Snowflake Cortex AI 在其现有治理框架内直接在该数据上运行 Claude 等模型。

Claude 现已贯穿 Power Digital 的各个方面，从客户交付物和财务运营到其自身产品中构建的模型。使用人数已从一月份的约 12 名工程师增长到今天的 800 多人。

作为 Snowflake 五年的客户，Power Digital 今年通过 Claude Marketplace 扩大了其 Snowflake 承诺。由于支出来自已批准的预算，其团队可以快速扩展 Snowflake 的使用。

> “*我们将许多运营都集中在 Claude 上，并在公司范围内管理数百个工具。Claude Marketplace 让我们将存放客户数据的 Snowflake 纳入同一个 Anthropic 承诺中。在我们询问时，合同已经在起草中了，”* Power Digital 创新高级副总裁 John Saunders 表示。

## **ThoughtSpot 在 Snowflake 上构建 AI 分析**

[ThoughtSpot 的代理分析平台](https://www.thoughtspot.com/) 为业务用户提供决策就绪的洞察，基于公司的语义和上下文层，通过确定性和可验证的查询提供可信的答案。

为了驱动其 AI 功能，ThoughtSpot 使用 Snowflake 的推理 API 直接在 Snowflake 内的客户数据上运行 Claude 等模型，将数据、业务上下文、访问控制和 AI 保持在同一个生态系统中。ThoughtSpot 将其对 Snowflake 推理 API 的购买应用于其现有的 Anthropic 承诺，因此其产品团队可以开始使用已预留预算的 API 进行构建。

> “*我们的代理分析平台运行在 Claude 上，因此通过 Claude Marketplace 购买 Snowflake 的推理 API 是自然而然的选择。我们应用了已经做出的承诺，因此购买来自我们已批准的预算，”* ThoughtSpot 产品管理高级副总裁 Francois Lopitaux 表示。

ThoughtSpot 也在与 Claude 一同成长。其 AI 分析师 [Spotter](https://claude.com/connectors/thoughtspot-spotter) 可作为 Claude 的连接器使用，因此用户可以在不离开 Claude 的情况下分析数据、构建和探索仪表板，并执行操作。

> “*Spotter，我们的 AI 分析师，已经在 Claude 的连接器目录中，我们希望自己通过市场销售我们的代理产品，这样我们的客户就可以完全做到我们刚刚做的事情，”* Lopitaux 补充道。

## **CodeRabbit 在 Vercel 上运行其编码代理**

[CodeRabbit](https://claude.com/platform/marketplace/coderabbit) 基于 Claude 构建，以验证 AI 生成的代码，使工程团队能够控制交付内容。其代理编写和测试代码，因此需要一个安全的地方来运行它。[Vercel Sandbox](https://vercel.com/sandbox) 在具有自己文件系统和网络的隔离 Linux 微虚拟机中运行每个代理的代码，远离其他任务和 CodeRabbit 自身的系统。[Vercel Workflows](https://vercel.com/workflows) 协调工作，使长时间运行的任务可以暂停、恢复和完成，而不会遇到时间限制。

当 CodeRabbit 的工程和产品领导层希望从按量付费的 Vercel 计划转向承诺计划时，该公司从其最近扩展的 Anthropic 承诺中资助了升级。由于预算已经批准，交易在一周内完成。

> “*对我们要来说，价值在于灵活性：用我们已经批准的预算支持我们的工程师信任的工具。我们能够将同样的价值直接交付给 Claude Marketplace 上的客户，这是最终的共赢，”* CodeRabbit 全球合作伙伴关系负责人 Blair Pierson 表示。

## **Snowflake 和 Vercel 与基于 Claude 构建的客户共同成长**

对于像 [Snowflake](https://claude.com/platform/marketplace/snowflake) 和 [Vercel](https://claude.com/platform/marketplace/vercel) 这样的卖家，Claude Marketplace 是一种接触已经在 Claude 上构建的客户的途径，并为拥有 Anthropic 承诺的公司提供更快的购买方式。

> “*当 AI 以数据和上下文为基础时，它是值得信赖的。Claude 直接在 Snowflake 中运行，因此我们客户的治理、上下文和权限已经到位，作为第一天可信洞察的基础。Claude Marketplace 使得扩展这种关系变得容易，让客户可以将 Anthropic 承诺的一部分直接用于 Snowflake 的 AI 工作负载。这是我们与 Anthropic 在共享账户中共同成长的方向，”* Snowflake 企业技术合作伙伴关系总监 Omar Bed-Mohamed 表示。

> “*Claude Marketplace 使像 CodeRabbit 这样的客户能够快速采购 Vercel 的代理基础设施并扩展其平台。我们期待帮助为每个在 Claude 上构建的公司运行代理，”* Vercel 产品合作伙伴关系负责人 Zack Ciesinski 表示。

## **通过 Claude Marketplace 购买**

使用 Claude 构建通常意味着引入你的团队已经依赖的数据平台和基础设施。[Claude Marketplace](https://claude.com/marketplace) 让客户可以将 Anthropic 承诺的一部分用于 Vercel、Snowflake 等合作伙伴，因此团队可以将更少的时间花在采购上，更多的时间花在构建上。

以这种方式使用你的 Anthropic 承诺目前处于有限预览阶段。如果你有一个，请与你的账户团队交谈或[提交请求](https://claude.com/marketplace-contact-sales)以查看你是否符合条件。[了解更多关于 Claude Marketplace 的信息](https://claude.com/blog/claude-marketplace)。
