它包含一个用于管理多个会话的新侧边栏、一个用于排列工作区的拖放布局、一个集成的终端和文件编辑器，以及性能和体验改进。

## 全新的桌面体验

对于许多开发者来说，代理式工作的形态已经改变。你不再只是输入一条提示然后等待。你会在一个仓库中启动重构，在另一个仓库中修复 bug，在第三个仓库中编写测试，并在结果返回时逐一检查，在出现偏差时进行引导，在发布前审查差异。

新应用专为代理式编码的实际感受而设计：许多任务同时进行，而你坐在指挥者的位置上。

## 并行运行会话

新的侧边栏将所有活跃和最近的会话集中到一处。在多个仓库之间启动工作，并在结果返回时切换查看。

你可以按状态、项目或环境进行筛选，或者按项目分组侧边栏，以便更快地查找和恢复会话。当某个会话的 PR 合并或关闭时，它会自动归档，使侧边栏只关注正在进行的任务。

当你在任务进行中需要提问时，可以打开侧边聊天（⌘ + ; 或 Ctrl + ;）来分支出一个对话。侧边聊天会从主线程中获取上下文，但不会向主线程添加任何内容，从而避免误导你的任务。

## 无需离开应用即可审查和发布

重新设计将更多常用工具直接集成到应用中，让你无需切换到编辑器即可审查、调整和发布 Claude 的工作成果：

* **集成终端**：在会话旁边运行测试或构建。
* **应用内文件编辑器**：打开文件，直接进行定点编辑，并保存更改。
* **更快的差异查看器**：针对大型变更集进行了性能重构。
* **扩展预览**：在应用内打开 HTML 文件或 PDF，同时还可以在预览面板中运行本地应用服务器。

每个面板都可拖放。将终端、预览、差异查看器和聊天按照你习惯的方式排列成网格。

## 适配你的技术栈

桌面应用现已与 CLI 插件保持对等。如果你的组织集中管理 Claude Code 插件，或者你本地自行安装了插件，它们在桌面应用中的工作方式与在终端中完全相同。

你仍然可以在本地或云端运行会话。SSH 支持现已扩展到 Mac 和 Linux，因此你可以从任一平台将会话指向远程机器。

## 根据你的工作方式自定义

三种视图模式——详细、常规和摘要——让你可以将界面从完全透明地显示 Claude 的工具调用调整为仅显示结果。新的键盘快捷键支持会话切换、创建和导航；按下 `⌘ + /`（或 `Ctrl + /`）即可查看完整列表。新增的使用量按钮可让你一目了然地查看上下文窗口和会话使用情况。

在底层，应用针对可靠性和速度进行了重构，现在能够流式传输 Claude 生成的结果。

## 开始使用

重新设计的桌面应用现已面向所有 Pro、Max、Team 和 Enterprise 计划的 Claude Code 用户开放，也可通过 Claude API 使用。

[下载应用](https://claude.com/download)，如果你已安装，请更新并重启。查看[文档](https://docs.claude.com/claude-code)了解更多信息。
