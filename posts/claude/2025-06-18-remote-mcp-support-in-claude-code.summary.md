# 远程MCP支持在Claude Code中

**日期：** 2025-06-18 00:00 UTC
**链接：** https://claude.com/blog/claude-code-remote-mcp

---

今天，我们宣布在Claude Code中支持远程MCP服务器。连接您喜欢的工具和数据源，个性化您的编码体验，无需管理本地服务器。

### **将Claude Code用作您的开发主界面**

Claude Code可以访问MCP服务器公开的工具和资源，使其能够从您的第三方服务（如开发工具、项目管理系统和知识库）中获取上下文，并在这些服务中执行操作。

您可以将Claude Code与任何远程MCP服务器集成，不断增长的服务器生态系统意味着新功能正在不断上线。

例如，通过将Claude Code与Sentry MCP服务器集成，您可以访问Sentry中的错误和问题。然后，您可以在不离开终端的情况下，利用这些问题的上下文进行调试。

您还可以将Claude Code与Linear MCP服务器集成，以处理您活跃项目的上下文。

“Linear的MCP集成将Linear项目和问题直接带入Claude Code，”Linear工程主管Tom Moor分享道。“借助来自Linear的结构化实时上下文，Claude Code可以提取问题详情和项目状态——工程师现在可以在规划、编写代码和管理问题之间保持流畅。更少的标签页，更少的复制粘贴。更好的软件，更快。”

### **无缝连接，维护成本极低**

远程MCP服务器提供了比本地服务器更低的维护替代方案：只需将供应商的URL添加到Claude Code——无需手动设置。供应商负责更新、扩展和可用性，因此您可以专注于构建，而不是管理服务器基础设施。

Claude Code还支持远程MCP服务器的原生OAuth认证，确保与您现有账户的安全连接。只需一次认证到您的服务器，Claude Code会处理其余部分——无需管理API密钥或存储凭据。

### **开始使用**

远程MCP服务器支持现已可在Claude Code中使用。查看[文档](https://docs.anthropic.com/en/docs/claude-code/mcp)开始使用，或探索我们的[MCP目录](http://anthropic.com/partners/mcp)以获取推荐的服务器。
