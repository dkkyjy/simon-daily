# ONE SENTENCE SUMMARY:
生产级AI代理通过MCP协议连接云系统，实现可扩展、可移植且语义丰富的集成，这是当前主流方案。

# MAIN POINTS:
1. 代理连接外部系统有三种方式：直接API调用、CLI和MCP。
2. 直接API调用适合少量集成，但规模化时面临M×N集成问题。
3. CLI在本地环境快速轻量，但无法触及移动端或云端平台。
4. MCP提供标准化协议层，支持认证、发现和丰富语义。
5. MCP SDK月下载量已从1亿增长至3亿以上。
6. 远程MCP服务器是唯一能在网页、移动和云端运行的配置。
7. 按意图而非端点分组工具，可减少代理调用次数。
8. 大规模服务应暴露薄工具层，让代理在沙箱中执行代码。
9. MCP Apps扩展允许工具返回交互式界面如图表或表单。
10. 工具搜索可将工具定义令牌减少85%以上，同时保持高准确率。

# TAKEAWAYS:
1. 为最大化覆盖范围，始终构建远程MCP服务器而非本地方案。
2. 按用户意图设计工具，避免简单镜像API端点。
3. 利用MCP Apps和Elicitation扩展提供丰富的交互体验。
4. 采用标准化OAuth认证和凭证保管库简化云端安全集成。
5. 将MCP服务器与技能（Skills）捆绑，让代理获得完整工作流知识。
