# Anthropic API 控制台中的工作区  

**日期：** 2024-09-10 00:00 UTC  
**链接：** https://claude.com/blog/workspaces  

---  

我们正在 Anthropic API 控制台中引入工作区，以帮助开发者高效管理多个 Claude 部署。工作区是独特的环境，使您能够组织资源、简化访问控制，并在更细粒度上设置自定义支出和速率限制。  

## 管理多个部署  

对于在不同环境（如开发、测试和生产）以及不同用例中使用 Claude 的开发者，工作区为您的整体组织和单个 API 密钥提供了一个抽象层。  

**通过工作区，您可以：**  

* **设置细粒度支出限制：** 按工作区实施月度支出限制，从而对 API 使用成本进行精细控制。  
* **分组相关资源：** 将 API 密钥、使用数据和设置组织成与项目或环境相符的逻辑组。  
* **管理速率限制：** 独立调整每个工作区的速率限制，同时保持在整体组织速率限制范围内，以更好地管理各部署的负载。  
* **简化访问控制：** 通过在工作区级别分配用户权限来提高账户安全性。  
* **高效监控使用情况：** 获取按工作区细分的 API 使用情况和成本洞察，从而更轻松地跟踪和优化资源分配。  

## 入门指南  

工作区现已面向所有 Anthropic API 用户在我们的控制台中提供。要开始使用，您可以在此处[创建带有工作区范围 API 密钥的工作区](https://console.anthropic.com/settings/workspaces)。要了解更多信息，请在我们的[帮助中心](https://support.anthropic.com/en/articles/9796807-creating-and-managing-workspaces)探索详细指南。
