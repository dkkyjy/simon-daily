# 一份摘要

Claude Code 的动态工作流功能允许AI为复杂任务动态创建定制化执行框架，以克服单一上下文的局限性。

# 主要观点

1. 动态工作流让Claude能即时编写定制化执行框架。
2. 工作流通过JavaScript文件协调多个子代理完成任务。
3. 默认框架在长期、并行或对抗性任务中容易失败。
4. 代理惰性指Claude在完成部分任务后过早停止。
5. 自我偏好偏见使Claude倾向于偏爱自己的结果。
6. 目标漂移指在多次压缩后原始目标逐渐丢失。
7. 静态工作流需要处理所有边缘情况，因此更通用。
8. 动态工作流由Claude Opus 4.8根据用例智能编写。
9. 工作流可保存、共享，并通过技能分发。
10. 对于常规编码任务，动态工作流通常不是必需的。

# 要点

1. 使用“分类并行动”模式将任务拆分给独立子代理。
2. 利用“对抗性验证”让不同代理相互检查输出。
3. 通过“锦标赛”模式让多个代理竞争同一任务。
4. 结合“/loop”命令实现工作流的持续运行。
5. 为工作流设置明确的令牌使用预算以控制成本。
