# Claude Design 现已在日常工作中保持品牌一致性

            **日期：** 2026-06-17 00:00 UTC
            **链接：** https://claude.com/blog/claude-design-stays-on-brand-for-daily-work

            ---

            现在，Claude Design 可在不同项目中遵循您的设计系统，与 Claude Code 流畅协作，让您直接在画布上进行编辑，并连接更多您已使用的工具。它在 Claude 桌面应用的侧边栏中拥有了新位置；您也可以在 [claude.ai/design](https://claude.ai/design) 找到它。

我们的目标一如既往：让您探索比截止日期通常允许的更多方向，并让交接给润色或构建环节尽可能无缝。现在，这一目标服务于更多人。超过一百万人已在第一周内使用 Claude Design，而您的反馈正在塑造我们接下来构建的内容。

## 使用您的设计系统组件进行构建

我们重新构建了设计系统导入功能，以提供更多灵活性和更高精度。从 GitHub 仓库、设计文件或原始上传中导入一个或多个设计系统。Claude 使用您的组件进行构建，对照您的设计系统检查输出，并在您看到之前进行修正。对于较大的团队，新的管理员角色可以批准一个标准系统并锁定编辑，从而确保作品始终符合公司规范。

## 在设计代码之间切换

现在，在 Claude Design 和 Claude Code 之间切换更加容易，同时保持工作同步，相关更新今日起陆续推出。使用 /design-sync 导入您的设计系统，以便您在 Claude Design 中构建的所有内容都从现有组件开始。当设计准备好转化为软件时，您可以将其交接给 Claude Code，后者将从您现有工作继续，而不是从截图重新开始。

更喜欢从 Claude Code 开始？您可以在不离开终端的情况下，使用 /design 创建、编辑和同步设计项目。将设计导入您的代码库，将代码转化为实时原型，或让 Claude 将项目一路推进到底。

## 日常工作中更稳定

我们的新编辑器让您对设计的每个元素拥有直接、精细的控制。新的丰富布局控件让您可以拖拽、调整大小和对齐元素。数百项稳定性修复使编辑器在真实使用中表现更佳。

Claude Design 现在还与聊天、Claude Cowork 和 Claude Code 共享使用限制，因此大多数人将获得更多创作空间，而那些触及限制的人遇到限制的频率也会降低。平均每次交互现在使用更少的令牌来实现相同结果，错误率也大幅下降。

## 从画布到您使用的工具

可靠地导出为 PDF 和 PowerPoint，或将您的作品发送到您已使用的应用——连接器列表现在包括 Adobe、Base44、Canva、Gamma、Lovable、Miro、Replit、Vercel 和 Wix，更多目的地即将推出。

## 开始使用

Claude Design 在 Claude Pro、Max、Team 和 Enterprise 计划中处于测试阶段，并包含在您的订阅中。对于 Enterprise 用户，默认情况下处于关闭状态；管理员可以在组织设置中启用它，作品仅可在组织内部共享。在 [claude.ai/design](https://claude.ai/design) 或桌面应用的侧边栏中找到它。导入您的设计系统并开始创作。没有灵感？让系统为您下一个着陆页提供三个方向，然后选择值得精化的那个。
