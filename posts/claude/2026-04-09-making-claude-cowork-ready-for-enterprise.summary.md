# 一句话摘要

Anthropic 为 Claude Cowork 推出企业级管理控制功能，支持团队大规模部署并提升生产力和可见性。

# 主要观点

1. Claude Cowork 现已在所有付费计划中全面可用。
2. 企业版新增基于角色的访问控制，可分组管理用户权限。
3. 管理员可为团队设置消费限额，实现可预测成本控制。
4. 使用分析仪表板追踪 Cowork 会话和活跃用户数据。
5. 分析 API 提供每用户活动、技能和连接器调用详情。
6. 扩展 OpenTelemetry 支持，兼容 Splunk 和 Cribl 等工具。
7. Zoom MCP 连接器将会议摘要直接集成到 Cowork 中。
8. 管理员可限制每个 MCP 连接器的具体操作权限。
9. 大部分 Cowork 使用来自工程以外的运营、营销等团队。
10. Zapier、Jamf 和 Airtree 已通过 Cowork 实现工作流自动化。

# 核心启示

1. 企业部署 AI 代理需平衡治理与团队自主权。
2. 细粒度权限和预算控制是规模化采用的关键。
3. 非工程团队对 AI 辅助的需求增长迅速。
4. 连接现有工具（如 Zoom）能显著提升工作流价值。
5. 使用分析数据可优化 AI 投资方向。
