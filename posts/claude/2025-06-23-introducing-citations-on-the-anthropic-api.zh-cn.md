# 在 Anthropic API 上引入引用功能

            **日期：** 2025-06-23 00:00 UTC
            **链接：** https://claude.com/blog/introducing-citations-api

            ---

            ***更新：** *现已可在 Amazon Bedrock 中使用。（2025 年 6 月 30 日）*

今天，我们推出引用功能，这是一项新的 API 特性，让 Claude 能够基于源文档来支撑其回答。Claude 现在可以提供详细的引用，指向其用于生成回复的确切句子和段落，从而带来更可验证、更值得信赖的输出结果。

引用功能已在 Anthropic API 和 Google Cloud 的 Vertex AI 上全面可用。

### 通过验证建立信任

所有 Claude 模型都经过训练，设计上具有可信赖性和可引导性。引用功能在此基础上构建，满足了 AI 应用中的一个特定需求：验证 AI 生成回复背后的来源。

此前，开发者依赖复杂的提示词来指示 Claude 包含来源信息，这往往导致性能不稳定，并在提示词工程和测试上投入大量时间。借助引用功能，用户现在可以将源文档添加到上下文窗口中，当查询模型时，Claude 会自动在其输出中引用那些从这些来源推断出的主张。

**我们的内部评估显示，Claude 内置的引用能力优于大多数自定义实现，将召回准确率提高了高达 15%。1**

### 使用场景

借助引用功能，开发者可以创建在以下使用场景中提供更强可问责性的 AI 解决方案：

* 文档摘要：生成长文档（如案件档案）的简洁摘要，每个关键点都链接回其原始来源。
* 复杂问答：针对大量文档语料库（如财务报表）中的用户查询提供详细答案，每个回复元素都追溯到相关文本的特定章节。
* 客户支持：创建能够通过引用多个产品手册、常见问题解答和支持工单来回答复杂查询的支持系统，始终引用信息的准确来源。

### 工作原理

启用引用功能后，API 会将用户提供的源文档（PDF 文档和纯文本文件）分句处理。这些分句后的句子，连同用户提供的上下文，会与用户的查询一起传递给模型。或者，用户也可以为源文档提供自己的分句块。

Claude 分析查询并生成回复，其中包含基于所提供的分句块和上下文的精确引用，用于任何源自源材料的主张。被引用的文本将引用源文档，以最大程度减少幻觉。

这种方法提供了卓越的灵活性和易用性，因为它不需要文件存储，并能与消息 API 无缝集成。

### 定价

引用功能使用我们标准的基于令牌的定价模型。虽然它可能使用额外的输入令牌来处理文档，但用户无需为返回引用文本本身的输出令牌付费。

### 客户聚焦：汤森路透

汤森路透使用 Claude 为其 AI 平台 CoCounsel 提供支持，帮助法律和税务专业人士综合专业知识，为客户提供全面建议。

"为了让 CoCounsel 对执业律师来说值得信赖且立即可用，它需要引用其工作成果。我们最初是自己构建这个功能的，但构建和维护起来非常困难。这就是为什么我们很兴奋地测试 Anthropic 的引用功能。它使得构建、维护和向用户部署引用及链接到原始来源的功能变得容易得多。这项能力不仅有助于最大程度降低幻觉风险，还能增强对 AI 生成内容的信任。引用功能将使我们能够为律师构建一个更加准确和全面的 AI 助手，"汤森路透 CoCounsel 产品负责人 Jake Heller 表示。

### 客户聚焦：Endex

Endex 使用 Claude 为金融公司提供自主代理支持。

"借助 Anthropic 的引用功能，我们将来源幻觉和格式问题从 10% 降至 0%，并且每次回复的引用数量增加了 20%。这消除了围绕引用进行复杂提示词工程的需要，并提高了我们在进行复杂、多阶段金融研究时的准确性，"Endex 首席执行官 Tarun Amasa 表示。

### 开始使用

引用功能现已可用于新的 Claude 3.5 Sonnet 和 Claude 3.5 Haiku。要开始使用引用功能，请探索我们的[文档](https://docs.anthropic.com/en/docs/build-with-claude/citations)。
