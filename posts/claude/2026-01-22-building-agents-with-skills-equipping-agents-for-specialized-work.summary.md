# 一句话总结

Anthropic 提出 Agent Skills 标准，将领域专业知识打包成文件，让通用智能体变成领域专家。

# 主要观点

1. 智能体有通用能力但缺乏领域专业知识，Skills 填补了这一空白。
2. Skills 是包含工作流、最佳实践和脚本的文件集合。
3. 代码被视为智能体执行几乎所有数字工作的通用接口。
4. Skills 采用渐进式披露机制，保护上下文窗口不被撑爆。
5. Skills 可包含脚本作为工具，脚本可自我文档化且可修改。
6. 生态系统已形成三类 Skills：基础型、合作伙伴型和企业型。
7. Skills 复杂度从简单模板到数千行的生物信息学流水线不等。
8. Skills 与 MCP 服务器协同工作，连接外部工具和数据源。
9. 非开发者也能在 30 分钟内创建并测试自己的 Skills。
10. Anthropic 将 Agent Skills 发布为开放标准，支持跨平台移植。

# 核心启示

1. 不要为每个领域构建专用智能体，而是构建通用智能体并配备 Skills。
2. Skills 将机构知识编码为可版本控制、可共享的文件，降低知识传递成本。
3. 渐进式披露设计使智能体能携带数百个 Skills 而不影响性能。
4. 代码作为工具比传统工具更灵活，智能体可自行修改和扩展。
5. Skills 生态正在向金融、医疗等垂直领域快速扩展，标准化是关键推动力。
