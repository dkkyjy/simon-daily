# 一份句子摘要

Anthropic 推出技能创建器增强功能，通过测试、评估和迭代改进帮助非工程师用户更可靠地构建和维护 AI 技能。

# 主要观点

1. 技能创建器现在支持编写评估、运行基准测试并随模型演变保持技能有效。
2. 大多数技能作者是领域专家而非工程师，缺乏验证技能质量的工具。
3. 技能分为能力提升型和编码偏好型，需要不同类型的测试。
4. 评估可捕捉质量回归并了解模型能力何时超越技能。
5. 基准测试模式标准化评估技能通过率、耗时和令牌使用量。
6. 多代理支持并行运行评估，避免上下文污染并加快速度。
7. 比较代理可进行技能版本的 A/B 测试，判断更改是否有效。
8. 描述优化功能帮助技能在正确时机触发，减少误报和漏报。
9. 评估框架是未来技能从"如何做"转向"做什么"的关键一步。
10. 所有更新现已在 Claude.ai、Cowork 和 Claude Code 插件中可用。

# 要点

1. 利用评估测试捕捉技能在模型更新后的质量退化。
2. 当基础模型无需技能即可通过评估时，可安全移除该技能。
3. 使用基准测试模式标准化追踪技能性能随时间的变化。
4. 利用描述优化确保技能仅在需要时触发，避免干扰。
5. 采用比较代理进行盲测，客观判断技能修改是否真正改进。
