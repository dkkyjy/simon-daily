自[10月份推出技能功能](https://claude.com/blog/skills)以来，我们看到了来自开发者的强烈兴趣，他们希望 Claude 能够始终如一地遵循特定工作流程；来自高级用户的兴趣，他们希望自动执行重复性任务，如文档创建或研究流程；来自团队的兴趣，他们希望标准化 Claude 在整个组织中的运作方式；以及来自 MCP 连接器构建者的兴趣，他们希望将集成与可靠的工作流程相结合。

共同的诉求是：人们希望获得关于构建有效技能的更详细指导——无论是用于独立工作流程还是 MCP 增强的集成——涵盖从规划和结构到测试和分发的方方面面。

我们整理了这份指南来填补这一空白。它涵盖了从技术要求、技能结构到测试方法和常见故障排除模式的所有内容。无论你是在构建与 Claude 内置功能配合使用的独立技能，还是增强 MCP 集成，你都会发现这些指导具有相关性——对于那些需要的人，我们还专门设置了关于 MCP + 技能的部分。

**你将学到：**

* 技术要求与技能结构的最佳实践
* 独立技能与 MCP 增强工作流程的模式
* 在不同使用场景中行之有效的模式
* 如何测试、迭代和分发你的技能

如果你知道想要自动化的前 2-3 个工作流程，预计使用 skill-creator 构建和测试你的第一个可用技能大约需要 15-30 分钟。

**适用人群：**

* 希望 Claude 始终如一地遵循特定工作流程的开发者
* 为其集成添加工作流程知识的 MCP 连接器构建者
* 自动化执行重复性任务的高级用户
* 希望将 Claude 在整个组织中的运作方式标准化的团队
