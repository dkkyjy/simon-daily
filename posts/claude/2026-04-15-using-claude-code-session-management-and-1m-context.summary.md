# ONE SENTENCE SUMMARY:
Claude Code 通过会话管理、压缩、回退和子代理功能，帮助用户优化百万级上下文窗口的使用效率。

# MAIN POINTS:
1. `/usage` 命令帮助用户了解 Claude Code 的使用情况。
2. 上下文窗口包含系统提示、对话历史、工具调用和读取文件。
3. 上下文腐烂指模型性能随上下文增长而下降的现象。
4. 压缩功能自动将任务总结并迁移到新上下文窗口。
5. 每个对话回合都是分支点，提供继续、回退、清除等选项。
6. 新任务应开启新会话，避免上下文腐烂影响性能。
7. 回退比直接纠正更有效，可保留有用文件读取。
8. 压缩由模型总结历史，清除由用户手动编写关键信息。
9. 不良自动压缩常因模型无法预测工作方向导致。
10. 子代理拥有独立上下文窗口，仅返回最终结果。

# TAKEAWAYS:
1. 新任务开启新会话，相关任务可继续使用当前会话。
2. 使用回退功能跳转到之前消息并重新提示，优于直接纠正。
3. 压缩适合低努力场景，清除适合需要精确控制上下文时。
4. 子代理适用于产生大量中间输出但只需结论的任务。
5. 主动使用 `/compact <提示>` 可避免不良自动压缩。
