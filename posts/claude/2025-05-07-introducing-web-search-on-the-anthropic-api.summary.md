# 一句话总结

Anthropic API 新增网络搜索工具，让 Claude 能实时获取最新信息并生成带引用的精准回答。

# 主要观点

1. 网络搜索工具让 Claude 访问实时网络数据以增强回答。
2. Claude 自主判断何时需要搜索并生成精准查询。
3. Claude 可进行多轮渐进式搜索以深化研究。
4. 开发者可通过 max_uses 参数控制搜索行为。
5. 每次回答都包含来源引用以支持信息验证。
6. 管理员可设置域名允许列表和阻止列表。
7. 支持金融、法律、开发工具和生产力等用例。
8. 网络搜索已集成至 Claude Code 开发工作流。
9. 适用于 Claude 3.7 Sonnet 等最新模型。
10. 每千次搜索收费 10 美元加标准令牌费用。

# 核心启示

1. 无需自建搜索基础设施即可获取实时数据。
2. 引用机制确保信息可追溯和可信赖。
3. 域名控制功能满足企业合规需求。
4. 渐进式搜索实现类人研究能力。
5. 开发者工具场景可访问最新 API 文档。
