# 在 Anthropic API 上推出网页搜索 | Claude by Anthropic

**日期：** 2025-05-07 00:00 UTC
**链接：** https://claude.com/blog/web-search-api

---

***更新：*** *您现在可以在请求中添加网页抓取工具，Claude 将获取并分析任何网页 URL 的内容。2025年9月10日*

今天，我们在 Anthropic API 上推出网页搜索——一种新工具，让 Claude 能够获取来自互联网的最新信息。启用网页搜索后，开发者可以构建由 Claude 驱动的应用程序和智能代理，提供最新的洞察。

### 利用来自网络的最新信息赋能 AI 代理

开发者现在可以通过在向 Messages API 发出请求时启用网页搜索工具，用当前的真实世界数据来增强 Claude 的全面知识。

当 Claude 收到一个需要最新信息或专业知识才能更好回答的请求时，它会运用推理能力来判断网页搜索工具是否有助于提供更准确的回答。如果搜索网络是有益的，Claude 会生成有针对性的搜索查询、检索相关结果、分析其中的关键信息，并提供带有来源引用的全面回答。

Claude 还可以以代理模式运行，进行多次渐进式搜索，利用先前的结果来指导后续查询，以进行轻度研究并生成更全面的回答。开发者可以通过调整 *max\_uses* 参数来控制这一点*。* 在后台，Claude 也可能会优化其查询，以提供更准确的回答。

借助网页搜索，开发者现在可以构建利用当前信息的 AI 解决方案，而无需自行管理网页搜索基础设施。

### 使用场景

网页搜索使 Claude 能够支持各种受益于实时数据和专业知识的跨行业使用场景。使用场景包括：

* **金融服务：** 构建能够分析实时股价、市场趋势和监管动态的 AI 代理。
* **法律研究：** 创建能够访问最新法院判决、监管变化和法律新闻的工具。
* **开发者工具：** 让 Claude 能够参考最新的 API 文档、GitHub 版本发布和技术更新。
* **生产力：** 构建整合最新公司报告、竞争情报或行业研究的代理。

### 以信任和控制为基础进行构建

每个来自网络的回答都包含对来源材料的引用，使用户能够直接核实信息。这对于需要准确性和可问责性的敏感使用场景尤其有价值。

组织可以通过以下管理员设置保持额外控制：

* **域名允许列表：** 指定 Claude 可以搜索和检索信息的域名，确保结果仅来自经批准的来源。
* **域名阻止列表：** 防止 Claude 访问可能包含对您的组织敏感、具有竞争性或不当内容的某些域名。
* **组织级管理：** 管理员可以在组织层面允许或禁止网页搜索的使用。

### 使用网页搜索增强 Claude Code

网页搜索现在也可在 Claude Code 中使用，为开发工作流程添加来自网络的最新信息。

启用网页搜索后，Claude Code 可以访问最新的 API 文档、技术文章以及其他关于开发工具和库的信息。这在处理新的或快速发展的框架、排查晦涩的错误或实现需要特定版本 API 参考的功能时尤其有价值。

### 客户聚焦：Poe

Quora 正在将网页搜索引入其 AI 平台 Poe。

“Anthropic 的网页搜索工具是对 Poe 平台的一个受欢迎的补充。它成本效益高，并且以令人印象深刻的速度提供搜索结果，这将惠及那些需要在 Poe 上使用 Claude 模型时访问实时信息的用户，”Quora 的 Poe 产品负责人 Spencer Chan 表示。

### 客户聚焦：Adaptive.ai

Adaptive 是一款面向消费者的 AI 工具，用于创建端到端应用程序。

“Anthropic 的网页搜索始终如一地提供全面的结果，表现优于我们测试过的其他工具。Claude 回答的深度和准确性及其作为研究代理的能力，将对我们帮助客户构建支持网页的产品产生重大影响，”Adaptive 联合创始人 Dennis Xu 表示。

### 开始使用

网页搜索现已在 Anthropic API 上可用于 Claude 3.7 Sonnet、升级版 Claude 3.5 Sonnet 和 Claude 3.5 Haiku，价格为每 1,000 次搜索 10 美元，另加标准令牌费用。

要开始使用，请在您的 API 请求中启用网页搜索工具。浏览我们的[文档](https://docs.anthropic.com/en/docs/build-with-claude/tool-use/web-search-tool)和[定价](https://www.anthropic.com/pricing#api)以了解更多信息。
