# 一句话摘要

Anthropic Console 全新升级，提供一站式平台用于构建、测试和协作部署 Claude AI 应用。

# 主要观点

1. 全新控制台支持团队协作共享提示词，解决版本控制问题。
2. 工作台可交互测试 API 调用，结构化编写提示词。
3. Claude 能自动生成采用思维链技术的精准提示词。
4. 自动生成测试用例并并排比较输出，评估模型响应质量。
5. 高级提示工程技术可自动优化手写或迁移的提示词。
6. 点击“获取代码”即可获得可直接部署的生产级 API 调用。
7. 共享提示词库集中管理，确保组织内提示词质量一致。
8. Claude 3.7 Sonnet 支持即时响应或逐步可见的扩展思考。
9. 可指定提示词用于扩展思考，并设置最大思考令牌预算。
10. 升级版控制台现已对所有用户开放，可立即登录使用。

1. 利用工作台和自动生成功能快速创建高质量提示词。
2. 通过自动测试和并排比较，数据驱动地优化提示词。
3. 使用共享提示词库促进团队协作与知识标准化。
