# Claude 和 Slack

**日期：** 2025年10月1日 00:00 UTC
**链接：** https://claude.com/blog/claude-and-slack

---

***更新：** * *Slack 连接器现已面向 Claude Pro 和 Max 订阅用户开放。（2026年1月26日）*

我们推出两种将 Claude 与 Slack 结合使用的方式。将 Claude 直接添加到您的 Slack 工作区，或将 Slack 连接到 Claude 应用程序，以便 Claude 在对话期间能够搜索并引用相关的 Slack 消息。

通过 Claude 与 Slack 的深度集成，您可以在任何想要的地方工作。直接在 Slack 对话中获得 Claude 的帮助，或在需要为更深入的研究项目获取背景信息时，让 Claude 搜索您的 Slack 工作区。起草关键消息的回复、通过调取相关讨论来准备会议，或分析共享文档——所有这些操作都在您已有的工作环境中完成。

### 将 Claude 引入 Slack

当您在 Slack 中与 Claude 协作时，您将获得您已使用的所有功能——网页搜索、文档分析以及您现有的连接。这意味着 Claude 可以直接在 Slack 中从您的文档、电子邮件以及您已连接的任何其他工具中获取上下文信息。

Claude 仅搜索您有权访问的公共和私人 Slack 频道。当您要求 Claude 在公共线程中提供帮助时，它会先私下起草回复。您可以在与团队分享之前进行审查、编辑或重新生成，全程保持控制。

在 Slack 中有三种使用 Claude 的方式：

* **直接消息：** 与 @Claude 开始私人对话，以获得研究、写作或分析方面的一对一协助。
* **AI 助手面板：** 在任何频道中点击 Slack AI 助手标题中的 Claude 图标，即可访问 Claude，而不会中断正在进行的对话。
* **线程参与：** 通过提及 @Claude 将 Claude 添加到任何线程。Claude 将根据对话上下文起草回复，您可以在分享前进行审查。

### 将 Slack 连接到 Claude

当您将 Slack 连接到 Claude 时，Claude 会搜索您工作区的频道、直接消息和共享文件，以找到您所需的上下文信息，从而提供更好的回复和研究支持。

Claude 通过调取相关的 Slack 讨论、从多个频道收集项目更新，或查找隐藏在团队对话中的行动项，帮助您为会议做准备。将其用于：

* **会议准备：** 审查 Slack 讨论，调取相关文档，并创建包含最新更新和关键决策的简报
* **项目协调：** 跨频道搜索以收集状态更新，识别阻碍因素，并总结进展
* **入职支持：** 通过审查频道历史记录、共享文档和相关电子邮件线程，帮助新团队成员了解正在进行的项目
* **创建文档：** 将团队讨论正式化为文档，从对话和相关背景材料中获取上下文信息

此次集成代表着向更智能、AI 驱动的工作流程迈出的重要一步：

"每家公司都在走向成为智能体企业的道路上，AI 智能体与人类携手合作。与 Anthropic 合作，将 Claude 集成到 Slack 中，并将 Slack 上下文引入 Claude，加速了这一进程——将一流的 AI 直接带入工作流程中，"Salesforce 旗下 Slack 的首席产品官 Rob Seaman 分享道。"通过弥合 Claude 与 Slack 用户之间的差距，我们正在打造一种无缝的 AI 体验，让工作比以往任何时候都更高效、更愉快、更智能。"

### 安全与控制

Slack 中的 Claude 保持与用户 Claude 账户相同的安全标准和隐私设置。工作区管理员控制组织级别的应用审批，而个人用户则使用其现有的 Claude 账户进行身份验证。

在 Slack 中，Claude 仅访问您有权查看的频道和对话——尊重所有现有的 Slack 权限。Slack 对话遵循您组织的保留策略和安全设置。

### 入门指南

Slack 中的 Claude 现已通过 Slack 应用市场面向使用付费 Slack 计划的团队开放。工作区管理员必须首先批准 Claude 应用，然后个人用户才能使用其 Claude 账户进行身份验证。

Slack 连接器面向已安装 Slack 应用中 Claude 的 Claude Team 和 Enterprise 计划客户开放。管理员必须首先为其组织启用[连接器](https://claude.ai/directory/597f662f-36de-437e-836e-5a81013cbfbe)，然后用户才能在其 Claude 设置的"连接器"选项卡中进行设置。
