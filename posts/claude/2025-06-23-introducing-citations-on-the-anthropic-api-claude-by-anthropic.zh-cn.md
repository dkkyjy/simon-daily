# 在 Anthropic API 中推出引用功能 | Anthropic 的 Claude

**日期：** 2025-06-23 00:00 UTC
**链接：** https://claude.com/blog/introducing-citations-api

---

***更新：****现已在 Amazon Bedrock 上可用。（2025 年 6 月 30 日）*

今天，我们正式推出"引用"功能——一项全新的 API 特性，使 Claude 能够将其回答锚定于源文档。Claude 现在可以为生成回答所使用的确切句子和段落提供详细引用，从而带来更具可验证性和可信度的输出。

引用功能已在 Anthropic API 和 Google Cloud 的 Vertex AI 上全面可用。

### 以验证建立信任

所有 Claude 模型在设计上均经过训练，以确保其可信性和可控性。引用功能在此基础上进一步构建，针对 AI 应用中的一个特定需求：验证 AI 生成回答背后的信息来源。

此前，开发者依赖复杂的提示词来指示 Claude 包含来源信息，但往往导致性能不一致，并在提示词工程和测试方面投入大量时间。借助引用功能，用户现在可以将源文档添加到上下文窗口中，在查询模型时，Claude 会自动在输出中引用从这些来源中推断出的论断。

**我们的内部评估表明，Claude 内置的引用能力优于大多数自定义实现，召回准确率最高提升 15%。¹**

### 用例

借助引用功能，开发者可以创建在以下场景中提供更强可追溯性的 AI 解决方案：

* 文档摘要：生成长文档（如案件卷宗）的简洁摘要，将每个要点链接回其原始来源。
* 复杂问答：在大量文档（如财务报表）中为用户查询提供详细回答，将每个回答要素追溯到相关文本的具体章节。
* 客户支持：创建能够引用多本产品手册、常见问题解答和支持工单来回答复杂查询的支持系统，始终注明信息的精确来源。

### 工作原理

启用引用功能后，API 会将用户提供的源文档（PDF 文档和纯文本文件）分块为句子。这些分块句子连同用户提供的上下文，将与用户的查询一起传递给模型。或者，用户也可以自行提供源文档的分块。

Claude 会分析查询并生成包含精确引用的回答，这些引用基于所提供的分块和上下文，用于标注任何源自源材料的论断。被引用的文本将指向源文档，以最大限度减少幻觉。

这种方法提供了卓越的灵活性和易用性，因为它无需文件存储，并能与 Messages API 无缝集成。

### 定价

引用功能采用我们标准的基于令牌的定价模式。虽然处理文档可能会使用额外的输入令牌，但用户无需为返回引用文本本身的输出令牌付费。

### 客户聚焦：Thomson Reuters（汤森路透）

Thomson Reuters 使用 Claude 为其 AI 平台 CoCounsel 提供动力，帮助法律和税务专业人士整合专业知识，为客户提供全面的建议。

"为了让 CoCounsel 值得信赖并立即为执业律师所用，它需要引用其工作依据。我们最初自行构建了这一功能，但构建和维护都非常困难。这就是我们为何兴奋地去测试 Anthropic 的引用功能。它使引用和链接到原始来源变得更加容易构建、维护和向用户部署。这一能力不仅有助于将幻觉风险降至最低，还能增强对 AI 生成内容的信任。引用功能将使我们能够构建一个更加准确、全面的律师 AI 助手，"Thomson Reuters CoCounsel 产品负责人 Jake Heller 说道。

### 客户聚焦：Endex

Endex 使用 Claude 为金融公司驱动自主代理。

"借助 Anthropic 的引用功能，我们将来源幻觉和格式问题从 10% 降低至 0%，每条回答中的引用数量增加了 20%。这消除了围绕引用进行复杂提示词工程的需要，并提高了我们在进行复杂的多阶段金融研究时的准确性，"Endex 首席执行官 Tarun Amasa 说道。

引用功能现已在最新的 Claude 3.5 Sonnet 和 Claude 3.5 Haiku 上可用。要开始使用引用功能，请访问我们的[文档](https://docs.anthropic.com/en/docs/build-with-claude/citations)。
