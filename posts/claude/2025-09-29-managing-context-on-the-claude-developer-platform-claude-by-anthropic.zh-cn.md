# 在 Claude 开发者平台上管理上下文 | Claude by Anthropic

今天，我们在 Claude 开发者平台上推出了管理智能体上下文的新功能：上下文编辑和记忆工具。

借助我们最新的模型 [Claude Sonnet 4.5](https://www.anthropic.com/news/claude-sonnet-4-5)，这些功能使开发者能够构建能够以更高性能处理长时间运行任务的 AI 智能体，同时避免达到上下文限制或丢失关键信息。

## 上下文窗口有限，但实际工作没有止境

随着生产环境中的智能体处理更复杂的任务并生成更多工具结果，它们往往会耗尽有效的上下文窗口——这让开发者陷入两难：要么裁剪智能体记录，要么降低性能。上下文管理通过两种方式解决这一问题，帮助开发者确保只有相关数据留在上下文中，并能在不同会话之间保留有价值的见解。

**上下文编辑** 能够在接近 token 限制时自动清除上下文窗口中过时的工具调用及其结果。当您的智能体执行任务并积累工具结果时，上下文编辑会移除陈旧内容，同时保留对话流程，从而有效延长智能体的运行时间，无需人工干预。这也提升了模型的有效性能，因为 Claude 只关注相关的上下文。

**记忆工具** 使 Claude 能够通过基于文件的系统在上下文窗口之外存储和查询信息。Claude 可以在您基础设施中专用的记忆目录中创建、读取、更新和删除文件，这些文件会跨会话持久存在。这使得智能体能够随时间为知识库积累内容，跨会话维护项目状态，并引用之前学到的信息，而无需将所有内容保留在上下文中。

记忆工具完全通过客户端侧的 tool 调用运行。开发者管理存储后端，从而完全控制数据的存储位置和持久化方式。

Claude Sonnet 4.5 增强了这两项功能，具备内置的上下文感知能力——在整个对话过程中跟踪可用 token，从而更有效地管理上下文。

这些更新共同构建了一个提升智能体性能的系统：

*   通过自动从上下文中移除过时的工具结果，实现更长的对话
*   通过将关键信息保存到记忆中来提高准确性——并将这些学习成果带到连续的智能体会话中

## 构建长时间运行的智能体

Claude Sonnet 4.5 是世界上构建智能体的最佳模型。这些功能为长时间运行的智能体解锁了新的可能性——处理整个代码库、分析数百份文档或维护广泛的工具交互历史。上下文管理在此基础上构建，确保智能体能够高效利用这种扩展后的容量，同时仍然处理超出任何固定限制的工作流。用例包括：

*   **编码：** 上下文编辑清除旧的文件读取和测试结果，而记忆则保存调试见解和架构决策，使智能体能够在大型代码库上工作而不丢失进度。
*   **研究：** 记忆存储关键发现，而上下文编辑移除旧的搜索结果，构建出随时间推移性能不断提升的知识库。
*   **数据处理：** 智能体将中间结果存储在记忆中，同时上下文编辑清除原始数据，处理那些原本会超出 token 限制的工作流。

## 上下文管理带来的性能提升

在一个用于智能体搜索的内部评估集中，我们测试了上下文管理如何提升智能体在复杂多步骤任务上的性能。结果显示了显著的提升：将记忆工具与上下文编辑结合使用，性能相比基线提升了 39%。仅使用上下文编辑就带来了 29% 的提升。

在一个 100 轮次的网页搜索评估中，上下文编辑使智能体能够完成因上下文耗尽而本会失败的工作流——同时减少了 84% 的 token 消耗。
