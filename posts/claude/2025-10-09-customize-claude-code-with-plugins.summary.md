# ONE SENTENCE SUMMARY:
Claude Code 推出插件系统，允许用户打包和共享自定义命令、代理、MCP 服务器和钩子，以标准化开发工作流程。

# MAIN POINTS:
1. 插件可打包斜杠命令、子代理、MCP 服务器和钩子四种扩展点。
2. 使用 `/plugin` 命令即可安装插件，目前处于公开测试阶段。
3. 插件可按需启用或禁用，以减少系统提示的上下文复杂度。
4. 插件有助于团队强制执行代码审查和测试工作流等标准。
5. 开源维护者可通过插件提供斜杠命令，帮助开发者正确使用其包。
6. 任何人都可以创建并托管插件市场，分享自定义插件集合。
7. 插件市场只需一个带有 `.claude-plugin/marketplace.json` 文件的仓库或 URL。
8. 使用 `/plugin marketplace add` 命令可添加并浏览市场中的插件。
9. 社区成员已创建 DevOps、文档生成和测试等领域的插件市场。
10. 插件支持终端和 VS Code 环境，适用于所有 Claude Code 用户。

# TAKEAWAYS:
1. 利用插件标准化团队开发环境，确保一致的工作流和代码质量。
2. 按需启用插件，避免不必要的上下文开销，提升 Claude Code 效率。
3. 创建内部插件市场，安全分发经批准的自定义工具和配置。
4. 探索社区插件市场，快速获取 DevOps、测试等领域的现成解决方案。
5. 使用元插件快速创建新插件，降低自定义扩展的开发门槛。
