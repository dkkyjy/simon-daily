# 一句话摘要

Claude Code 推出动态工作流，通过并行子代理处理复杂工程任务，将季度工作缩短至数天完成。

# 主要观点

1. 动态工作流可并行运行数十至数百个子代理，自动检查结果。
2. 适用于跨服务调试、大型迁移和关键任务的双重验证。
3. Bun 项目通过动态工作流在11天内将 Zig 移植为 Rust。
4. 工作流自动规划、分解子任务并并行执行，结果经检查后整合。
5. 代理从独立角度解决问题，其他代理尝试反驳结果直至收敛。
6. 支持长时间运行任务，进度可保存，中断后能恢复。
7. 动态工作流消耗的令牌量远超典型 Claude Code 会话。
8. 首次触发时需用户确认，组织管理员可禁用此功能。
9. 适用于 Pro、Max、Team 和企业计划，以及多个云平台。
10. 可通过直接请求或启用 ultracode 设置来启动工作流。

# 核心启示

1. 动态工作流将复杂工程任务自动化，显著缩短项目周期。
2. 并行子代理与对抗性验证机制确保结果可靠性。
3. 适合代码库级安全审计、性能优化和框架迁移等场景。
4. 使用前应从小范围任务开始，以评估令牌消耗情况。
5. 进度保存功能使长时间运行任务更具容错性和实用性。
