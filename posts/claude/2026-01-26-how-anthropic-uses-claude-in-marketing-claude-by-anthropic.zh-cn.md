# Anthropic 如何在营销中使用 Claude | Claude by Anthropic

**日期：** 2026-01-26 00:00 UTC
**链接：** https://claude.com/blog/how-anthropic-uses-claude-marketing

---

在 Claude Code 之前，Austin Lau 一生从未写过一行代码。当这个产品首次推出时，他不得不去谷歌搜索如何打开电脑上的终端。

“Claude Code 上线时我的第一反应是，我完全不知道这个产品是干什么用的，”Anthropic 的增长营销人员 Austin 说。“作为一个营销人员，它真的没有让我产生共鸣——它的使用场景对我来说并不明显。”

但好奇心占了上风。

一位 Anthropic 同事在公司的 Slack 工作区发布了一份指南，教非技术员工如何安装 Claude Code。Austin 决定按照指南操作。

一周后，Austin 构建了两个从根本上改变他工作方式的工作流：一个 Figma 插件，只需单击一次即可生成广告创意变体；以及一个 Google Ads 文案工作流，帮助他构思和优化广告文案，然后导出为可直接上传的 CSV 文件。过去每个广告需要 30 分钟，现在只需 30 秒。

以下是他的做法，以及营销人员可以从他使用 Claude Code 的经验中学到什么。

‍

## **问题：淹没在文案和创意变体中**

大规模运行效果营销需要不断产生新鲜的创意。Google 的响应式搜索广告单独就需要 15 个独特的标题。每隔几周，这些文案就需要更新——同时还要保持品牌调性并传达价值主张。

“最难的部分是，当你在这个层面上运作时，你需要非常频繁地更新文案，”Austin 解释说。“而 Google 对文案的要求因严格的字符数限制而缺乏灵活性。”

旧流程是这样的：打开 Google Sheets，构思标题和描述，手动检查字符数，复制粘贴到 Google Ads，然后重复。

对于视觉广告，流程更加复杂。Austin 会打开 Figma，多次复制现有框架，切换到 Google Doc 获取标题文案，再切换回 Figma 粘贴文案，重复——跨越十多个变体和多种宽高比。

“所有这些时间累积起来非常非常快，”Austin 说。

## **解决方案：两个消除了营销琐事的工作流**

使用 Claude，Austin 最终构建了两个改变他日常生活的工流。但 Austin 的第一个项目是构建一个简单的计算器应用。

“我让 Claude 做的第一件事就是为我制作一个非常简单的计算器应用，只是为了看看它会如何回应，”他回忆道。“Claude 基本上创建了后端，还为我做了一个简单的前端。然后它基本上告诉我，‘这是你实际如何运行它的方法。’”

那个小实验改变了他对自己在工作中能实现什么的想法。

### **用于创意变体的 Figma 插件**

创建广告变体意味着无尽的复制、粘贴以及在 Figma 和 Google Docs 之间切换。

于是 Austin 用 Claude Code 构建了一个 Figma 插件，这个项目花了大约 45 分钟到 1 小时来构建，但每次他更新大量跨多种宽高比的创意时，现在可以节省近 30 分钟。

开始时，他打开 Claude Code 并通过提示描述了他的问题：“Claude，我在 Figma 中工作。我真的希望解决这个重复复制粘贴的挑战。你能帮我构建一个 Figma 插件来解决我的挑战吗？”

Claude 出去做了研究，评估如何最好地构建插件，有什么限制，然后开始制作原型。经过一些故障排除后，Austin 在 Figma 中安装了一个可用的插件。

*Austin 的插件让他可以从 Google Sheet 粘贴标题文案，并一键生成数十个广告变体。*

“我所要做的就是指定创意的框架，然后只需一次复制粘贴所有我想要更新的不同变体和文案，点击一个按钮，Figma 插件就会为该单个图像创建所有不同的排列，”Austin 解释说。

### **Google Ads 文案生成**

对于响应式搜索广告，Austin 构建了一个工作流，帮助构思和创建可上传的广告文案，利用现有的广告系列和广告效果数据来帮助了解哪些类型的信息能引起潜在客户的共鸣。这个工作流每周在文案创建和字符验证上节省数小时。由于在机械性任务上节省了时间，Austin 现在可以运行更多的文案实验，并更快地迭代实际表现最好的内容。

开始工作时，他输入 `/rsa`（他为响应式搜索广告创建的自定义斜杠命令）到 Claude。Claude Code 会询问广告系列数据、现有文案和关键词，然后将他的输入与 Anthropic 的品牌语调和声音、产品准确性以及 Google Ads RSA 最佳实践的 [Agent Skills](https://claude.com/blog/skills) 进行交叉引用。

但输出只是一个起点。

“Claude 是一个很好的头脑风暴伙伴，但有时它第一次尝试并不能做对，”Austin 解释说。“我所做的大量工作都是反复推敲，来回调整以逐步优化文案。”

这种优化很重要，因为 Austin 要根据他对什么能与 Anthropic 受众产生共鸣的了解来评估每个标题。价值主张是否到位？语气是否正确？是否与竞争对手区分开来？一旦文案感觉合适，Claude Code 会将所有内容组合成一个 CSV 文件，准备上传。

而所有这一切都建立在人类的基础上。“我们提供给 Claude 的所有文案和示例都是与产品营销和文案团队合作编写的，”Austin 说。这个坚实的起点意味着在 Claude 开始头脑风暴之前，已经融入了人类的判断。

*该工作流导出相关的广告系列和广告组列，以及每个广告 15 个标题和 4 个描述，生成一个 CSV 文件，可直接上传到 Google Ads（经过人工审核后）。*

## **构建自己工作流的最佳实践**

Austin 的经验为营销人员——或者实际上任何没有技术背景的人——提供了实用的指导，帮助他们使用 Claude Code 构建自定义工具。

**从小的、重复的步骤开始**

“我的建议是：如果你想尝试像 Claude Code 这样的工具，只要思考一下，你工作中哪些领域是你认为重复的或可以自动化的，然后从一个非常非常小且简单的事情开始，”Austin 解释道。

例如，Austin 的第一个项目是构建他的计算器应用，首先看看 Claude 是如何工作的。

**让好奇心驱动你的工作**

Austin 形容自己是“那种如果对某件事非常好奇，就会达到几乎固执的程度，必须找到答案的人”。这种坚持将那个他不知道如何交互的空白终端变成了每天使用的功能工具。

**像向同事解释问题一样与 Claude 对话**

“你不需要知道如何编码。你只需要知道如何以非常清晰、简洁的方式解释你的挑战和你试图解决的问题，”Austin 说。

非技术员工已经在自己领域内是主题专家。他们了解自己的工作流程，感受痛点，并且确切知道他们需要从输出中得到什么。Claude Code 赋予他们自行修复任何重复性技术问题的能力。

**基于现有资源构建**

对于 Figma 插件，Austin 将 Claude Code 指向现有的 Figma API 文档。使用现有文档，Claude 进行了自己的研究，并为 Austin 构建了一个原型进行实验。一个几乎无法工作的原型足以证明 Austin 脑中的概念，最终导致了一个可用的产品。

**更大图景**

在职业生涯的大部分时间里，Austin 认为某些事情是他无法企及的。如果他需要安装跟踪像素，就必须请工程师来安装。如果需要构建自定义工作流，就必须向支持部门提交工单。

“我会说，几年前，如果你有一个想法要构建像这样的工作流，你可能需要一支工程师团队来支持你，”Austin 说。“现在，有了像 Claude Code 这样的工具，作为一个非技术营销人员，我实际上可以去构建这些东西。所以‘我希望这个存在’和‘我实际上可以自己构建这个’之间的差距，比人们意识到的要小得多。”

他现在已经向同事和客户演示了他的工作流，他们的反应都一样：为什么我们*没有*这样做？

## **营销人员的下一步**

Austin 认为增长营销人员的角色正在迅速演变。“我认为增长营销正在走向几乎像产品经理那样的道路，”Austin 说。“我们不仅能够执行广告活动，我们还能够实际构建产品来帮助我们实现目标。”

Austin 并不是 Anthropic 唯一使用 Claude 进行构建的营销人员。在整个营销组织中，各团队都在取得类似的结果：

* **网红营销** 使用 Claude 为影响者和播客撰写脚本，每月节省 100 多个小时，专注于更高价值的工作
* **客户营销** 将案例研究草稿时间从 2.5 小时缩短到 30 分钟，每周节省 10 小时
* **数字营销** 构建了 Web 开发工作流，使团队生产力同比提高 5 倍
* **产品营销** 使用 Skills 和 Projects 创建发布简报，每次发布节省 5-10 小时
* **合作伙伴营销** 构建了自助式活动支持工具供销售使用，将贸易展准备时间减少了 40%

“大多数营销人员可能以同样的方式对待 AI，他们只是将其视为简化文案写作或头脑风暴等事情的一种方式，”Austin 说。“但他们还没有真正思考过，哪些实际领域是他们可以真正将像 Claude 这样的工具嵌入到自己的工作流中的。”

对于那些采用像 Claude Code 这样工具的团队来说，有一个机会正在出现：花更少的时间在重复执行上，花更多的时间在对自己工作重要的事情上。
