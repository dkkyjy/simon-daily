# 一句话摘要

Claude Code 推出“例程”功能，允许开发者通过计划、API或事件触发自动化软件开发任务。

# 主要观点

1. 例程是Claude Code的自动化功能，可配置提示、仓库和连接器。
2. 例程在Claude Code的网页基础设施上运行，无需依赖本地电脑。
3. 支持按小时、每晚或每周的计划调度运行。
4. 可通过API端点触发，每个例程拥有独立认证令牌。
5. 支持GitHub仓库事件触发，如拉取请求创建。
6. 每个拉取请求会创建独立会话，并持续跟踪后续更新。
7. 常见用例包括夜间问题分类、文档漂移检测和部署验证。
8. 警报分类例程可在值班人员查看前生成修复草案。
9. 例程支持Pro、Max、Team和Enterprise计划用户使用。
10. 每日例程运行次数根据订阅计划有不同限制。

# 核心启示

1. 例程将开发者从管理cron任务和基础设施中解放出来。
2. 通过API集成可将Claude Code嵌入现有工具链和警报系统。
3. GitHub事件触发实现自动化代码审查和跨语言移植。
4. 每个拉取请求的独立会话确保上下文持续跟踪。
5. 使用额度与交互式会话相同，但设有每日运行上限。
