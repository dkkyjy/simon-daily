# Claude 政府版现已正式发布 | Claude 由 Anthropic 出品

**日期：** 2026-09-30 00:00 UTC
**链接：** https://claude.com/blog/claude-for-government-is-now-generally-available

---

今天，[Claude 政府版](https://claude.com/solutions/government) 正式面向联邦和州政府机构发布。该平台通过经 FedRAMP 高级别授权的环境提供 Claude 的编码和代理工作能力，自七月起已进入[公开测试阶段](https://claude.com/blog/bringing-claude-code-and-claude-cowork-to-government)。

政府机构可以访问与 Anthropic 商业客户相当的功能，同时不妥协合规性要求。新功能通常按照商业发布节奏上线。

[Claude](https://claude.com/product/overview) 可直接与桌面上的文件交互，允许机构员工使用技能、插件和项目来创建备忘录、审查招标书、处理案件以及其他任务。借助 [Claude Code](https://claude.com/product/claude-code)，公共部门团队可以构建和现代化支撑公共服务的软件系统。

Claude 政府版的治理控制专为公共部门机构设计。管理员可以设置配置默认值，并在各部门之间分配和控制支出。安全团队和授权官员可以获得审计日志和文档，以支持机构的授权运营（ATO）流程。采购官员可以直接与 Anthropic 签订合同，并在正式发布条款下授标。

Claude Code 命令行界面和 [Claude for Microsoft 365](https://claude.com/claude-for-microsoft-365) 也将在同一环境下并通过相同的行政控制推出早期访问版本。

## 计费、管理和监督

**无席位费用。** 机构按固定增量支付使用费，并设有硬性上限，确保支出不会超过机构承诺的金额。管理员可以为每个用户组定义具有支出和模型限制的用户层级，按用户和模型跟踪使用情况，并在余额不足之前收到消耗预警。

*管理控制台中的支出分析视图*

**与部门组织结构相匹配的管理。** 部门级管理员将预付费使用量分配给下属机构，同时各下属机构管理自己的用户。机构可以连接自己的身份提供商以实现单点登录，并在管理门户中进行自助设置。SCIM 组映射为每个席位层级设置速率限制、金额上限和允许的模型。分层配置为下属机构设置默认值，包括 Claude 可以连接的内容以及可用的功能。

**设计内置监督。** 管理操作记录在组织管理员可以审查的审计日志中。Anthropic 方面的敏感操作需要两人批准。使用量导出仅包含计量数据，因此机构可以在不移动敏感材料的情况下回应 ATO 和 IG 的请求。对话历史保留在机构管理的设备上。

## 开始使用

Claude 政府版今天正式面向联邦和州政府机构发布。机构无需单独的云服务商关系即可开始使用。现有客户可以迁移到桌面应用程序，并通过应用内导入功能携带他们的对话历史。

我们的 [FedRAMP 安全配置指南](https://trust.anthropic.com/resources#6ab2b125752bf0e0e8025505) 可在 Anthropic 的[信任中心](https://trust.anthropic.com/)获取。该应用程序通过标准机构 MDM 平台部署。

新机构可以在 [claude.com/solutions/government](http://claude.com/solutions/government) 申请访问权限。要加入 Claude Code CLI 或 Claude for Microsoft 365 的早期访问，请联系我们的公共部门团队。
