## Claude Enterprise

Claude Enterprise 让您的整个组织能够使用 [Claude](https://claude.com/product/overview)、[Claude Code](https://claude.com/product/claude-code) 和 [Cowork](https://claude.com/product/cowork) —— 同时提供企业级安全能力，并支持处理大型代码库、海量文档集以及广泛的组织上下文。

您的团队可以与 Claude 进行头脑风暴，从网页和终端委托编码任务，或移交复杂的多步骤项目并取回完成的交付成果。借助 [使用插件](https://claude.com/blog/cowork-plugins) 的 Cowork，您可以将 Claude 转变为销售、财务、法务、营销等领域的专家。

Claude 还能与您的团队已在使用的工具协同工作。通过 [连接器](https://claude.com/connectors) 连接到 Microsoft 365、Slack 及其他平台，或通过内置的聊天侧边栏直接在 [Excel](https://claude.com/claude-in-excel) 和 [PowerPoint](https://claude.com/claude-in-powerpoint) 中与 Claude 协作。

Claude Enterprise 包含组织大规模部署 AI 所需的安全和管理控制功能：

* 通过单点登录（SSO）和域名捕获管理用户访问权限，并通过 SCIM 实现自动化配置。
* 审计日志和合规 API 让您的安全和合规团队能够了解 Claude 的使用情况，管理员可以管理整个组织的权限。
* 管理员可以设置自定义数据保留策略，并通过使用情况分析跟踪团队活动、功能采用率和支出。
* Anthropic 默认不会使用 Claude Enterprise 内容训练模型。

## 定价

Claude Enterprise 采用简单的席位加使用量计费模式。使用量按 API 费率计费，因此您的组织只需为实际使用量付费。管理员可以在组织和单个用户级别设置支出上限，以可靠地管理成本。
