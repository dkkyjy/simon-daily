# Anthropic 团队如何使用 Claude Code

**日期：** 2025-07-24 00:00 UTC
**链接：** https://claude.com/blog/how-anthropic-teams-use-claude-code

---

像 [Claude Code](https://www.anthropic.com/claude-code) 这样的智能编码工具能帮助开发者加速工作流程、自动化重复性任务，并处理复杂的编程项目。随着该领域的发展，我们每天都在从用户（包括我们自己的员工）那里了解到新的应用场景。

为了了解更多信息，我们与 Anthropic 的员工进行了交流，以了解他们在工作中如何使用 Claude Code。

虽然他们的许多用例是可以预见的——调试、浏览代码库、管理工作流程——但其他一些用例却让我们感到惊讶。律师构建了电话树系统。营销人员在几秒钟内生成了数百个广告变体。数据科学家在不懂 JavaScript 的情况下创建了复杂的可视化内容。

模式变得清晰：智能编码不仅仅是在加速传统开发。它正在消解技术工作与非技术工作之间的界限，让任何能够描述问题的人都能成为构建解决方案的人。

以下是我们了解到的情况。

### **代码库导航与理解**

公司内的各个团队都使用 Claude Code 来帮助新员工甚至老员工快速熟悉我们的代码库。

我们基础设施团队的新数据科学家将整个代码库提供给 Claude Code，以便快速上手工作。Claude 会读取代码库的 [CLAUDE.md](http://claude.md) 文件，识别相关文件，解释数据管道依赖关系，并显示哪些上游数据源为仪表板提供数据，从而取代了传统的数据目录工具。

我们的产品工程团队将 Claude Code 称为任何编程任务的"第一站"。他们会请 Claude 识别需要检查哪些文件来修复 bug、添加功能或进行分析，从而省去了在构建新功能之前手动收集上下文的耗时过程。

### **测试与代码审查**

智能编码工具尤其受欢迎，因为它们能够自动化两项关键但繁琐的编程任务：编写单元测试和审查代码。

产品设计团队使用 Claude Code 为新功能编写全面的测试。他们通过 GitHub Actions 自动化了拉取请求评论，由 Claude 自动处理格式问题和测试用例重构。

安全工程团队将他们的工作流程从"设计文档 → 粗糙代码 → 重构 → 放弃测试"转变为：向 Claude 请求伪代码，引导其进行测试驱动开发，并定期检查进展。这带来了更可靠、更可测试的代码。

智能编码还可以用于将测试翻译成其他编程语言。例如，当推理团队需要用 Rust 等不熟悉的语言测试功能时，他们会解释想要测试的内容，然后 Claude 用代码库的原生语言编写逻辑。

### **调试与故障排除**

生产问题需要快速解决，但在压力下试图推理不熟悉的代码常常导致延误。对于公司内的许多团队来说，Claude Code 通过实时分析堆栈跟踪、文档和系统行为来加速诊断和修复。

在事件处理期间，安全工程团队将堆栈跟踪和文档提供给 Claude Code，以追踪代码库中的控制流。通常需要 10-15 分钟手动扫描的问题，现在解决速度提高了 3 倍。

借助 Claude Code，产品工程团队获得了处理不熟悉代码库中 bug 的信心。他们直接问 Claude："你能修复这个 bug 吗？我看到了这样的行为"，然后审查提出的解决方案，无需依赖其他工程团队的协助。

在一个实例中，当 Kubernetes 集群停止调度 Pod 时，数据基础设施团队使用 Claude Code 来诊断问题。他们将仪表板截图提供给 Claude，Claude 引导他们逐菜单浏览 Google Cloud 界面，直到发现 Pod IP 地址耗尽。然后 Claude 提供了创建新 IP 池并将其添加到集群的确切命令，在系统宕机期间为他们节省了 20 分钟的宝贵时间。

### **原型设计与功能开发**

构建新功能传统上需要深厚的技术知识和大量的时间投入。Claude Code 支持快速原型设计甚至完整的应用程序开发，让团队无论编程专业水平如何都能快速验证想法。

产品设计团队的成员会将 Figma 设计文件提供给 Claude Code，然后设置自主循环，让 Claude Code 编写新功能的代码、运行测试并持续迭代。他们向 Claude 提出抽象问题，让其自主工作，然后在最终优化前审查解决方案。在一个案例中，他们让 Claude 在几乎没有人工审查的情况下为自己构建了 Vim 键位绑定。

借助 Claude Code，产品设计团队发现了一个意想不到的用途：在设计阶段就映射出错误状态、逻辑流程和系统状态，以识别边缘情况，而不是在开发过程中才发现它们。这从根本上提高了他们初始设计的质量，并在后续节省了数小时的调试时间。

尽管不精通 TypeScript，数据科学家们使用 Claude Code 构建了完整的 React 应用程序，用于可视化强化学习模型的性能。在沙盒环境中进行一次提示后，该工具无需他们理解代码就能从头编写完整的 TypeScript 可视化内容。鉴于任务的简单性，如果第一次提示不够充分，他们会稍作调整并再次尝试。

### **文档与知识管理**

技术文档常常散落在 Wiki、代码注释和团队成员的脑海中。Claude Code 通过 MCP 和 CLAUDE.md 文件将这些知识整合成可访问的格式，让需要的人都能获得专业知识。

没有机器学习背景的推理团队成员依赖 Claude 来解释特定于模型的函数。通常需要一小时谷歌搜索的工作现在只需 10-20 分钟——研究时间减少了 80%。

安全工程团队让 Claude 摄取多个文档来源，以创建 Markdown 格式的运行手册和故障排除指南。这些精简后的文档成为调试实际生产问题的上下文，通常比搜索整个知识库更高效。

### **自动化与工作流程优化**

智能编码工具帮助团队构建自定义自动化，而这传统上需要专门的开发人员资源或昂贵的软件。

增长营销团队构建了一个智能工作流程，处理包含数百个广告的 CSV 文件，识别表现不佳的广告，并在严格的字符限制内生成新的变体。通过使用两个专门的子代理，该系统在几分钟内生成数百个新广告，而不是数小时。

他们还开发了一个 Figma 插件，能够识别框架并通过交换标题和描述来自动生成多达 100 个广告变体，将数小时的复制粘贴工作减少到每批广告半秒钟。

在一个特别独特的用例中，法律团队创建了原型"电话树"系统，帮助团队成员在 Anthropic 联系到合适的律师，展示了部门如何在没有传统开发资源的情况下构建自定义工具。

### **用 Claude Code 解锁新的可能性**

这些故事揭示了一个模式：当你专注于 Claude Code 能够增强的人类工作流程时，它的效果最好。最成功的团队将 Claude Code 视为思维伙伴，而非代码生成器。

他们探索可能性，快速制作原型，并在技术与非技术用户之间分享发现。这种人与 AI 之间的协作方式创造了我们才刚刚开始理解的机会。
