# 中文摘要

## 一句话总结
Claude Code 推出代理视图，让用户在一个界面中管理多个并行会话，提升开发效率。

## 主要观点
1. 代理视图集中管理所有 Claude Code 会话。
2. 用户可同时启动多个代理并发送到后台。
3. 一目了然查看哪些代理等待用户输入。
4. 按左箭头或运行 `claude agents` 打开视图。
5. 每行显示会话状态、最后响应和交互时间。
6. 选中会话可预览最后一轮对话内容。
7. 等待决策的会话可直接内联回复。
8. 使用 `/bg` 将现有会话加入代理视图。
9. 使用 `claude --bg [任务]` 启动后台新会话。
10. 支持扩展并发会话、管理长期运行代理等场景。

## 核心启示
1. 并行处理多个任务时无需切换终端标签页。
2. 后台代理完成后可快速预览结果并继续工作。
3. 长周期任务如 PR 监控可自动显示下次运行时间。
4. 在会话间导航时能无缝启动关联任务。
5. 状态指示器帮助快速识别已生成 PR 的会话。
