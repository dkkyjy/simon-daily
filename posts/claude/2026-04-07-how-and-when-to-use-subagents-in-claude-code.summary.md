# 一句话总结

Claude Code的子代理功能允许在隔离上下文中并行执行独立任务，减少主会话噪音并提升效率。

# 主要观点

1. 子代理是拥有独立上下文窗口的隔离Claude实例，只返回结果。
2. 研究密集型任务适合子代理，避免主会话被大量文件淹没。
3. 无依赖关系的独立子任务可并行执行，显著缩短完成时间。
4. 子代理提供无偏见的审查，不受主会话历史影响。
5. 管道工作流中每个阶段使用子代理可保持专注。
6. 自定义子代理存储在.markdown文件中，支持自动委托。
7. CLAUDE.md文件定义何时使用子代理的规则，保持行为一致。
8. 技能提供可重用的多步骤工作流，按需加载而非始终生效。
9. 钩子在生命周期事件中自动触发子代理工作流。
10. 顺序依赖、同文件编辑和小型任务不适合使用子代理。

# 关键要点

1. 从对话式调用开始，识别重复模式后再构建自动化。
2. 明确指定任务范围、并行执行要求和输出格式以获得最佳效果。
3. 使用自定义子代理为安全审查、测试编写等常见任务创建专家。
4. 子代理间无法相互通信，需要协调时使用代理团队。
5. 探索十多个文件或涉及三个以上独立任务时，强烈建议使用子代理。
