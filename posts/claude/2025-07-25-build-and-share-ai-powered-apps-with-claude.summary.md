# 一句话摘要

Claude 现在支持构建、托管和分享 AI 驱动的应用，用户通过自己的账户认证，开发者无需承担使用成本。

# 主要观点

1. Claude 可创建通过 API 与自身交互的 AI 应用。
2. 用户使用应用时需通过自己的 Claude 账户认证。
3. API 使用量计入用户订阅，而非开发者账户。
4. 开发者无需为他人使用应用支付任何费用。
5. 无需管理 API 密钥，简化了分享流程。
6. Claude 编写真实代码，可查看、修改和自由分享。
7. 支持构建带记忆的 AI 游戏和个性化学习工具。
8. 可创建数据分析应用，支持 CSV 上传和自然语言提问。
9. 应用可通过链接即时分享，无需部署流程。
10. 当前限制包括无外部 API 调用和持久化存储。

# 要点总结

1. 利用用户自己的订阅计费，大幅降低开发者分享成本。
2. 通过自然语言描述即可让 Claude 自动编写应用代码。
3. 支持实时调试和改进代码，基于用户反馈迭代优化。
4. 应用可自由复刻和定制，促进社区协作与创新。
5. 无需处理部署和基础设施，专注于创意实现。
