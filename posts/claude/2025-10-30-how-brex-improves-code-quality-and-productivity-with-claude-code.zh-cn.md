# Brex 如何借助 Claude Code 提升代码质量与生产力

**日期：** 2025-10-30 00:00 UTC
**链接：** https://claude.com/blog/how-brex-improves-code-quality-and-productivity-with-claude-code

---

两年前，当安迪·里德以内容设计师的身份加入 [Brex](https://www.brex.com/) 时，他从未想过自己会编写代码并构建 Figma 插件。

"如果没有 [Claude Code](https://www.anthropic.com/claude-code)，我根本无法想象在过去一个月里如何完成哪怕一半的工作。"里德说道。

但这正是里德拥抱 [Claude Code](https://www.anthropic.com/claude-code)（Anthropic 的智能编码解决方案）后发生的事情——而他的故事，只是这家智能金融平台如何改变其公司工作方式的众多案例之一。

为了了解更多情况，我们采访了三位 Brex 团队成员，了解他们如何使用 Claude Code：

* 赫拉克勒斯·吉梅内斯，产品 AI 团队软件工程主管
* 苏米特·马尔瓦哈，数据与分析主管
* 安迪·里德，高级内容设计师

从这些对话中浮现出的，不仅仅是关于生产力提升的故事——尽管团队报告在特定任务上实现了 3-4 倍的改进。更重要的是，它从根本上重新构想了公司如何协同工作，以简化工作流程、激发创造性问题解决，并推动大规模协作。

## 采用智能编码带来的思维转变

对于赫拉克勒斯·吉梅内斯和产品 AI 团队而言，Claude Code 代表的不仅仅是一个新工具。

"Claude Code 带来了一种思维转变，"他解释道。"你不再处于驾驶座上，而是成为 Claude 所引入变更的审查者。你在引导愿景和方向。"

这种转变重新定义了 Brex 的"编写代码"的含义——反映了公司 AI 优先原则的实际应用。工程师不再花费时间在实现细节上，而是专注于架构和问题解决。结果如何？更好的代码，而不仅仅是更快的代码。

"我不认为使用 Claude Code 节省了时间，"吉梅内斯说。"我反而对问题本身进行了更深入的提炼。你可以在相同的时间内对同一个问题尝试三种方法，经过第三种方法后，你会对问题有更清晰的理解，并得到更简洁的接口。"

## 打破技术与非技术角色之间的壁垒

当产品 AI 团队发现迭代代码质量的新方法时，里德也在经历他自己的启示。

作为一名内容设计师，他在 Claude Code 中发现了一些意想不到的东西：独立性。

以前，更新一个简单的字符串意味着提交一个工单并等待工程师处理。现在，里德可以直接提交 PR，但真正的转变发生在他着手处理一个被无限期搁置的项目时：将全面的内容指南整合到 Brex 设计系统的每个组件中。

"如果手动操作，可能需要花费我几周甚至几个月的时间，"里德解释道。使用 Claude Code，他在几天内完成了这个项目，系统地添加了来自内部风格指南、可访问性标准和外部最佳实践的内容特定指南。

其影响波及了整个团队。工程师和设计师现在可以直接在工具中嵌入内容指南，无需不断交叉引用，并在错误发生之前减少错误。这是一个微小但有力的智能金融工作实例：系统在后台运行，让人们能够专注于更高价值、更具创造性的工作。

## 在整个组织内普及数据访问

与此同时，苏米特·马尔瓦哈的数据与分析团队正在解决一个不同但同样重要的挑战：让 Brex 的每个人都能访问数据，而不仅仅是 SQL 专家。

该团队构建了 Brex Explorer，这是一个由 Claude Code 和 MCP 服务器驱动的文本转 SQL 界面。现在，一位销售经理可以用纯文本提问："在佛罗里达州杰克逊维尔，有多少客户在 Brex 账户中拥有超过 1000 万美元的资金，并且是在过去一年内入住的？"系统会翻译查询、运行它并汇总结果。

真正的乘数效应来自于他们的 AI 数据工程代理。以前需要专业知识才能完成的任务，例如添加包含所有必要文件编辑和测试配置的数据表，现在任何工程师都可以完成。

"这相当于大约 4 倍的速度提升，并且可能有 2 倍更多的人在贡献，"马尔瓦哈指出。Claude Code 在整个组织中的采用率已达到 50%，马尔瓦哈希望到月底实现 100% 的采用率。

## 拥有"万能工具"带来的意外收获

随着 Brex 各个团队采用 Claude Code，一些令人惊讶的用例出现了。在一次公司黑客马拉松中，吉梅内斯使用 Claude Code 的无头模式在短短几小时内构建了一个复杂的提交代理，而这通常需要数天的开发时间。

里德发现他现在可以构建自己从未想象过的工具，比如一个能自动根据 Brex 标准审查设计的 Figma 插件。"感觉就像我拥有了世界上最棒的实习生，"他说。

但也许最显著的意外收获是 Claude Code 作为组织知识库的角色。由于 Brex 使用 Kotlin 和 Bazel 构建的复杂单体仓库结构，理解不同系统如何连接一直是个挑战。现在，Claude Code 充当了一个"神谕"，可以即时回答有关代码库功能的问题。

"传统上，设计会议会讨论某件事应该如何工作，但没有人真正了解内部机制，"里德解释道。"现在我的另一个显示器上就坐着这个神谕。"

## 在公司范围内推广 Claude Code 最佳实践

随着 Claude Code 在 Brex 的采用率不断提高，各个团队开发出了一些已成为标准的最佳实践：

* **结构化上下文管理**：单体仓库中的每个主要目录现在都有自己的 CLAUDE.md 文件，包含特定领域的上下文。新工程师无需依赖隐性知识就能理解 Mastercard 集成细节或银行法规。
* **自动化文档**：产品 AI 团队实施了 CI/CD 检查，当代码变更可能导致文档过时时，会提示更新。"拥有最新的文档是你可以信赖的——这非常强大，"吉梅内斯强调道。
* **上下文感知命令**：团队创建了自动加载相关上下文的自定义命令。例如，/submit-pr 命令在执行前会获取 git 状态、最近的变更以及相关的 PR 信息。
* **从探索开始**："能够找到你需要的东西，不再仅仅存在于某个高级工程师的脑子里，"马尔瓦哈观察到。"它存在于代码库中，对所有人都可访问。"

## Claude Code 在 Brex 的未来

Brex 的团队已经在规划下一代应用：

* 数据团队正准备处理以前无法触及的项目，比如分析数万亿信用卡交易明细数据点，这些工作在 Claude Code 使其变得可行之前，因过于繁琐而无法进行。他们还在开发特定角色的代理，包括一个用于支持 RevOps 任务的代理。
* 产品 AI 团队设想了更复杂的上下文管理，其中文档会自动更新，上下文保持去中心化但仍可访问。

从构建技术工具的内容设计师到普及数据访问的数据分析师，Claude Code 已成为吉梅内斯所说的"万能工具"——用于整合 Brex 的领域知识与外部最佳实践。

它还突显了一个强大的二元性：Brex 为客户提供的智能金融——帮助他们更明智地消费、更快地行动——与塑造 Brex 团队内部工作方式的理念相同，即赋予每位员工以速度和信心进行构建的能力，无论其技术背景如何。
