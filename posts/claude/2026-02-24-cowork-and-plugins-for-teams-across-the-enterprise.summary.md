# 一句话摘要

Anthropic 发布 Claude 企业版更新，新增插件市场、跨应用协作和针对各行业的预建模板。

# 主要观点

1. 插件可将 Claude 转变为面向不同角色和部门的专业代理。
2. 管理员可创建私有插件市场，在整个组织内分发插件。
3. 新增“自定义”统一菜单，整合插件、技能和连接器管理。
4. 斜杠命令现以结构化表单启动，工作流程更直观。
5. 新增 Google Workspace、DocuSign 等十余种企业连接器。
6. 推出 HR、设计、工程等九个行业专用插件模板。
7. 插件是简单可移植的文件系统，可在 Claude Agent SDK 上运行。
8. Claude 现可跨 Excel 和 PowerPoint 端到端处理多步骤任务。
9. 新增 OpenTelemetry 支持，便于管理员追踪使用和成本。
10. 团队和企业管理员可访问公司品牌、配置和 MCP 控制功能。

#  takeaways

1. 企业可通过私有市场自定义 Claude 插件，满足特定团队需求。
2. 预建模板让非技术用户也能快速部署 AI 工作流。
3. 跨应用协作功能让 Claude 像人类一样在工具间传递上下文。
4. 连接器生态扩展使 Claude 能融入现有企业软件栈。
5. 管理员获得更精细的控制权，包括按用户配置和自动安装。
