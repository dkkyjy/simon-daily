# Claude 在 Microsoft Foundry 现已正式可用 | Anthropic 的 Claude

**日期：** 2026年6月29日 00:00 UTC
**链接：** https://claude.com/blog/claude-in-microsoft-foundry

---

自今日起，Claude 模型已在 Microsoft Foundry 正式可用，托管于 Azure 上。Claude 在你的 Azure 环境中运行，使用你的团队已经使用的身份验证、计费和管理控制。你可以选择推理处理的位置，包括为有数据驻留要求的团队提供的美国数据区域。Anthropic 运营推理服务并作为数据处理方。
