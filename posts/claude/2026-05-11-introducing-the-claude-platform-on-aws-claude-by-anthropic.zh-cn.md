# 在 AWS 上推出 Claude 平台 | Anthropic 的 Claude

**日期：** 2026-05-11 00:00 UTC  
**链接：** https://claude.com/blog/claude-platform-on-aws

---

在 AWS 上的 Claude 平台现已正式上线，为 AWS 客户提供了一种新方式，使其能够通过 AWS 身份验证、账单和承诺抵扣来访问 Claude 平台的全部功能。Claude 仍可通过 Amazon Bedrock 使用，其中 AWS 作为数据处理方。

从今天开始，AWS 上的 Claude 平台客户可以使用 [Claude 托管代理](https://claude.com/blog/claude-managed-agents) 大规模部署代理，并使用代码执行、技能、顾问策略等工具进行构建。

## 通过 AWS 访问完整的 Claude 平台

在 AWS 上的 Claude 平台首次为 AWS 客户带来了 Claude API 的完整功能，所有新功能和测试版均在原生 Claude API 上线的同日推出。

身份验证通过 AWS IAM 运行，审计日志通过 CloudTrail 进行，账单通过单一 AWS 发票处理，该发票可完全抵扣现有承诺。客户使用其现有的 AWS 凭证和 IAM 策略，因此团队可以继续使用他们已管理的工具和权限。

在 AWS 上的 Claude 平台将在大多数 AWS 商业区域可用，并支持全球和美国推理区域。
