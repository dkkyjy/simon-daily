# 重新设计桌面版 Claude Code，实现并行代理

            **日期：** 2026-04-14 00:00 UTC
            **链接：** https://claude.com/blog/claude-code-desktop-redesign

            ---

            它包含一个用于管理多个会话的新侧边栏、一个用于布置工作区的拖放布局、一个集成终端和文件编辑器，以及性能和体验方面的改进。

## 全新的桌面体验

对于许多开发者来说，代理式工作的形态已经改变。你不再只是输入一个提示然后等待。你可以在一个仓库中启动重构，在另一个仓库中修复 bug，在第三个仓库中编写测试，随着结果的到来逐一检查，在出现偏差时进行调整，并在发布前审查差异。

新应用程序专为代理式编码的实际感受而构建：多任务并行推进，而你则坐在指挥席上。

## 并行运行会话

新的侧边栏将所有活跃和最近的会话集中在一个地方。在多个仓库中启动工作，并在结果到来时在它们之间切换。

你可以按状态、项目或环境进行筛选，也可以按项目对侧边栏进行分组，以便更快地查找和恢复会话。当某个会话的 PR 合并或关闭时，它会自动归档，以便侧边栏专注于当前活跃的内容。

当你在任务进行中需要提问时，可以打开一个侧边聊天（⌘ + ; 或 Ctrl + ;）来分支出一个对话。侧边聊天会从主线程中提取上下文，但不会向主线程添加任何内容，以避免误导你的任务。

## 无需离开应用即可审查和发布

重新设计将更多常用工具集成到应用中，因此你无需切换到编辑器即可审查、调整和发布 Claude 的工作成果：

* **集成终端**：在会话旁边运行测试或构建。
* **应用内文件编辑器**：打开文件，直接进行局部编辑，并保存更改。
* **更快的差异查看器**：针对大型变更集的性能进行了重建。
* **扩展预览**：除了在预览窗格中运行本地应用服务器外，还可以在应用内打开 HTML 文件或 PDF。

每个窗格都可以拖放。将终端、预览、差异查看器和聊天安排成适合你工作方式的任何网格布局。

## 适配你的技术栈

桌面应用现在与 CLI 插件具有同等功能。如果你的组织集中管理 Claude Code 插件，或者你已自行安装本地插件，它们在桌面应用中的工作方式与在终端中完全相同。

你仍然可以在本地或云端运行会话。SSH 支持现已扩展到 Mac 和 Linux 平台，因此你可以从任一平台将会话指向远程机器。

## 根据你的工作方式进行自定义

三种视图模式——详细、普通和摘要——让你可以将界面从完全透明地展示 Claude 的工具调用调整为仅显示结果。新的键盘快捷键涵盖了会话切换、生成和导航；按下 `⌘ + /`（或 `Ctrl + /`）可查看完整列表。一个新的使用量按钮可让你一目了然地查看上下文窗口和会话使用量。

在底层，应用程序已针对可靠性和速度进行了重建，现在可以在 Claude 生成响应时流式传输响应。

## 开始使用

重新设计的桌面应用现已面向所有 Pro、Max、Team 和 Enterprise 计划的 Claude Code 用户提供，也可通过 Claude API 使用。

[下载应用](https://claude.com/download)，如果你已安装，请更新并重启。探索[文档](https://docs.claude.com/claude-code)以了解更多信息。
