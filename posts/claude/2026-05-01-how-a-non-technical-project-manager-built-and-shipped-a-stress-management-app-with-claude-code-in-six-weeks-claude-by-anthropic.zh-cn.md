就在参加本次采访的视频通话前十五分钟，Kostiantyn Vlasenko 还感到紧张。他满脑子都在想自己要说什么，以至于没有注意到自己的焦虑——但他的手机注意到了。

“应用检测到了这一点，并提醒我：*‘伙计，你可以去做一个简短的箱式呼吸练习。箱式呼吸以前帮你缓解过压力。’*”他说。

这款应用就是 [Respiro](https://apps.apple.com/us/app/respiro-stress-relief/id6758023997)，是 Vlasenko 的创作。虽然他是一名拥有十年经验的项目经理，但在 2026 年 2 月之前，他从未发布过一行代码。那时他决定为 [Built With Opus 4.6 Claude Code 黑客松](https://cerebralvalley.ai/e/claude-code-hackathon?tab=guest-list) 构建一个项目。一个月后，Respiro（一款基于科学原理的压力管理 iOS 应用）便上架了苹果 App Store，拥有数百名用户，并运行在一个包含 15 个以上由 Vlasenko 自行构建和编排的专业子代理的架构上。

他完全是用 Claude Code 完成的，耗时 72 小时，没有团队，也没有编程经验。

## 没有应用能解决的问题

作为位于基辅的 [Mythical Games](https://mythicalgames.com/) 的项目经理，Vlasenko 十年来一直在应对利益相关者的压力、团队动态以及产品发布的无情节奏。他发现呼吸技巧和正念有助于控制压力水平；但他找不到一款能在真正紧张的时刻介入的压力管理工具。

“现有的应用可以在晚上 10 点或任何时间提醒我做深呼吸。但它们不知道我*现在*很紧张，”他解释道。他在乌克兰西部山区度假时，这个想法逐渐成形：构建一款应用，能够实时从个人设备检测压力信号，并在你最需要的时候通过引导式正念呼吸练习进行干预。唯一的问题是他不知道如何构建应用。

## 像管理人一样管理代理

当时，Vlasenko 正在使用 Claude 自动化工作任务，如更新 Jira 和在 Slack 中发布会议记录，并且刚刚开始使用 Claude Code 命令行界面。“然后我想，好吧，我知道我的团队成员是如何用 Claude 写代码的。为什么我不能也这样做呢？”他说。

他很快意识到，他的项目管理背景比编码技能更重要。“我有很多管理真人的经验，”他说。“我意识到这是一回事，只不过是在我的 IDE 里管理代理，我真的很惊讶这竟然这么容易。”

Vlasenko 开玩笑说，他的第一个提示基本上就是 *嗨 Claude，给我一个能让我不那么紧张的应用*，但即便如此，他说，最初的结果还是让他惊叹。“哇，这太令人印象深刻了。这不仅仅是我的想象，它*现在*就在我的手机里，而且确实有效！”

但 Vlasenko 并没有止步于此。他使用 Claude 研究代理系统如何工作，以及哪些苹果 API 可以为他的压力检测逻辑提供数据，然后让 Claude 帮助构建一个多代理架构：一个 TCA 架构代理、一个 Swift 开发者代理、一个 Metal 专家、一个代码审查员等等，所有这些都在不同模块上并行运行。

Claude 还让转向变得轻松：当 Respiro 最初的基于 React Native 的 MVP 因为 Vlasenko 没有 Android 手机进行测试而出现问题时，他使用 Claude Code 在几个小时内用 Swift 从头重写了应用。

总的来说，他说，从最初的想法到功能完备、可上架 App Store 的 Respiro 版本，只花了不到六周时间。

## 从 Claude Code 代码到 App Store

构建应用是一回事。发布它又是另一回事，而 Vlasenko 之前从未接触过苹果开发者计划。他使用 Claude 逐步引导自己完成这个有时令人困惑的过程。

“当我卡住时，我可以截个图然后问 Claude：‘嘿，我该按哪里？’”他说。他用同样的方法设置了其他第三方服务，比如用于日志记录的 Sentry 和用于分析的 Amplitude。“我会告诉 Claude：*我完成了登录，这是 API 密钥*，99% 的情况下 Claude 第一次就能搞定，”Vlasenko 说。另外 1% 的情况，他接着说，“我只需要完善一下，让我在第一个提示中提出的要求更清晰，再多试几次，Claude 就会给我想要的结果。”

事实上，Vlasenko 认为 [Claude 的视觉能力](https://platform.claude.com/docs/en/build-with-claude/vision) 是其最被低估的功能。“你发送一个截图给 Claude 分析，它会告诉你它看到了什么。然后你利用这一点让 Claude 引导你完成最复杂的用户界面，”他解释说。“比如，我需要在 Meta 上创建一个 API 令牌，但在他们的界面里完全迷路了，而 Claude 真的能理解并引导你去任何需要去的地方。”

营销 Respiro 也是一项由 Claude 辅助的工作。当 Vlasenko 需要分析功能时，Claude 不仅仅是集成了 Amplitude 的基础 SDK，而是设置了完整的用户漏斗、留存指标以及日活跃和月活跃用户的跟踪。当他需要内容时，Claude 开始为他撰写博客文章并帮助他制作 TikTok 视频。Claude 还提出了一项 Vlasenko 自称从未想到过的增长策略：联系心理学家和正念实践者，让他们向客户推荐 Respiro。他试了。奏效了。实践者们开始推荐这款应用。

## 创始人模式在行动

Vlasenko 在构建 Respiro 时培养的技能不仅仅用在了他的副业项目上。他现在正以日常工作的身份在 Mythical Games 提交代码发布并直接交付功能。此外，他还成为了自己开发过程中形成的开发流程的内部倡导者，与工程团队分享他的 Claude 文件夹和工作流程。

“大多数人回来说：*嘿，这个工作流程比我现在的要好得多！*”他指出。因此，Mythical 现在有一个小型内部团队完全通过 Claude 交付工作。不过，Vlasenko 观察到，并非所有人都能毫无摩擦地适应这种转变。“有些工程师很难转变心态，不再完全控制每一行代码，”他说。“对我来说很容易，因为我没有深厚的编程背景，这感觉就像一种自然的工作方式。”

对 Vlasenko 来说，构建 Respiro 的经历已经消除了可能与不可能之间的任何界限。他正在将语音引导练习和运动功能加入到应用的下一个版本中，按照 Claude 帮助他编写的路线图进行，并在完成日常工作后每天进行七八个小时的编码工作。

“我会说 Claude Code 是我的新瘾，”他说。
