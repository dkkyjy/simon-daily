# ONE SENTENCE SUMMARY:
Claude Cowork 让非技术知识工作者通过委派多步骤任务来交付成果，无需复制粘贴。

# MAIN POINTS:
1. Claude Cowork 适用于需要交付成果的多步骤任务，而非简单问答。
2. 聊天适合头脑风暴和快速问题，Cowork 适合生成文件或报告。
3. 五个关键特征：多输入、有输出、可重复、知好坏、中间枯燥。
4. 日常简报任务可自动整理 Slack 和邮件，生成每日摘要报告。
5. 预算跟踪通过连接广告平台自动创建实时仪表盘。
6. 报告任务自动从 Google Search Console 拉取数据并生成模板报告。
7. 开始前让 Claude 重复任务并提问，可节省后续修改时间。
8. 提供丰富上下文比优化提示词更能提升输出质量。
9. 聊天用于输出想法，Cowork 用于输出可交付成果。
10. 选择熟悉的任务开始，能快速判断输出是否正确。

# TAKEAWAYS:
1. 从每周重复的枯燥任务开始尝试 Claude Cowork，如数据整理或报告生成。
2. 在提示词中加入“开始前请重复我的要求并提问”，避免误解和返工。
3. 连接多个应用和文件夹提供上下文，而非仅依赖提示词优化。
4. 使用调度功能让任务自动运行，节省日常重复操作时间。
5. 区分聊天和 Cowork：前者用于思考，后者用于交付成果。
