# ONE SENTENCE SUMMARY

Claude Code 通过提示缓存优化实现高效代理系统，其核心原则是保持请求前缀稳定以最大化缓存命中率。

# MAIN POINTS

1. 提示缓存通过前缀匹配复用先前计算，降低延迟和成本。
2. 静态内容应放在提示词开头，动态内容放在末尾。
3. 使用消息而非修改系统提示词来传递更新信息。
4. 会话中途切换模型会导致缓存失效，成本更高。
5. 添加或删除工具会破坏缓存前缀，应避免操作。
6. 计划模式通过工具本身而非切换工具集来保持缓存稳定。
7. 工具搜索使用延迟加载存根，而非移除工具定义。
8. 压缩对话时需使用与父会话完全相同的系统提示词和工具。
9. 缓存命中率应像正常运行时间一样监控，偏差需告警处理。
10. 分支操作必须共享父会话的前缀以复用缓存。

# TAKEAWAYS

1. 设计代理系统时应围绕提示缓存前缀匹配约束构建。
2. 使用消息传递动态信息，避免修改系统提示词导致缓存失效。
3. 通过工具建模状态转换，而非动态切换工具集或模型。
4. 压缩操作需使用与父会话完全相同的参数以确保缓存命中。
5. 监控缓存命中率并设置告警，以控制成本和延迟。
