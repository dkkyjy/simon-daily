## 我们当前保障用户安全的方法

Claude Code 基于权限模型运行：默认情况下为只读模式，这意味着它在进行修改或运行任何命令之前都需要请求许可。这里有一些例外情况：我们通过静态分析自动允许安全命令（如 echo 或 cat），但大多数操作仍需要明确的批准。

但不断点击“批准”会拖慢开发进度，并可能导致“批准疲劳”，即用户可能不会密切关注他们批准的内容。为了让 Claude Code 既更安全又更高效，我们希望找到更好的方法。

## 沙箱：更安全、更自主的方法

沙箱创建了预先定义的边界，Claude 可以在这些边界内更自由地工作，而无需为每个操作请求许可。

通过我们对 Claude Code 的更新，我们正在转向这种方法。我们的沙箱方法基于操作系统级别的功能，支持两项新功能，每项功能都基于以下两套主要边界：

1. **文件系统隔离**，确保 Claude 只能访问或修改指定的目录。这对于防止注入提示的 Claude 修改敏感系统文件尤为重要。
2. **网络隔离**，确保 Claude 只能连接到经过批准的服务器。这可以防止注入提示的 Claude 泄露敏感信息或下载恶意软件。

值得注意的是，有效的沙箱需要同时具备文件系统隔离和网络隔离。如果没有网络隔离，被攻破的智能体可能会泄露敏感文件（如 SSH 密钥）；如果没有文件系统隔离，被攻破的智能体可能轻易逃出沙箱并获得网络访问权限。正是通过同时使用这两种技术，我们才能为 Claude Code 用户提供更安全的智能体体验。

### Claude Code 中的两项新沙箱功能

#### 沙箱化 bash 工具：无需权限提示的安全 bash 执行

今天，我们推出了一个新的沙箱运行时环境（处于研究预览阶段），它允许你精确定义智能体可以访问哪些目录和网络主机，而无需启动和管理容器的开销。该工具可用于沙箱化任意进程、智能体和 MCP 服务器。现在它作为开源研究预览版本在此提供： [GitHub 链接？]

在 Claude Code 中，我们使用这个运行时环境来沙箱化 bash 工具，使 Claude 能够在你设置的限定范围内运行命令。这些命令默认更安全，需要的用户权限提示更少，因此 Claude 可以更自主地运行。如果 Claude 试图访问沙箱*之外*的内容，你会立即收到通知，并可以选择是否允许。

我们基于操作系统级别的原语（如 Linux 的 [bubblewrap](https://github.com/containers/bubblewrap) 和 MacOS 的 seatbelt）构建了此功能，以在操作系统级别强制执行这些限制。它们不仅涵盖 Claude Code 的直接交互，还涵盖由命令生成的任何脚本、程序或子进程。

如上所述，此沙箱强制实施以下两点：

1. **文件系统隔离**，允许对当前工作目录进行读写访问，但阻止修改其外部的任何文件。
2. **网络隔离**，仅允许通过连接到沙箱外部代理服务器的 Unix 域套接字访问互联网。该代理服务器对进程可以连接的域名施加限制，并处理用户对新请求域名的确认。如果你希望进一步提高安全性，我们甚至支持自定义此代理，以对出站流量实施任意规则。

两个组件均可配置：你可以轻松选择允许或禁止特定的文件路径或域名。

沙箱确保即使发生成功的提示注入，也完全被隔离，不会影响用户的整体安全。这样，被攻破的 Claude Code 无法窃取你的 SSH 密钥，也无法向攻击者的服务器发送信息。

若要开始使用此功能，请运行：`claude --sandbox`，并在此处阅读更多关于我们安全模型的技术细节。

#### Claude Code 网页版：在云端安全运行 Claude Code

今天，我们还发布了 [Claude Code 网页版](https://docs.claude.com/en/docs/claude-code/claude-code-on-the-web)，使用户能够在云端的隔离沙箱中运行 Claude Code。Claude Code 网页版在隔离的沙箱中执行每个 Claude Code 会话，使其能够安全地完全访问其服务器。我们设计此沙箱旨在确保敏感凭据（如 git 凭据或签名密钥）永远不会进入沙箱环境。这样，即使沙箱中运行的代码被攻破，用户也能免受进一步危害。

Claude Code 网页版使用一个自定义代理服务，透明地处理所有 git 交互。在沙箱内部，git 客户端使用自定义构建的作用域凭据向该服务进行身份验证。代理验证此凭据以及 git 交互的内容（例如，确保它只推送到已配置的分支），然后在将请求发送到 GitHub 之前附加正确的身份验证令牌。

## 开始使用

我们新的沙箱化 bash 工具和 Claude Code 网页版为使用 Claude 进行工程工作的开发者提供了安全性和生产力的显著提升。

若要开始使用这些工具：

1. 运行 `claude --sandbox` 并查看 [我们的文档](https://docs.claude.com/en/docs/claude-code/sandboxing) 了解如何配置此沙箱。
2. 前往 [claude.com/code](http://claude.ai/code) 试用 Claude Code 网页版。
