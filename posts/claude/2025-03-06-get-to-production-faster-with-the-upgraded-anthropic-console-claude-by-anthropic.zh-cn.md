# 借助升级后的 Anthropic 控制台，更快投入生产 | Anthropic 出品的 Claude

**日期：** 2025-03-06 00:00 UTC
**链接：** https://claude.com/blog/upgraded-anthropic-console

---

我们重新设计了 Anthropic 控制台，将其打造为一个统一的平台，让您和团队成员能够使用 Claude 构建、测试和迭代 AI 部署。

开发人员现在可以在 [Anthropic 控制台](https://console.anthropic.com/) 中直接共享提示词，与团队成员协作。我们还新增了对最新模型 Claude 3.7 Sonnet 的支持，以及控制扩展思考预算的功能。

### 构建可靠的 AI 应用

提示词质量在模型针对特定任务生成响应时起着至关重要的作用。Anthropic 控制台已通过提供编写、评估和优化提示词的工具，简化了 AI 开发流程。

**编写提示词：** 使用工作台来有效组织提示词结构，融入示例，并集成外部工具，在交互式环境中测试 API 调用。

**自动生成提示词：** 描述您想要实现的目标，Claude 将运用链式思维推理等提示工程技巧，生成高效、精准且可靠的提示词。

**评估模型响应：** 通过自动测试用例生成和并排输出对比，在真实场景下评估您的提示词。轻松运行测试套件，对响应质量进行评分，并基于数据做出关于部署哪些提示词的决策。

**优化提示词：** 使用高级提示工程技巧自动优化提示词。这对于适配最初为其他 AI 模型编写的提示词以及优化手工编写的提示词都非常理想。

完成提示词的定稿后，您可以点击"获取代码"，即可获得一个可直接部署的生产级 API 调用。

### 通过可共享的提示词实现协作

开发人员、领域专家、产品经理和 QA 专员通常需要协作优化提示词以获得最佳效果。此前，团队不得不将提示词在文档或聊天应用之间来回复制粘贴，由此引发了版本控制问题和知识孤岛。

Anthropic 控制台中的可共享提示词功能现在提供了一种集中化的方式，让您在整个组织中开发、优化和标准化提示词。团队成员可以访问并协作使用共享的提示词库，从而更容易建立最佳实践，确保所有基于 Claude 的应用保持一致的质量。

### 针对扩展思考优化提示词

[Claude 3.7 Sonnet](https://www.anthropic.com/news/claude-3-7-sonnet) 是我们迄今为止最新、最智能的模型，它能够生成近乎即时的响应，或进行扩展的、逐步的思考过程，并将其呈现给用户。

虽然启用扩展思考后，提示词的使用方式基本相同，但我们使优化提示词以充分利用这一新能力变得轻而易举。只需指定该提示词将配合扩展思考使用，Claude 便会生成尽可能优质的响应。您还可以使用 Anthropic 控制台通过设置最大思考 token 数量来控制思考的*预算*。

### 开始使用

升级后的 Anthropic 控制台现已面向所有用户开放。[登录](https://console.anthropic.com/) 即可开始使用，或浏览我们的[文档](https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering/overview) 以了解更多详情。
