# Claude Cowork 和聊天现已合二为一，成为统一的 Claude | Claude by Anthropic

**日期：** 2026-09-16 00:00 UTC
**链接：** https://claude.com/blog/cowork-is-now-claude

---

从今天起，Claude Cowork 和聊天功能将合并为一个统一的 Claude。无论是快速提问，还是委托一项中午截止的报告，Claude 都能接手处理，即使你已合上笔记本电脑。该功能将在未来几周内逐步向 Pro 和 Max 套餐推出，更多套餐也将陆续支持。

Claude 生成的内容也不再需要单独存放。Claude Docs 和 Claude Slides 于今日全新上线，[Claude Design](https://claude.com/product/design) 现已可在对话中直接使用。请求一份文档，你和 Claude 即可共同撰写；请求一份演示文稿，Claude 便会起草幻灯片。你可以直接编辑、从 Claude 中直接演示，或下载为 PowerPoint 或 PDF 格式。这三项功能目前均处于付费套餐的测试阶段，企业版管理员可自行选择启用时间。如果你单独使用 Claude Design，其功能将保持不变。

我们最初将 Cowork 设计为处理大型任务的独立空间，将 Design 用于视觉设计工作。用户同时使用两者，并反馈最令他们沮丧的是需要判断任务应放在哪里。在一个空间中开始的工作也无法延续到另一个空间。因此，我们不再让你做选择。现在，Claude 可以自行判断任务需求，Cowork 和 Design 的功能均可在任何对话中使用，并保留你已有的上下文、技能和连接器。

> “我可以让 Claude 调取[我的法律研究数据库]，它会检索所有相关案例，阅读它们，判断我可能还需要哪些案例，下载它们，并存储在一个文件夹中供我亲自审阅。”——Andrew Keller，高级经济学家

## 使用示例

一份周报需在中午前提交。出门前，你询问 Claude 上周项目进展，并补充道：“按我们一贯的方式撰写，标出任何延误事项，并将重点内容整理为五张幻灯片，用于管理层会议。”如有不明确之处，Claude 会主动询问。在前往办公室的路上，你可以通过手机查看进度。到达办公桌时，报告已作为一份文档等待你审阅，其中包含同事的批注；幻灯片也已准备就绪，可打开、调整并下载为 PowerPoint 格式。两者均出自同一对话，因此幻灯片已与报告内容保持一致。你可以自行修改某一行，在幻灯片上给 Claude 留下评论，然后分享。将该任务设置为每周一执行，Claude 便会无需提醒自动开始撰写报告。

任何使用 Claude Design、Slides 或 Docs 创建的内容都可通过一个可共享链接访问，可在手机上打开。你可以选中元素并移动，或告诉 Claude 你需要修改的内容。

你可以选择 Claude 与你沟通的方式。默认情况下，Claude 在执行操作前会先询问。如果你希望它继续工作，仅在需要仔细审查时才向你汇报，可以启用该选项。最终决定权始终在你手中。

## 开始使用

如果你主要使用聊天功能，无需做任何改变。当你想委托更复杂的任务时，可以尝试将原本需要自己完成的报告或演示文稿交给 Claude。如果你之前在 Cowork 中工作，所有内容都保留在原处：你的对话、项目、工件、连接器和技能。打开应用后，即可继续之前的工作。

该功能将首先向 Pro 和 Max 套餐推出，在未来几周内，通过网页、桌面和移动端的 Claude 应用，向这些套餐的新老用户逐步开放。无需手动开启。Team 和 Free 套餐将很快跟进，企业版管理员将在其组织发生任何变化前至少 30 天收到通知。

完整功能列表请参阅[帮助中心](https://support.claude.com/en/articles/16761823)。如果你一直有一个复杂的大型项目搁置，现在正是时候。
