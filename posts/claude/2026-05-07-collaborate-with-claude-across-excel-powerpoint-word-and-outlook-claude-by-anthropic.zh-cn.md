从今天起，Claude for Excel、PowerPoint 和 Word 正式全面可用，Claude for Outlook 也在所有付费计划中进入公开测试版。当 Claude 在您的 Microsoft 应用之间切换处理任务时，它会保留您对话的完整上下文。

‍

## **一个对话横跨四个应用**

大多数工作并不局限于单一应用，因此 Claude 会像您一样在应用间移动。在 Outlook 中对一封邮件进行分类处理，在 Word 中打开附件，使用团队模板起草备忘录，在 Excel 中构建支持性分析，然后将其转化为 PowerPoint 演示文稿——所有这些都不需要重新说明您正在做什么。调整 Excel 中的一个假设，PowerPoint 中的图表和 Word 备忘录中的数字也会自动更新。

Claude 可跨打开的文件工作，因此将电子表格、演示文稿和备忘录并排打开，更改即可在它们之间流动。

对话随每个文件持续存在，因此您可以关闭侧边栏，第二天重新打开，然后使用键盘或语音接着上次的进度继续。

## **Claude for Outlook**

Claude for Outlook 将 Claude 引入您的收件箱。让 Claude 对您的收件箱进行分类处理，它会将邮件整理为：需要您回复的、它可以为您起草的、以及属于干扰信息的。回复会以草稿形式出现在 Outlook 的撰写窗格中，并已填写好收件人、主题和正文。日历邀请会检查参与者的空闲情况，并在 Outlook 的原生事件表单中打开。

打开 Word 或 Excel 中的附件时，Claude 已经知道发件人要求什么。您可以在每封回复和每个日历邀请发出之前进行审阅，在您点击“发送”之前，任何内容都不会发送出去。

## **在您的组织中部署 Claude for Microsoft 365**

Claude for Excel、PowerPoint 和 Word 现已全面可用，并具备 IT 管理员和组织所需的控制能力。一个 AppSource 列表涵盖 Excel、PowerPoint 和 Word，另一个单独的列表增加了处于测试阶段的 Outlook。管理员可以从 Microsoft 管理中心部署两者。

企业管理管理员可以配置 [OpenTelemetry](https://support.claude.com/en/articles/14447276-configure-a-custom-opentelemetry-collector-for-office-agents)，将提示、工具调用和文档引用流式传输到他们自己的收集器，以便安全团队精确查看 Claude 在每个应用中的操作。[Analytics API](https://support.claude.com/en/articles/13703965-claude-enterprise-analytics-api-reference-guide) 可按用户、按应用、按天细分活动。

组织可以使用 Claude 账户访问所有四个加载项，或者通过现有的 LLM 网关将流量路由到运行在 Amazon Bedrock、Google Cloud 的 Vertex AI 或 Microsoft Foundry 上的 Claude 模型。

Microsoft 365 Copilot 客户还可以直接在 [Excel](https://support.microsoft.com/en-gb/topic/choose-your-model-when-editing-with-copilot-in-excel-b2c3b3ec-154b-484b-84d0-914a80df395a) 和 [PowerPoint](https://support.microsoft.com/en-gb/topic/choose-your-model-in-agent-mode-25ba645b-2932-4f10-a910-fea4ae76d65c) 中与 Claude AI 模型协作。
