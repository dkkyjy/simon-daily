# 中文摘要

## 一句话总结
Claude Desktop 现已在 AWS、Google Cloud 和 Microsoft Foundry 上提供完整桌面体验，包含聊天、Cowork 和 Code 功能。

## 主要观点
1. 组织可通过现有云环境获得完整的 Claude Desktop 体验。
2. 推理过程在用户配置的云区域中运行，对话历史本地存储。
3. 每个功能模块（聊天、Cowork、Code）拥有独立策略密钥。
4. 员工可使用现有工作账户（如 IAM、Entra ID）单点登录。
5. 支持通过 Intune、GPO 或 Jamf 推送策略模板部署。
6. 离线安装程序适用于气隙环境，无需网络连接。
7. 模型防护可确保路由始终指向 Claude，包括 GovCloud。
8. Microsoft 365 连接器允许访问邮件和文档，支持 GCC High。
9. 本地连接器满足最严格的数据驻留要求。
10. 管理员可在部署前测试所有连接器和模型配置。

## 关键收获
1. 单一部署即可覆盖组织内所有角色和工作场景。
2. 无需共享密钥或云凭证，安全性显著提升。
3. 策略模板支持大规模自动化部署和管理。
4. 数据驻留控制权完全掌握在用户手中。
5. 可逐步扩大访问权限，从非技术团队到工程师。
