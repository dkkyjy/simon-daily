# Anthropic 团队如何使用 Claude Code | Claude by Anthropic

**日期：** 2025-07-24 00:00 UTC
**链接：** https://claude.com/blog/how-anthropic-teams-use-claude-code

---

像 [Claude Code](https://www.anthropic.com/claude-code) 这样的智能编码工具帮助开发者加速工作流程、自动执行重复性任务，并处理复杂的编程项目。随着这一领域的发展，我们每天都能从用户（包括我们自己的员工）那里了解到新的应用场景。

为了进一步了解情况，我们与 Anthropic 的多位员工进行了交流，了解他们在工作中如何使用 Claude Code。

虽然他们的许多用例是可以预见的——调试、浏览代码库、管理工作流——但另一些用例却让我们感到惊讶。律师构建了电话树系统。市场营销人员在几秒钟内生成了数百个广告变体。数据科学家在不了解 JavaScript 的情况下创建了复杂的可视化图表。

模式变得清晰：智能编码不仅加速了传统的开发工作。它正在消解技术工作与非技术工作之间的界限，让任何能够描述问题的人都成为能够构建解决方案的人。

以下是我们学到的内容。

### **代码库导航与理解**

公司各团队使用 Claude Code 帮助新员工甚至老员工快速熟悉我们的代码库。

基础设施团队的新数据科学家将整个代码库提供给 Claude Code，以便快速上手。Claude 读取代码库中的 [CLAUDE.md](http://claude.md) 文件，识别相关文件，解释数据管道依赖关系，并展示哪些上游数据源为仪表板提供数据，取代了传统的数据目录工具。

我们的产品工程团队将 Claude Code 视为任何编程任务的“第一站”。他们让 Claude 识别需要检查哪些文件来修复 bug、添加功能或进行分析，从而省去了构建新功能前手动收集上下文的耗时过程。

### **测试与代码审查**

智能编码工具尤其受欢迎，因为它们能够自动化两项关键但繁琐的编程任务：编写单元测试和审查代码。

产品设计团队使用 Claude Code 为新功能编写全面的测试。他们通过 GitHub Actions 自动化了拉取请求评论，Claude 自动处理格式问题和测试用例重构。

安全工程团队将工作流程从“设计文档 → 粗糙代码 → 重构 → 放弃测试”转变为：向 Claude 询问伪代码，引导其进行测试驱动开发，并定期检查进度。这带来了更可靠、更易于测试的代码。

智能编码还可以用于将测试翻译成其他编程语言。例如，当推理团队需要在不熟悉的语言（如 Rust）中测试功能时，他们会解释想要测试的内容，Claude 则用代码库的本机语言编写逻辑。

### **调试与故障排除**

生产问题需要快速解决，但在压力下试图理解不熟悉的代码常常导致延误。对于公司的许多团队来说，Claude Code 通过实时分析堆栈跟踪、文档和系统行为，加速了诊断和修复过程。

在事故期间，安全工程团队将堆栈跟踪和文档输入 Claude Code，以跟踪代码库中的控制流。通常需要手动扫描 10-15 分钟的问题，现在解决速度提高了 3 倍。

借助 Claude Code，产品工程团队获得了处理不熟悉代码库中 bug 的信心。他们问 Claude：“你能修复这个 bug 吗？这是我看到的行为”，然后审查提出的解决方案，无需依赖其他工程团队的帮助。

在一次实例中，当 Kubernetes 集群停止调度 Pod 时，数据基础设施团队使用 Claude Code 诊断问题。他们将仪表板截图输入 Claude，Claude 引导他们逐个菜单地浏览 Google Cloud 的用户界面，直到找到 Pod IP 地址耗尽的问题。然后 Claude 提供了确切的命令来创建新的 IP 池并将其添加到集群中，在系统中断期间为他们节省了 20 分钟的宝贵时间。

### **原型开发与功能开发**

构建新功能传统上需要深厚的技术知识和大量时间投入。Claude Code 能够实现快速原型开发甚至完整的应用开发，让团队无论编程专长如何，都能快速验证想法。

产品设计团队的成员会将 Figma 设计文件输入 Claude Code，然后设置自主循环，让 Claude Code 为新功能编写代码、运行测试并持续迭代。他们向 Claude 提出抽象问题，让它自主工作，然后在最终优化前审查解决方案。在一次案例中，他们让 Claude 为自己构建 Vim 键盘绑定，几乎没有经过人工审查。

借助 Claude Code，产品设计团队发现了一个意想不到的用途：在设计阶段就绘制错误状态、逻辑流程和系统状态，以识别边缘情况，而不是在开发过程中才发现。这从根本上提高了初始设计质量，并节省了数小时的调试时间。

尽管不熟悉 TypeScript，数据科学家仍使用 Claude Code 构建完整的 React 应用程序来可视化强化学习模型性能。在沙盒环境中进行一次提示后，该工具无需理解代码本身，就能从零编写完整的 TypeScript 可视化代码。由于任务简单，如果第一次提示不够充分，他们会稍作调整后再次尝试。

### **文档与知识管理**

技术文档通常分散在维基、代码注释和团队成员的头脑中。Claude Code 通过 MCP 和 CLAUDE.md 文件将这些知识整合为可访问的格式，使专业知识对需要的人触手可及。

没有机器学习背景的推理团队成员依赖 Claude 来解释特定于模型的函数。通常需要一小时的谷歌搜索现在只需 10-20 分钟——研究时间减少了 80%。

安全工程团队让 Claude 摄取多个文档来源，创建 markdown 运行手册和故障排除指南。这些精简的文档成为调试实际生产问题的上下文，通常比搜索整个知识库更高效。

### **自动化与工作流优化**

智能编码工具帮助团队构建自定义自动化，传统上这需要专门的开发人员资源或昂贵的软件。

增长营销团队构建了一个智能工作流，处理包含数百条广告的 CSV 文件，识别表现不佳的广告，并在严格的字符限制内生成新的变体。使用两个专门的子代理，该系统在几分钟内生成数百条新广告，而非数小时。

他们还开发了一个 Figma 插件，能够识别画板并通过交换标题和描述程序化地生成最多 100 个广告变体，将数小时的复制粘贴工作缩短到每批广告半秒。

在一个特别独特的用例中，法律团队创建了原型“电话树”系统，帮助团队成员在 Anthropic 找到合适的律师，展示了各部门无需传统开发资源就能构建自定义工具的能力。

### **用 Claude Code 解锁新可能**

这些故事揭示了一个模式：当专注于可以用 Claude Code 增强的人类工作流程时，Claude Code 发挥最佳作用。最成功的团队将 Claude Code 视为思维伙伴，而非代码生成器。

他们探索可能性、快速构建原型，并在技术与非技术用户之间分享发现。这种人与 AI 之间的协作方式创造了我们才刚刚开始理解的机会。
