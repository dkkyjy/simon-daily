# 一句话总结

Anthropic 安全团队利用 Claude Code 构建了 CLUE 平台，将威胁检测时间缩短 5-10 倍，误报率从 33% 降至 7%。

# 主要观点

1. CLUE 平台通过自然语言接口连接内部系统，实现自动化威胁检测与响应。
2. 传统安全分析需在五六个工具间切换，调查耗时数小时到数天。
3. CLUE Triage 自动完成告警初筛，为每条告警分配置信度评分。
4. 平台利用 Slack、文档和代码仓库等内部上下文消除告警噪音。
5. CLUE Investigate 支持自然语言查询，平均执行 25 次工具调用和 11 次查询。
6. 30 天内自动化处理 12,000 次查询和 27,000 次工具调用。
7. 团队使用 Claude Code 在一周内完成从原型到设计文档的全流程开发。
8. 数据治理审查任务从半天缩短至几分钟完成。
9. 平台采用非确定性调查路径，允许模型自主探索更优方案。
10. 未来方向包括主动威胁狩猎和基于历史调查的知识库积累。

# 收获

1. 安全团队应利用 AI 整合内部上下文（如聊天记录和文档）来增强告警分析。
2. 给予 AI 工具访问权限和目标而非固定流程，能发现人类忽略的调查路径。
3. Claude Code 可大幅缩短安全工具开发周期，从数月压缩至数天。
4. 自动化告警初筛可释放分析师精力，专注于高优先级威胁。
5. 存储每次调查记录可构建组织级知识库，实现持续学习与改进。
