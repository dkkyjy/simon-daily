# ONE SENTENCE SUMMARY:
Claude Code的钩子系统允许开发者通过自定义脚本在特定事件触发时自动执行操作，消除重复工作并强制执行项目规则。

# MAIN POINTS:
1. 钩子是自定义shell命令，在Claude Code特定事件发生时自动执行。
2. 八种钩子类型覆盖会话启动到工具执行的完整生命周期。
3. PreToolUse钩子在工具执行前触发，用于阻止危险命令或自动批准。
4. PermissionRequest钩子拦截权限对话框，自动批准或拒绝操作。
5. PostToolUse钩子在工具完成后触发，运行格式化工具或检查器。
6. SessionStart钩子注入git状态和TODO列表到会话上下文。
7. Stop钩子检查任务是否完成，可强制Claude继续工作。
8. 钩子配置在项目级、用户级和本地级JSON设置文件中。
9. 匹配器语法支持简单字符串、管道和参数模式过滤工具。
10. 钩子有60秒超时限制，多个匹配钩子并行执行。

# TAKEAWAYS:
1. 从PostToolUse格式化钩子开始，能立即看到效果并快速获得反馈。
2. 使用SessionStart钩子自动注入项目上下文，避免重复输入相同信息。
3. 通过PermissionRequest钩子自动批准频繁运行的测试命令，减少提示疲劳。
4. 使用PreCompact钩子在上下文压缩前备份重要决策和代码片段。
5. 利用调试包装脚本记录钩子输入输出，快速定位配置问题。
