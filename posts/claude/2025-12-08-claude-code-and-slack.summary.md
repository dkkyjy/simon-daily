# 中文摘要

## 一句话总结
Anthropic推出Slack与Claude Code集成功能，允许用户通过@提及直接委托编码任务。

## 主要观点
1. 新功能允许从Slack直接委托任务给Claude Code。
2. 工程上下文通常存在于Slack对话中，包括错误报告和功能请求。
3. 用户可通过@Claude自动启动编码会话。
4. 支持错误调查、代码审查和协作调试。
5. Claude会自动收集Slack线程和频道中的上下文。
6. 系统基于已验证的仓库自动选择运行环境。
7. 编码会话进行时，Claude会发布状态更新。
8. 完成后提供完整会话链接和拉取请求链接。
9. 需先安装Slack应用并验证Claude账户。
10. 功能目前处于测试阶段，作为研究预览。

## 关键要点
1. 通过Slack上下文无缝启动编码会话。
2. 自动收集对话信息以指导编码任务。
3. 支持多种编码任务类型：错误修复、代码审查、调试。
4. 实时状态更新和完整会话记录可追溯。
5. 需提前配置Slack应用和Claude Code Web访问权限。
