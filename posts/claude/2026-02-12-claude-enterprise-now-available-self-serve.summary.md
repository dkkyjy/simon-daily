# 一句话总结

Anthropic 推出 Claude Enterprise 自助服务，为企业提供安全、可扩展的 AI 协作工具套件。

# 主要观点

1. Claude Enterprise 包含 Claude、Claude Code 和 Cowork 三大核心产品。
2. 支持单点登录、SCIM 自动配置和域捕获等企业级安全控制。
3. 管理员可设置自定义数据保留策略并跟踪团队活动与支出。
4. 默认情况下，Anthropic 不会使用 Claude Enterprise 内容训练模型。
5. 销售团队可快速搜索邮件和日历信息准备客户会议。
6. 工程团队通过 Claude Code 加速整个软件开发生命周期。
7. 营销团队可起草、翻译和优化内容并保持品牌一致性。
8. 财务团队直接在 Excel 中进行深度数据分析与预测建模。
9. 采用简单的按席位加按用量计费模式，按 API 费率收费。
10. 支持 Microsoft 365、Slack 等平台连接及 Excel 和 PowerPoint 侧边栏。

# 核心启示

1. 企业可通过自助服务快速部署 AI，无需定制合同或销售沟通。
2. Cowork 插件功能可将 Claude 转化为销售、财务等领域的专业助手。
3. 管理员可为组织和个人设置支出上限以有效控制成本。
4. 审计日志和合规 API 为安全团队提供完整的使用可见性。
5. 需要 HIPAA 合规或专用支持的企业仍可联系销售团队。
