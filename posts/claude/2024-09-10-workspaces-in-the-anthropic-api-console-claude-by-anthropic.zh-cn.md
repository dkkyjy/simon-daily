# Anthropic API 控制台中的工作区 | Anthropic 的 Claude

**日期：** 2024-09-10 00:00 UTC
**链接：** https://claude.com/blog/workspaces

---

我们已在 Anthropic API 控制台中推出工作区（Workspaces）功能，帮助开发者高效管理多个 Claude 部署。工作区是独立的环境，使您能够组织资源、简化访问控制，并在更细粒度的层面上设置自定义支出限额和速率限制。

## 管理多个部署

对于在不同环境（如开发、预发布和生产环境）以及不同用例中使用 Claude 的开发者，工作区为您的整体组织和各个 API 密钥提供了一层抽象。

**借助工作区，您可以：**

* **设置细粒度的支出限额**：按工作区设置每月支出限额，从而对 API 使用成本进行精细控制。
* **分组相关资源**：将 API 密钥、使用数据和设置组织为与您的项目或环境相对应的逻辑组。
* **管理速率限制**：独立调整每个工作区的速率限制，同时保持在整体组织速率限制的范围内，从而更好地管理各部署的负载。
* **简化访问控制**：通过在工作区级别分配用户权限来提高账户安全性。
* **高效监控使用情况**：获取按工作区分列的 API 使用情况和成本洞察，使资源分配的跟踪与优化更加便捷。

## 快速入门

工作区现已面向 Anthropic API 控制台的所有用户开放。要开始使用，您可以[在此处](https://console.anthropic.com/settings/workspaces)创建一个带有工作区级别 API 密钥的工作区。如需了解更多详情，请访问我们的[帮助中心](https://support.anthropic.com/en/articles/9796807-creating-and-managing-workspaces)查看详细指南。
