# 一句话摘要

Claude Code推出自动模式，通过分类器在安全与效率间取得平衡，减少人工审批但保留风险防护。

# 主要观点

1. 自动模式让Claude代表用户做出权限决策，并带有安全监控。
2. 默认权限模式每次文件写入和bash命令都需人工批准。
3. 跳过所有权限可能导致危险和破坏性后果。
4. 自动模式在每次工具调用前由分类器审查潜在危险操作。
5. 安全操作自动执行，危险操作被阻止并引导Claude改用其他方法。
6. 持续被阻止的操作最终会触发用户权限提示。
7. 自动模式不能完全消除风险，建议在隔离环境中使用。
8. 分类器可能因用户意图模糊或环境上下文不足而允许风险操作。
9. 自动模式可能对令牌消耗、成本和延迟产生轻微影响。
10. 管理员可通过托管设置禁用自动模式，开发者需运行启用命令。

# 核心启示

1. 自动模式提供比完全跳过权限更安全的中庸方案。
2. 分类器可识别文件批量删除、数据泄露和恶意代码执行等风险。
3. 该功能支持Claude Sonnet 4.6和Opus 4.6两个模型版本。
4. 团队计划用户可立即体验，企业版和API用户即将获得。
5. 桌面应用默认禁用自动模式，需在组织设置中手动开启。
