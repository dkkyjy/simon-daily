# Claude 现已可在 Microsoft 365 Copilot 中使用 | Anthropic 的 Claude

**日期：** 2025-09-24 00:00 UTC
**链接：** https://claude.com/blog/claude-now-available-in-microsoft-365-copilot

---

今天，微软宣布 Claude 模型现已可在 Microsoft 365 Copilot 中使用，通过微软的生产力平台将 Claude 带给数百万企业用户。

从微软的 Researcher 智能体和 Copilot Studio 开始，企业客户现在可以选择 Claude Sonnet 4 和 Opus 4.1，与现有模型选项一起使用，为组织提供更大的灵活性，以便根据特定业务需求选择合适的人工智能。

Claude Sonnet 4 和 Claude Opus 4.1 的加入，帮助微软将业界最佳的人工智能创新引入 Microsoft 365 Copilot，针对工作场景进行优化，并根据您的业务需求量身定制。

**Anthropic 模型在 Microsoft 365 Copilot 中的呈现方式：**

* **Researcher 智能体**：微软的推理智能体现可由 Claude Opus 4.1 驱动。无论您是在制定详细的市场进入策略、分析新兴产品趋势，还是创建全面的季度报告，您现在都可以选择偏好的模型来驱动深度工作。Researcher 帮助您处理复杂、多步骤的研究——不仅推理网络和可信的第三方数据，还包括您的工作内容（电子邮件、聊天、会议、文件等），按需提供高度专业的专业知识——现在您有了模型选择。
* **Copilot Studio**：Claude Sonnet 4 和 Claude Opus 4.1 模型现已在 Copilot Studio 中作为模型选项提供，使您能够轻松创建和定制企业级智能体。借助此次发布，您可以构建、编排和管理由 Anthropic 模型驱动的智能体，用于深度推理、工作流程自动化和灵活的智能体任务。通过 Copilot Studio 中的多智能体系统和提示工具，您可以根据需要选择 Claude 执行专门任务。

一旦您选择加入，就能轻松在 Researcher 中选择 Claude。

Claude Opus 4.1 现已可在微软的 Researcher 智能体中使用，使团队能够处理由 Anthropic 业界领先人工智能驱动的复杂多步骤研究。

**入门指南**

Researcher 中的 Claude 从今天开始通过微软的 Frontier 计划向选择加入的 Microsoft 365 Copilot 许可客户推出。要构建智能体，用户也可以通过 Frontier 计划选择加入，在 Copilot Studio 中试用 Claude。Anthropic 模型托管在微软管理环境之外，并受 Anthropic 服务条款约束。要开始使用，组织的管理员可以在 Microsoft 365 管理中心中启用对 Anthropic 模型的访问权限。了解更多信息，请点击[此处](https://go.microsoft.com/fwlink/?linkid=2334803)。

敬请期待 Microsoft 365 生态系统中更多 Claude 体验，并访问 [anthropic.com/enterprise](http://anthropic.com/enterprise) 了解 Claude 的企业级功能以及我们对安全、可信赖人工智能的承诺。更多详细信息请参阅[微软的发布博客](https://www.microsoft.com/en-us/microsoft-365/blog/2025/09/24/expanding-model-choice-in-microsoft-365-copilot/)。
