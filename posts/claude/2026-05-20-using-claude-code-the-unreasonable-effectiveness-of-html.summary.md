# ONE SENTENCE SUMMARY:
作者主张用HTML替代Markdown作为Claude Code的输出格式，以获得更丰富、可读性更强的AI协作体验。

# MAIN POINTS:
1. Markdown在信息密度和视觉呈现上已无法满足AI协作需求。
2. HTML能承载表格、CSS、SVG、JavaScript等丰富内容类型。
3. HTML文档比Markdown更易阅读，支持标签页和响应式设计。
4. HTML文件可直接在浏览器中分享，无需额外转换。
5. HTML支持滑块、按钮等交互元素，实现双向调整。
6. Claude Code可读取代码库、MCP和Git历史生成HTML文件。
7. 简单的提示如“制作HTML文件”即可让Claude生成高质量文档。
8. HTML适用于规格说明、代码审查、原型设计和报告生成。
9. 自定义编辑界面可导出JSON或Markdown，形成高效工作循环。
10. HTML虽消耗更多token，但可读性提升使整体效率更高。

# TAKEAWAYS:
1. 在AI协作中，优先使用HTML而非Markdown来呈现复杂信息。
2. 利用HTML的交互性创建可调整的编辑界面，优化工作流。
3. 将HTML文件作为共享文档格式，提高团队阅读和反馈率。
4. 使用HTML进行代码审查和原型设计，提升视觉理解效率。
5. 保持多个HTML文件作为规划参考，而非单一Markdown计划。
