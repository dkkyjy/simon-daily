# 一句话摘要

Claude Enterprise 推出更精细的管理分析、模型权限和支出警报，帮助管理员掌控使用与成本。

# 主要观点

1. 新分析仪表板可按组和用户显示使用量与成本。
2. Claude Code 新增“使用”和“价值”标签页，展示开发者活跃度。
3. 分析聊天支持自然语言提问，返回可导出的图表。
4. 分析 API 可将数据集成到 Datadog 和 CloudZero 等工具。
5. 用户可查看个人使用趋势，包括产品、模型和技能。
6. 模型默认设置允许管理员为对话选择成本更低的模型。
7. 支出阈值警报在 75% 和 90% 时通知管理员。
8. 用户在 75% 和 95% 时收到应用内通知并可请求提升限额。
9. 管理 API 支持自动化成本控制工作流程。
10. 管理员可按 SCIM 组过滤数据，匹配现有组织架构。

# 收获

1. 利用分组分析追踪团队级 Claude 使用模式。
2. 设置模型默认值以优化日常工作的成本。
3. 配置支出警报避免用户任务中断。
4. 通过分析 API 将数据集成到现有财务系统。
5. 赋予用户可见性以减少意外限额拦截。
