# ONE SENTENCE SUMMARY:
Claude Code 推出自动化安全审查功能，通过终端命令和 GitHub Actions 在开发周期早期发现并修复代码漏洞。

# MAIN POINTS:
1. 新的 /security-review 命令允许在提交前从终端运行安全分析。
2. 该命令使用专门提示检查 SQL 注入、XSS 等常见漏洞模式。
3. 识别问题后，可要求 Claude Code 自动实施修复方案。
4. 新的 GitHub Action 可在每次打开拉取请求时自动分析代码。
5. 该 Action 会在 PR 上内联发布评论，包含发现的问题和修复建议。
6. 可自定义规则过滤误报和已知问题，确保审查流程一致性。
7. Anthropic 内部已使用这些功能保护其生产代码安全。
8. 该工具曾发现内部工具中的远程代码执行漏洞并阻止其合并。
9. 另一个案例中，代理系统的 SSRF 漏洞被自动标记并修复。
10. 所有 Claude Code 用户现在均可使用这两项安全审查功能。

# TAKEAWAYS:
1. 将安全审查集成到内部开发循环中，可在问题最易修复时发现它们。
2. 自动化 PR 审查为整个团队创建一致的安全基线流程。
3. 自定义规则能力可有效减少误报，提高审查效率。
4. 终端命令和 CI/CD 集成提供了灵活的安全审查工作流选择。
5. Anthropic 自身案例证明该工具能捕获真实世界的严重安全漏洞。
