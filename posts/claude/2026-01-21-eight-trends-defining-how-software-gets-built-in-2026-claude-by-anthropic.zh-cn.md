# 定义2026年软件构建方式的八大趋势 | Claude by Anthropic

**日期：** 2026-01-21 00:00 UTC

编码代理现在是协作者。

2025年，工程团队发现AI能够处理整个实施工作流程：编写测试、调试故障、导航复杂代码库。2026年，我们预测这些能力将显著扩展。

我们的新报告识别了八项我们预测将定义今年代理编码的趋势，分为三个类别：**基础趋势**——改变开发方式，**能力趋势**——扩展代理所能完成的任务，以及**影响趋势**——影响业务成果。

那些领先的组织并没有将工程师从循环中移除，而是让工程师的专业知识在最关键的地方发挥作用。

### **我们正在看到的**

软件开发生命周期正经历自图形用户界面以来最重大的变革之一。工程师正从编写代码转向协调编写代码的代理，将自身的专业知识聚焦于架构、系统设计和战略决策。

在研究开发者实际如何与AI协作的过程中，出现了一个关键细微差别：这种转型依赖于主动协作。

我们社会影响团队的研究表明，虽然开发者在约60%的工作中使用AI，但他们报告称只能“完全委托”0-20%的任务。AI作为一个持续的协作者，但有效使用它需要监督、验证和人类判断。

### **实践中这意味着什么**

各行各业的组织正在将这些模式付诸实践，平衡代理自主性与人类监督，以在不牺牲质量的前提下更快交付。

[Rakuten](https://claude.com/customers/rakuten) 的工程师在 Claude Code 上测试了一项复杂的技术任务：在 vLLM（一个1250万行代码的代码库）中实现激活向量提取方法。Claude Code 在七小时的自主工作中完成了任务，达到了99.9%的数值精度。

[TELUS](https://claude.com/customers/telus) 团队创建了超过13,000个定制AI解决方案，同时将工程代码交付速度提升了30%，总计节省了超过50万小时。

[Zapier](https://claude.com/customers/zapier) 整个组织实现了89%的AI采用率，内部部署了800多个代理。

### **前进之路**

对于规划2026年优先事项的组织，有四个领域需要立即关注：掌握多代理协调、通过AI自动化审查扩展人机代理监督、将代理编码扩展到工程团队之外，以及从最初阶段嵌入安全架构。

那些将代理编码视为战略优先事项的组织将定义未来可能实现的目标。
