# 引入动态工作流

**日期：** 2026-05-28 00:00 UTC
**链接：** https://claude.com/blog/introducing-dynamic-workflows-in-claude-code

---

**更新：** 动态工作流现已全面可用。

今天我们在 Claude Code 中引入动态工作流，帮助 Claude 端到端地承担最具挑战性的任务。那些通常需要按季度规划的工作，现在只需数天即可完成。Claude 动态编写编排脚本，在单个会话中运行数十到数百个并行子代理，并在任何结果到达你之前自行检查工作。

有些问题对于单个代理的单次处理来说过于庞大，尤其是在复杂、遗留的代码库中：跨整个服务的漏洞排查、涉及数百个文件的迁移、在提交前需要从各个角度进行压力测试的计划。动态工作流可以端到端地处理所有这些任务。

动态工作流现已在 Claude Code CLI、桌面版和 VS Code 扩展中向 Pro、Max、Team 和 Enterprise 计划用户提供，同时也适用于 Claude API、Amazon Bedrock、Vertex AI 和 Microsoft Foundry。

注意：动态工作流消耗的 token 量可能远超典型的 Claude Code 会话，因此我们建议从范围较小的任务开始，以便在工作中感受其使用情况。

为获得最佳体验，请在使用动态工作流时开启自动模式。从那里开始，你有两种方式启动工作流：

1. 直接要求 Claude 创建动态工作流（例如，"创建一个工作流"），或
2. 开启一个名为 `ultracode` 的 Claude Code 专用设置。该设置可通过努力程度菜单访问，它将努力程度设为 xhigh，同时让 Claude 自动决定何时使用工作流来处理你的任务。

## **动态工作流实战**

早期用户和 Anthropic 内部的团队已在广泛用例中使用动态工作流，包括：

* **代码库范围的漏洞排查、分析器引导的优化审计和安全审计：** Claude 并行搜索服务或仓库，然后对每个发现进行独立验证，使报告仅呈现真实问题。同样的模式也适用于加固审查：跨整个代码库的认证检查、输入验证和不安全模式。
* **大规模迁移和现代化改造：** Claude 可以处理框架替换、API 弃用、跨数千个文件的端到端语言移植。
* **需要双重检查的关键工作：** 当错误答案的代价很高时，工作流让 Claude 独立尝试解决问题，并安排对抗性代理在你看到结果之前尝试推翻结果。

### **使用动态工作流重写 Bun**

动态工作流在规模化应用中的一个示例是最近对 Bun 的重写。Jarred Sumner 使用动态工作流将 Bun 从 Zig 移植到 Rust，现有测试套件通过率达到 99.8%，生成了约 75 万行 Rust 代码，从首次提交到合并仅用十一天。一个工作流为 Zig 代码库中每个结构体字段映射了正确的 Rust 生命周期。下一个工作流将每个 .zig 文件的行为等同地移植为对应的 .rs 文件，数百个代理并行工作，每个文件配备两名审查员。随后一个修复循环驱动构建和测试套件，直到两者均运行无误。移植完成后，一个夜间工作流处理了不必要的数据拷贝，并为每个问题创建了拉取请求以供最终审查。虽然尚未投入生产，但所有这些都由动态工作流处理。Jarred 未来将对此进行更详细的介绍。

## **工作原理**

当工作流启动时，Claude 根据你的提示动态规划，将其分解为子任务，并将工作分发给并行运行的子代理。结果在整合前经过检查，你最终得到的是一个协调一致的答案。代理从独立角度解决问题，其他代理试图反驳它们的发现，运行过程持续迭代直到答案收敛——这正是工作流能够取得单次处理无法达到的结果的方式。

动态工作流专为并行和长时间运行的任务而设计，这些任务可能持续数小时甚至数天，完成以前需要数周的最复杂工程工作。进度在运行过程中持续保存，因此被中断的任务可以从断点处继续，而无需重新开始。由于协调发生在对话之外，无论任务规模多大，计划都能保持正轨。

需要注意的是，动态工作流消耗的使用量明显高于典型的 Claude Code 会话。当工作流首次触发时，Claude Code 会显示即将运行的内容并要求你确认。组织管理员还可以通过管理设置选择性地禁用工作流。

## **开始使用**

对于 Max、Team 和 Enterprise 计划用户，以及通过 API 使用 Claude Code 的用户，动态工作流默认开启。Pro 计划用户可以在 `/config` 中启用。要求 Claude 创建工作流或开启 Claude Code 专用设置 `ultracode` 即可开始使用。管理员可以在[设置](https://code.claude.com/docs/en/settings)中管理可用性。

阅读[文档](https://code.claude.com/docs/en/workflows)了解更多信息。
