# 一句话总结

CLAUDE.md文件为AI编码助手提供项目持久上下文，消除重复解释并提升代码协作效率。

# 主要观点

1. CLAUDE.md是存储在仓库中的特殊配置文件，提供项目特定上下文。
2. 文件可放在仓库根目录、父目录或主文件夹中灵活使用。
3. 包含架构上下文、工作流程和开发工具连接等核心功能。
4. `/init`命令自动分析代码库并生成初始配置。
5. 通过项目摘要和目录结构为Claude提供代码库地图。
6. 记录自定义工具和MCP服务器以扩展Claude能力。
7. 定义标准工作流程确保Claude在修改前思考。
8. 使用`/clear`重置上下文避免累积无关信息。
9. 子代理维护隔离上下文防止信息干扰新任务。
10. 自定义命令存储在`.claude/commands/`目录中可重复使用。

# 要点总结

1. 从简单基础开始，根据实际摩擦点逐步扩展文件内容。
2. 避免包含敏感信息如API密钥或数据库连接字符串。
3. 将定制视为持续实践，随项目演变不断优化。
4. 使用子代理处理多阶段工作以保持分析清晰。
5. 创建自定义命令减少重复提示，提高工作效率。
