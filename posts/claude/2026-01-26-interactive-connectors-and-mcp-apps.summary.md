# ONE SENTENCE SUMMARY:
Claude 推出 MCP Apps 交互式连接器，让用户在不切换标签页的情况下，直接在对话中操作 Figma、Slack 等工具并实时协作。

# MAIN POINTS:
1. MCP Apps 将工具作为交互式连接器嵌入 Claude 对话中。
2. 用户可直接在 Claude 中构建和更新 Asana 项目时间线。
3. 支持在 Slack 中草稿、编辑和发送格式化消息预览。
4. Figma 集成可将文本和图像转化为流程图或甘特图。
5. 基于开放标准模型上下文协议（MCP）构建。
6. MCP Apps 是 MCP 的新扩展，支持丰富用户界面。
7. 开发者可在任何支持 MCP 的 AI 产品中构建交互式 UI。
8. 首批支持的应用包括 Amplitude、Box、Canva 等。
9. Salesforce 集成即将推出，支持企业级上下文协作。
10. 免费、专业、团队和企业版用户均可使用。

# TAKEAWAYS:
1. 利用 MCP Apps 在 Claude 中实时协作，无需切换应用标签页。
2. 通过交互式图表和参数调整，深入探索数据分析洞察。
3. 在对话中直接创建并自定义演示文稿和品牌设计。
