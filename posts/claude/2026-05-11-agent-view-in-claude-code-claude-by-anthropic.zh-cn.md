今天我们推出 Claude Code 中的代理视图：一个管理所有 Claude Code 会话的集中位置。

以前在并行运行代理时，你可能不得不管理多个终端标签页、一个 tmux 网格，以及一份过载的心智清单，记录接下来需要处理什么。

借助 Claude Code 中的代理视图，你可以启动新代理、将其发送到后台，并且只在 Claude 需要你时才介入。一眼就能看出哪些代理在等待你、哪些仍在工作、哪些已完成，从而轻松同时操控多个代理。

## 工作原理

代理视图改进了在 CLI 中可视化和交互 Claude Code 会话的方式。

### 一目了然

从任意会话中按左箭头键，或在终端中运行 `claude agents`，即可打开代理视图。每一行都会显示会话、是否需要你的输入、上次响应的内容以及你上次与其交互的时间。

### 无需离开即可预览并回复

选择某个会话即可预览最后一轮对话。如果会话正在等待决策，直接内联回答，会话就会继续。按回车键可直接附加到你想查看完整记录的会话中。

### 任意任务放入后台

最后，用户可以通过 `/bg` 将任何现有会话添加到代理视图中，或者完全跳过前台，使用 `claude --bg [任务]` 启动一个全新的会话。

## 开发者如何使用代理视图

以下是一些早期用户的使用模式：

* **扩展并发会话数量：** 同时发送多个想法，每个可选配一项技能，然后返回查看一系列准备好审查的拉取请求。
* **管理长时间运行的代理：** PR 监控器、仪表盘更新器以及其他循环任务会在列表中直接显示下次运行时间。
* **在独立会话之间导航：** 当你在某个会话进行中时，按左箭头键启动一个相关任务或快速代码库问题，然后按右箭头键回到原来正在做的事情。预览会在答案到达时显示。
* **查看已发布的内容：** 每行上的状态指示器加上预览中的标题，让你轻松扫描哪些会话生成了 PR。

## 入门指南

代理视图今日起作为研究预览版在 Pro、Max、Team、Enterprise 以及 Claude API 方案中提供。通过运行 `claude agents` 选择加入。适用常规速率限制。更多信息请参见[文档](https://code.claude.com/docs/en/agent-view)。
