# Claude Code 远程 MCP 支持 | Anthropic 的 Claude

**日期：** 2025-06-18 00:00 UTC  
**链接：** https://claude.com/blog/claude-code-remote-mcp

---

今天，我们宣布在 Claude Code 中支持远程 MCP 服务器。连接你最喜欢的工具和数据源，个性化你的编码体验，而无需管理本地服务器。

### **将 Claude Code 作为你的主要开发界面**

Claude Code 可以访问 MCP 服务器暴露的工具和资源，使其能够从第三方服务中获取上下文——例如开发工具、项目管理系统和知识库——并在这些服务中执行操作。

你可以将 Claude Code 与任何远程 MCP 服务器集成，而不断增长的服务器生态系统意味着新功能正在持续上线。

例如，通过将 Claude Code 与 Sentry MCP 服务器集成，你可以访问 Sentry 中的错误和问题。然后，你可以在不离开终端的情况下，利用这些问题的上下文进行调试。

你还可以将 Claude Code 与 Linear MCP 服务器集成，以便在你的活跃项目上下文中工作。

“Linear 的 MCP 集成将 Linear 项目和问题直接带入 Claude Code，”Linear 工程主管 Tom Moor 分享道。“通过来自 Linear 的结构化、实时上下文，Claude Code 可以拉取问题详情和项目状态——工程师现在可以在规划、编写代码和管理问题之间保持流畅。更少的标签页，更少的复制粘贴。更好的软件，更快地完成。”

### **无缝连接，维护量最小**

远程 MCP 服务器提供了一种比本地服务器维护量更低的替代方案：只需将供应商的 URL 添加到 Claude Code 中——无需手动设置。供应商负责更新、扩展和可用性，因此你可以专注于构建，而不是管理服务器基础设施。

Claude Code 还原生支持远程 MCP 服务器的 OAuth 认证，确保与你现有账户的安全连接。只需一次认证到你的服务器，Claude Code 就会处理其余部分——无需管理 API 密钥或存储凭据。

### **开始使用**

远程 MCP 服务器支持现已可在 Claude Code 中使用。查看[文档](https://docs.anthropic.com/en/docs/claude-code/mcp)开始使用，或探索我们的[MCP 目录](http://anthropic.com/partners/mcp)，其中包含推荐的服务器。
