# Claude for Enterprise

            **日期：** 2024-09-10 00:00 UTC
            **链接：** https://claude.com/blog/claude-for-enterprise

            ---

            今天，我们宣布推出 [Claude 企业版计划](https://www.anthropic.com/enterprise)，帮助组织安全地与 Claude 协作，利用内部知识。

拥有更多上下文的团队能做出更好的工作。Claude 企业版计划提供扩展的 50 万 token 上下文窗口、更多使用容量以及原生 GitHub 集成，使您能够与 Claude 一起处理整个代码库。它还包含企业级安全功能——如单点登录、基于角色的权限和管理工具——帮助保护您的数据和团队。

借助 Claude，您的组织知识更易于共享和重复使用，使团队中的每个人都能快速且一致地产出最佳成果。同时，您的数据得到保护。我们不会使用您的对话和内容来训练 Claude。要开始使用企业版计划，请[联系我们的销售团队](https://www.anthropic.com/contact-sales)。

## 企业级控制

企业版计划引入了关键的安全和管理控制功能，优先考虑管理和保护您公司的敏感数据，包括：

* **单点登录 (SSO) 和域名捕获**：安全管理用户访问并集中控制配置。
* **具有细粒度权限的基于角色的访问**：为工作区指定主要所有者，以增强安全性和信息管理。
* **审计日志**：追踪系统活动以进行安全和合规监控。审计日志将在未来几周内推出。
* **跨域身份管理系统 (SCIM)**：自动化用户配置和访问控制。SCIM 也将在未来几周内推出。

## 企业功能

通过将 Claude 与您组织的知识相结合，您可以在比以往更多的项目、决策和团队中扩展专业知识。

借助企业版计划，您可以使用扩展的 **50 万 token 上下文窗口**与 Claude 协作——相当于数百份销售记录、数十份 100 多页的文档或中等规模的代码库。摄入知识使 Claude 能够提供深入的、特定功能的指导。

我们还为工程团队推出了**原生 GitHub 集成**，用于将 GitHub 仓库与 Claude 同步。现在，您可以在代码库旁工作，迭代新功能、调试问题或培训新工程师。GitHub 是我们正在构建的原生集成中的第一个，用于将 Claude 连接到您最重要的数据源，使 Claude 能够提供更相关、更有洞察力的帮助。此功能目前以测试版形式提供给早期企业版计划用户。我们计划在今年晚些时候更广泛地推出。

当您将扩展的上下文窗口与**项目**和**工件**结合使用时，Claude 成为一个端到端的解决方案，帮助您的团队将任何创意从想法转化为高质量的工作成果。例如，营销人员可以将市场趋势转化为引人注目的活动。产品经理可以上传产品规格，让 Claude 构建交互式原型。工程师可以连接代码库，以帮助排查错误和识别优化点。
