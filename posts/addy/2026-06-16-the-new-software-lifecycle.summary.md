# ONE SENTENCE SUMMARY
AI将软件生命周期从编写代码转变为判断代码，其中验证和上下文工程成为决定成败的关键。

# MAIN POINTS
1. 智能体是模型加框架，框架占90%工作量。
2. 上下文工程分为静态和动态，决定AI账单。
3. 验证是区分随意编码与工程实践的分界线。
4. 需求阶段从文档交接变为对话生成原型。
5. 架构设计仍是最顽固的人类主导环节。
6. 实施阶段效率提升25-39%，但需检查修复。
7. 测试和QA变成通过评估告诉AI何为正确。
8. 维护阶段可安全重构以前不敢动的代码。
9. 随意编码前期便宜后期成本高出3-10倍。
10. 原型可直接部署为生产智能体无需重写。

# TAKEAWAYS
1. 调试智能体时先检查框架而非模型本身。
2. 将上下文边界视为架构决策，版本化管理。
3. 用评估套件而非演示来衡量智能体可靠性。
4. 将复杂推理交给大模型，常规工作用小模型。
5. 规范化和验证能力是AI时代最值得掌握的技能。
