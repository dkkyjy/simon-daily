# ONE SENTENCE SUMMARY:
通过迭代式AI代理循环，开发者可以在睡眠期间让代理自动编码、测试和提交功能，实现持续交付。

# MAIN POINTS:
1. 核心是“拉尔夫·威格姆技术”：将开发分解为小任务，让AI代理循环执行。
2. 每次迭代包括：选择任务、实现、验证、提交、更新状态和重置上下文。
3. 使用AGENTS.md文件作为持久化知识库，记录模式、陷阱和偏好。
4. 内存持久化通过Git提交历史、进度日志、任务状态和知识文件实现。
5. 自动化验证（单元测试、类型检查、linting）是可靠输出的关键。
6. 并行代理需要规划-工人模型来避免冲突和协调问题。
7. 监控通过实时日志、检查点提交和自动停止条件实现。
8. 风险管理包括限制作用域、沙箱化和紧急停止机制。
9. 上下文膨胀可通过总结旧内容和按任务筛选相关信息来优化。
10. 人类监督和持续改进是系统成功的关键，需要定期审查和调整。

# TAKEAWAYS:
1. 将大型功能分解为原子任务，每个任务有明确的通过/失败标准。
2. 维护AGENTS.md文件，让代理自动记录学习到的模式和陷阱。
3. 在每次迭代中运行自动化测试和类型检查，确保代码质量。
4. 使用Git分支和人工审核作为安全网，防止破坏性操作。
5. 定期监控成本和性能，设置最大迭代次数和时间限制。
