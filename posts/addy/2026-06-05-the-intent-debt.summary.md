# ONE SENTENCE SUMMARY:
意图债务是未记录的目标、约束和决策理由，AI无法偿还，在智能体时代成本最高。

# MAIN POINTS:
1. 技术债务在代码中，认知债务在人脑中，意图债务在未写的文档中。
2. 意图债务是目标、约束和系统设计理由的缺失或侵蚀。
3. 三种债务相互独立：低技术债务可能伴随高意图债务。
4. AI能重构代码并解释系统，但无法生成真实的意图。
5. 智能体每次会话从零开始，不携带团队积累的隐性意图。
6. 未外化的意图在智能体时代每次会话都要付出代价。
7. 高意图债务表现为无法解释为何存在特定代码或设计。
8. 写规范应记录意图而非实现细节，让智能体能读取。
9. 决策日志（ADR）在决策时刻记录“为什么”是低成本偿债。
10. 学习循环将每次错误的原因写回文档，逆转意图债务积累。

# TAKEAWAYS:
1. 将意图从脑中取出，放在智能体可读取的文档中。
2. 用AGENTS.md记录团队约定和约束，而非自动生成配置。
3. 在决策发生时立即记录理由，避免八个月后高成本重建。
4. 智能体每次会话都是新成员，必须外化所有关键意图。
5. 代码是答案，意图是问题，AI擅长回答你忘记写下的问题。
