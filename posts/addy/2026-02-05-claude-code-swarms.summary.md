# ONE SENTENCE SUMMARY
Claude Code 的智能体团队功能允许多个专业 AI 代理并行协作，通过分工与协调解决复杂任务。

# MAIN POINTS
1. 智能体团队由一名团队领导创建并协调多个独立工作的队友。
2. 每个队友拥有独立的上下文窗口，可并行处理不同任务。
3. 共享任务列表支持依赖追踪和自动解锁功能。
4. 邮箱系统允许队友之间直接通信，而非仅向领导汇报。
5. 单智能体模型在上下文扩展时性能下降，多智能体模式解决此问题。
6. 智能体团队适合并行探索、跨层功能开发和代码审查。
7. 通过自然语言描述即可创建团队，系统自动处理分工。
8. 支持显示模式切换：进程内模式或 tmux 分屏模式。
9. 计划审批功能允许队友先提交方案，领导批准后再执行。
10. 委托模式限制领导仅做协调工作，防止其自行实现任务。

# TAKEAWAYS
1. 将复杂问题分解为独立子任务，让专业队友并行处理。
2. 为每个队友提供清晰具体的任务简报，提升输出质量。
3. 确保文件所有权清晰，避免多个队友编辑同一文件导致覆盖。
4. 从研究和审查任务开始，逐步过渡到跨层功能和大型重构。
5. 让问题引导工具选择，避免为使用多智能体而过度配置。
