# 中文总结

## 一句话总结

AI编码代理默认跳过规范、测试和审查，而Agent Skills通过强制工作流程将这些资深工程师行为重新嵌入开发过程。

## 核心要点

1. AI编码代理默认选择最短路径完成功能，跳过规范、测试和审查。
2. 资深工程师的关键工作包括暴露假设、编写规范、分块审查和留下证据。
3. Agent Skills是Markdown工作流程文件，包含步骤、检查点和退出标准。
4. 工作流程优于散文：可操作步骤比长篇参考文档更有效。
5. 反合理化表格预先反驳代理可能用来跳过流程的借口。
6. 验证不可协商：每个技能以具体证据终止，而非“看起来正确”。
7. 渐进式披露：仅加载相关技能到上下文，避免性能退化。
8. 范围纪律：代理只能修改被要求修改的内容，不触碰无关系统。
9. 技能编码Google工程实践，如Hyrum定律、测试金字塔和~100行PR。
10. 反合理化、工作流程验证和渐进式披露可独立于工具使用。

## 关键启示

1. 将反合理化作为团队实践：记录常见借口并配以反驳，减少偷工减料。
2. 内部文档采用工作流程格式：将2000字参考转为400字可执行检查点。
3. 将“产生证据”设为每项任务的硬性退出标准，杜绝“看起来正确”。
4. 对任何规则手册采用渐进式披露：用小路由器指向相关章节，避免长篇手册。
5. 采纳五项不可协商原则：暴露假设、冲突时询问、拒绝盲从、选择简单方案、只修改指定内容。
