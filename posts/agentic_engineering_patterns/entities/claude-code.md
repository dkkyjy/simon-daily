# Claude Code

## 概述

Anthropic 推出的基于 CLI 的编码智能体，能自主编写、编辑和调试代码。属于智能体格局中的"编码智能体与 IDE"类别。

## 关键事实

- 目前约 4% 的公开 GitHub 提交由 Claude Code 驱动
- 类别：自主编码智能体（区别于辅助 augment 模式）
- 创造者：Anthropic
- 模式："自动驾驶"（完全自主）推动主要增长

## 为何出众

- 已有显著的生产环境采用率：4% 的公开 GitHub 提交
- 代表了从"副驾驶"（辅助）到"自动驾驶"（自主）编码的转向
- 由 Anthropic 的 Claude 模型家族开创
- 树立了编码智能体自主能力的标杆

## 与其他实体的关系

- 属于 [[coding-agents]] 类别的智能体工具
- 与 [[cursor]] 和 [[devin]] 在编码智能体领域相关
- 工作区操作使用 [[code-execution]]
- 体现了 [[coding-agent-evolution]] 趋势（从副驾驶到自动驾驶）
- 与 [[openhands]] 及其他编码智能体竞争
