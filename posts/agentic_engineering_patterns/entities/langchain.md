# LangChain

## 概述

最初的 & 仍然最大的 LLM 框架生态。12.6 万+ GitHub 星标，使其成为星标最多的代码优先框架。LangGraph 现已成为其面向生产系统的智能体后继者。

## 关键事实

- 12.6 万+ GitHub 星标（领域最多）
- 架构：最初基于链式；现正演变为基于图的模式
- 创造者：Harrison Chase（也是 LangGraph 的创造者）
- 状态：基石层；生产智能体越来越多地用 LangGraph 替代原始 LangChain

## 为何仍然重要

- 庞大的集成与抽象生态
- 链式模式仍然适用于更简单的用例
- LangGraph 从 LangChain 演化而来用于复杂生产工作流
- 参考实现和文档广度无人能及

## 与其他实体的关系

- 是 [[langgraph]] 的父项目（复杂工作流的智能体后继者）
- 为生态中的 [[tool-use]] 提供基础抽象
- 使用 [[vector-stores]] 实现 RAG 管线（记忆系统）
- 与 [[crewai]]、[[microsoft-autogen]] 和厂商专属 SDK 竞争
