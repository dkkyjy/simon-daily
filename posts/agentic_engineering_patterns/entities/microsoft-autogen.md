# Microsoft AutoGen

## 概述

微软构建多智能体系统的框架。2025 年第四季度，AutoGen 和 Semantic Kernel 合并为统一的多智能体开发框架。

## 关键事实

- 由微软研究院和微软工程团队构建
- 架构：可配置通信模式的对话式智能体组
- 2025 年第四季度：与 Semantic Kernel 合并为单一统一框架
- 焦点：企业友好型多智能体工作流，强大的 C# 集成

## 为何出众

- 企业级，由微软生态背书
- C# Semantic Kernel 在企业部署中日益流行
- 强大的多智能体对话模式能力
- 与微软云和企业工具无缝集成

## 与其他实体的关系

- 2025 年第四季度与 [[semantic-kernel]] 合并
- 与 [[langgraph]] 和 [[crewai]] 竞争
- 通过对话式智能体组解决 [[multi-agent-systems]]
- 配合 [[agent-protocols]] 实现工具访问
- 属于更广泛的 [[microsoft-cloud]] 生态的一部分
