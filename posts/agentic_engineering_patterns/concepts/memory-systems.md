# 记忆系统

## 概述

智能体的记忆系统已从临时的上下文窗口扩展到专用的持久化记忆层。四种类别的记忆正成为智能体架构的标准组成部分。

## 记忆的四种类别

| 类型 | 说明 | 典型实现 |
|---|---|---|
| **工作记忆** | 当前任务期间的短期存储 | 图状态、对话上下文 |
| **情景记忆** | 过去交互的具体事件 | 对话日志、历史工具调用 |
| **语义记忆** | 结构化知识和事实 | 向量数据库（pgvector、Pinecone） |
| **程序性记忆** | "怎么做"的规则和经验 | 知识图谱（Zep）、元数据缓存 |

## 记忆存储方案

| 方案 | 用途 | 特点 |
|---|---|---|
| **pgvector** | 数据库内向量存储 | 部署最简单 |
| **Pinecone** | 托管向量 DB | 在 LangChain 生态中流行 |
| **Weaviate** | 混合语义/向量搜索 | 支持混合查询 |
| **Mem0** | 专用记忆层 | AWS 独家 |
| **Zep** | 时间知识图谱 | 长期记忆管理 |

## 关键趋势

- **专用记忆层正成为必选项** — 有记忆的智能体胜过零样本方案
- 记忆不再是 API 会话后的遗留物，而是智能体架构的核心层
- 多提供商路由成为记忆检索的成本与可用性问题
