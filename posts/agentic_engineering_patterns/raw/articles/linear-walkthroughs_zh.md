线性讲解
有时，让编码智能体为你提供代码库的结构化讲解会很有用。
可能是你需要快速上手的现有代码，可能是你自己编写但已忘记细节的代码，或者可能是你全程凭感觉编码后需要理解其实际工作原理的代码。
配备合适智能体框架的前沿模型能够构建详细的讲解，帮助你理解代码的工作原理。
使用 Showboat 和 Present 的示例
我最近在 Mac 上使用 Claude Code 和 Opus 4.6 凭感觉编码了一个 SwiftUI 幻灯片演示应用。
我当时在谈论 2025 年 11 月到 2026 年 2 月间前沿模型的进展，并且我喜欢在演讲中至少包含一个噱头（一个 STAR 时刻——Something They'll Always Remember，即听众会永远记住的瞬间）。这次我决定将噱头设定为：在演示结束时揭示幻灯片机制本身就是凭感觉编码能实现的一个例子。
我将代码发布到 GitHub 后，才意识到我完全不清楚它实际上是如何工作的——我通过提示让整个代码凭空出现（部分记录在此），却完全没有关注它正在编写的代码。
于是我启动了一个新的 Claude Code for Web 实例，指向我的代码库并提示：
阅读源代码，然后规划一个代码的线性讲解，详细解释其所有工作原理
接着运行 "uvx showboat --help" 来了解 showboat - 使用 showboat 在代码库中创建一个 walkthrough.md 文件，并在其中构建讲解，使用 showboat note 添加注释，并使用 showboat exec 加上 sed 或 grep 或 cat 或任何你需要的工具来包含你正在讨论的代码片段
Showboat 是我构建的一个工具，旨在帮助编码智能体编写展示其工作的文档。你可以在此处查看 showboat --help 的输出，其设计目的是为模型提供使用该工具所需的一切信息。
showboat note 命令向文档添加 Markdown 内容。showboat exec 命令接受一个 shell 命令，执行它，然后将命令及其输出都添加到文档中。
通过告诉它使用 "sed 或 grep 或 cat 或任何你需要的工具来包含你正在讨论的代码片段"，我确保 Claude Code 不会手动将代码片段复制到文档中，因为这可能引入幻觉或错误的风险。
这个方法效果极佳。这是 Claude Code 使用 Showboat 创建的文档，其中详细讨论了所有六个 .swift 文件，并对代码的工作原理提供了清晰且可操作的说明。
通过阅读这份文档，我学到了很多关于 SwiftUI 应用结构的知识，并吸收了一些关于 Swift 语言本身的可靠细节。
如果你担心 LLM 可能会降低你学习新技能的速度，我强烈建议采用此类模式。即使是一个约 40 分钟凭感觉编码的玩具项目，也能成为探索新生态系统并学到一些有趣新技巧的机会。
