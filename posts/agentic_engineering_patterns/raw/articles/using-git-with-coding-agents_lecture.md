# 智能体工程模式：与编码智能体协作使用 Git

**SUMMARY**
本讲座阐述了如何利用 Git 作为与编码智能体协作的核心工具，涵盖 Git 基础、高级操作及实用提示，以最大化开发效率和代码管理能力。

**TOOLS**
*   **Git**: 分布式版本控制系统，用于跟踪代码变更。
*   **GitHub**: 流行的 Git 远程仓库托管服务平台。
*   **git init**: 初始化新 Git 仓库的命令。
*   **git commit**: 创建提交以记录更改的命令。
*   **git log**: 查看提交历史的命令。
*   **git bisect**: 使用二分查找定位引入错误的提交的工具。
*   **git reset**: 用于撤销提交等操作的命令。
*   **git stash**: 临时保存工作目录更改的命令。
*   **reflog**: Git 的引用日志，记录本地仓库的引用更新历史。

**ONE-SENTENCE TAKEAWAY**
将 Git 视为可编辑的项目叙事工具，并利用编码智能体处理其复杂操作，从而显著提升版本控制与协作效率。

---

### **讲座主题与时间戳**

00:00:00 **Git 作为协作核心工具**
*   Git 是与编码智能体协作的关键，它记录变更、支持调查与回滚错误。
*   编码智能体精通 Git 的基础与高级功能，使我们能更雄心勃勃地使用它。

00:00:15 **Git 核心概念**
*   **仓库 (Repository)**: 跟踪文件更改的磁盘文件夹。
*   **提交 (Commit)**: 带时间戳、描述信息和作者的文件更改集合。
*   **分支 (Branch)**: 允许独立构建和试验新更改的并行开发线。
*   **克隆 (Clone)**: 将仓库完整复制到新机器，包含所有历史。
*   **远程仓库 (Remote)**: 用于协作和备份的共享仓库位置（如 GitHub）。

00:00:35 **实用 Git 提示与智能体指令**
*   **“在此处启动新的 Git 仓库”**: 智能体会运行 `git init`。
*   **“提交这些更改”**: 智能体会创建新的提交。
*   **“添加 username/repo 作为 GitHub 远程仓库”**: 配置 GitHub 远程连接。
*   **“查看今天/最近的更改”**: 启动会话的好方法，智能体运行 `git log` 加载上下文。
*   **“集成主分支的最新更改”** 或 **“讨论集成选项”**: 智能体可解释合并、变基等策略的优劣。
*   **“帮我理清这个 Git 乱局”**: 智能体擅长解决合并冲突等复杂问题。
*   **“查找并恢复我那个实现...功能的代码”**: 智能体可利用 `reflog` 或搜索分支找回丢失的代码。
*   **“使用 git bisect 查找此错误是何时引入的”**: 智能体能处理测试表达的样板工作，使强大的调试工具更易用。

00:01:10 **高级操作：重写 Git 历史**
*   将 Git 历史视为可编辑的、辅助未来开发的项目叙事，而非永久记录。
*   **“撤销最后一次提交”**: 例如，使用 `git reset --soft HEAD~1`。
*   **“从最后一次提交中移除 [某文件]”**: 精细修改提交内容。
*   **“用更好的提交消息合并最后三次提交”**: 智能体擅长优化提交历史与消息。
*   **“从旧仓库的碎片中构建新仓库”**: 例如提取库代码到新仓库并保留关键历史，智能体可复制作者和提交日期信息。
