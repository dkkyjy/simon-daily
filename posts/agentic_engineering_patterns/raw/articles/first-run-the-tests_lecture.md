# 课程摘要：智能体工程模式

## 摘要
本讲座介绍了在AI编码智能体工作中“首先运行测试”的核心工程模式，强调了自动化测试的必要性及其对确保代码质量和引导智能体的作用。

## 定义与要点
*   **智能体工程模式**
    *   一套与AI编码智能体协作的最佳实践和结构化方法，旨在提高开发效率和代码可靠性。
*   **“首先运行测试”提示**
    *   一个简短的指令（如“首先运行测试”或“运行 ‘uv run pytest’”），用于在智能体会话开始时引导智能体执行现有测试套件。
    *   **作用**：
        1.  **强制发现**：迫使智能体寻找并运行测试，使其意识到测试的存在。
        2.  **建立基准**：通过测试结果让智能体了解项目规模和复杂度。
        3.  **设定模式**：引导智能体进入测试驱动的思维模式，鼓励其在后续修改中添加新测试。

*   **自动化测试的角色转变**
    *   在传统开发中，快速演进的项目可能因成本而省略测试。
    *   在智能体辅助开发中，由于智能体能快速生成测试，不编写测试的借口不再成立。测试对于验证AI生成代码的功能至关重要。

*   **测试作为文档与引导工具**
    *   智能体在理解现有功能时，会倾向于查找并阅读相关测试用例。
    *   现有测试套件的存在会显著影响智能体的行为，推动其对新更改进行测试。

## 工具
*   **pytest**：一个Python测试框架，用于运行和编写测试。
*   **uv**：一个快速的Python包安装程序和解析器，此处用于运行测试命令（`uv run pytest`）。
*   **pyproject.toml**：Python项目的配置文件，可用于定义项目元数据和工具设置（如指定测试运行命令）。

## 一句话要点
在AI编码时代，通过“首先运行测试”的提示引导智能体，将测试从可选项转变为保障代码质量和引导开发的核心规范。
