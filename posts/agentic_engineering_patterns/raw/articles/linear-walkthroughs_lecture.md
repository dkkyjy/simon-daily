# 智能体工程模式：线性讲解代码库

**SUMMARY**
使用智能体框架（如Showboat）对代码库进行结构化讲解，帮助理解现有代码或凭感觉编写的代码的工作原理，并促进学习。

**TOOLS**
*   **Showboat**: 一个帮助编码智能体编写展示其工作文档的工具，包含 `note` 和 `exec` 等命令。
*   **Claude Code**: 一个编码智能体，用于分析和解释代码。
*   **Opus 4.6**: 一个前沿的AI模型。
*   **SwiftUI**: 用于构建苹果平台用户界面的框架。
*   **GitHub**: 代码托管平台。
*   **sed/grep/cat**: 用于在文档中处理和包含代码片段的命令行工具。

**ONE-SENTENCE TAKEAWAY**
利用智能体工具对代码进行线性讲解，是将凭感觉编码的项目转化为结构化学习机会的有效模式。

00:00:05 **线性讲解的应用场景**
*   快速上手现有代码。
*   回顾自己编写但已遗忘细节的代码。
*   理解凭感觉编码后代码的实际工作原理。

00:00:15 **核心方法与工具**
*   使用配备合适框架（如Showboat）的前沿模型构建详细讲解。

00:00:25 **使用 Showboat 和 Present 的示例**
00:00:30 **示例背景：凭感觉编码的 SwiftUI 应用**
*   项目：一个用于演讲的SwiftUI幻灯片演示应用。
*   目的：将“幻灯片机制本身是凭感觉编码实现”作为演讲的噱头（STAR时刻）。

00:00:50 **发现问题与启动分析**
*   将代码发布到GitHub后，意识到并不清楚其工作原理。
*   启动Claude Code for Web实例，指向代码库并给出提示。

00:01:05 **具体操作指令**
*   提示智能体：阅读源码并规划线性讲解。
*   指示使用 `uvx showboat --help` 了解工具。
*   使用 `showboat` 创建 `walkthrough.md` 文件。
*   使用 `showboat note` 添加注释。
*   使用 `showboat exec` 结合 `sed`/`grep`/`cat` 等工具嵌入正在讨论的代码片段。

00:01:25 **Showboat 工具详解**
*   **`showboat note`**: 向文档添加Markdown内容。
*   **`showboat exec`**: 执行shell命令，并将命令及输出都添加到文档中。
*   **设计目的**: 为模型提供使用该工具所需的一切信息，避免手动复制代码片段带来的幻觉或错误风险。

00:01:40 **成果与收益**
*   生成的文档详细讨论了所有六个 `.swift` 文件。
*   提供了清晰且可操作的代码工作原理说明。
*   作者通过文档学习了SwiftUI应用结构和Swift语言细节。

00:01:55 **核心建议**
