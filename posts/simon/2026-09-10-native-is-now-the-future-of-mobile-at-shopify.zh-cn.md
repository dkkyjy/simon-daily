2026年9月10日 - 链接博客

**[原生开发已成为 Shopify 移动端的未来](https://shopify.engineering/back-to-native)**（[转引自](https://news.ycombinator.com/item?id=49643982 "Hacker News")）Shopify 正从 React Native 转向独立的 Swift 和 Kotlin 代码库来开发其原生应用，原因正如你所料：

> 我们于 2020 年从原生开发转向 React Native，原因有三：
>
> * 停止重复构建相同的功能
> * 让开发者能够跨技术栈工作
> * 减少在功能对等上耗费的时间，将更多精力投入交付价值
>
> [...]
>
> 原生开发仍然意味着在两个平台上构建和维护软件，这一成本并未消失。变化在于，AI 智能体如今已能完成足够多的实现、翻译、测试和审查工作，使其不再像 2020 年那样成为决定性的因素。

这是一篇写得非常出色的文章，充分肯定了 React Native 作为一个优秀平台，在他们使用它的六年间所发挥的重要作用。

Shopify 维护着三个重要的 React Native 库：[react-native-skia](https://github.com/Shopify/react-native-skia)、[flash-list](https://github.com/Shopify/flash-list) 和 [restyle](https://github.com/Shopify/restyle)。前两个正在寻找新的归宿；第三个"用户群比我们的其他库更小"，将于 2026 年底归档。
