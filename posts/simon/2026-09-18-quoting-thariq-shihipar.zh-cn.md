> 我们正在为 Claude Code 添加对 AGENTS.md 的支持。
>
> 从今天起，在版本 2.1.277 中，如果文件夹中没有 CLAUDE.md，Claude 将会查找并使用 AGENTS.md。
>
> AGENTS.md 支持是建立在 Claude Code mods 基础上的，这是我们即将推出的自定义 Claude Code 框架的方式。
>
> 这是一个内置的 mod，但您也可以构建自定义的项目指令版本。
>
> 您可以在[这里查看该 mod 的源代码](https://github.com/anthropics/claude-code/tree/main/mods/agents-md)！
