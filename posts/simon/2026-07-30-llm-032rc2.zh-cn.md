[llm 0.32rc2](https://github.com/simonw/llm/releases/tag/0.32rc2)
— 从命令行访问大型语言模型

在 [RC1](https://simonwillison.net/2026/Jul/30/llm-rc1/) 之后紧跟着，此版本修复了一个依赖问题，并增加了两个简洁的新功能：

> * 未设置自己默认模型的用户，现在默认模型为 [GPT-5.6 Luna](https://developers.openai.com/api/docs/models/gpt-5.6-luna)。之前是 [GPT-4o mini](https://developers.openai.com/api/docs/models/gpt-4o-mini)。Luna 是一个更好更新的模型，尽管略贵一些——每百万输入令牌 0.20 美元，每百万输出令牌 1.20 美元，而 4o mini 是 0.15/0.60 美元。你可以使用 `llm models default gpt-4o-mini` 切换回 4o mini，或者使用 `llm models default gpt-5-nano` 切换到 [GPT-5 nano](https://developers.openai.com/api/docs/models/gpt-5-nano)，一个更便宜的默认模型（0.05/0.40 美元）。[#1576](https://github.com/simonw/llm/issues/1576)
> * 新的 [llm openai endpoint](https://llm.datasette.io/en/latest/other-models.html#openai-endpoint) 命令，用于针对任意兼容 OpenAI 的端点运行提示词、聊天和模型列表，而无需预先配置模型。这些调用不会被记录。[#1565](https://github.com/simonw/llm/issues/1565)

`llm openai endpoint` 命令*真*的很酷。我一直对缺乏一个明确的 CLI 工具来针对任意 OpenAI Chat Completions 模仿端点尝试提示词感到沮丧，所以我决定将这个功能添加到 LLM 本身。

你甚至不需要安装 LLM 就能使用这个功能。这里有一个 `uvx` 一行命令，用于针对 [LM Studio](https://lmstudio.ai) 本地模型运行包含工具的提示词：

```
uvx --pre llm openai endpoint http://127.0.0.1:1234/v1 \
  T llm_version -T llm_time --td \
  -m google/gemma-4-31b 'what is the current LLM version? And the time?'
```

[输出在此](https://github.com/simonw/llm/pull/1568#issuecomment-5136163707)。
