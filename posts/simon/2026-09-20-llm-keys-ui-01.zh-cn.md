[llm-keys-ui 0.1](https://github.com/simonw/llm-keys-ui/releases/tag/0.1)
— 用于设置密钥的 LLM Web UI

此插件解决了一个非常具体的问题。

我开始使用 [Codex Remote](https://learn.chatgpt.com/docs/remote) 在各种机器上运行编码代理，同时从我的手机控制它们。

有时我用那些机器来开发 LLM 项目，偶尔这意味着我需要配置一个 API 密钥。

我不喜欢将 API 密钥粘贴到代理会话中，所以我想要一种方式，可以在不直接将密钥粘贴到 ChatGPT 应用的情况下，将那些密钥放到机器上。

使用此插件，我可以告诉 Codex 运行：

```
uvx --with llm-keys-ui llm keys-ui --all
```

然后让它告诉我 URL——包括本地网络或 Tailscale 设备 IP——用于保存额外 API 密钥的界面。

之后，当它需要使用密钥时，它可以在 shell 命令中使用类似 `llm keys get anthropic` 的命令。
