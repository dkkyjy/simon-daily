Mojo 编程语言自 [2023 年 5 月](https://simonwillison.net/2023/May/4/mojo/) 以来一直承诺将开源。上周他们[发布了 1.0 版本](https://www.modular.com/blog/modular-26-5-mojo-1-0-is-here)，今天他们兑现了最初的承诺，以 Apache 2 许可证发布了编译器和工具链。

Mojo 最初发布时，其既定目标是打造 Python 的超集，以便利用现有的 Python 代码来构建自身的生态系统。这一计划在 [2025 年 8 月左右](https://forum.modular.com/t/mojo-vision-document-and-roadmap/2187) 发生了改变：

> Mojo 可能会也可能不会演变为 Python 的完整超集，即使没有也完全没问题。
>
> 我们看到 AI 辅助编码工具在将 Python 迁移到 Mojo 方面已经表现得相当出色，这让我们倍感鼓舞，我们有信心未来的工具链和生态系统的成熟将使这一演进过程更加顺畅。

如今，Mojo 已发展为一种独立的编程语言，采用受 Python 启发的语法，旨在让 GPU 编程尽可能轻松——尽管它并非与现有代码 100% 兼容。
