[sqlite-utils 4.1.1](https://github.com/simonw/sqlite-utils/releases/tag/4.1.1)
——用于操作 SQLite 数据库的 Python CLI 工具和库

主要是修复了一个边缘情况，该情况由常规 Claude 聊天在[尝试 4.1 版本](https://claude.ai/share/564b187d-d126-47ea-9b59-07c16ade0b70)以回答关于 ON DELETE 的问题时发现。

> * `table.transform()` 现在会在以下情况下抛出 `TransactionError`：当事务打开且启用了 `PRAGMA foreign_keys`，并且该表被具有破坏性 `ON DELETE` 动作（`CASCADE`、`SET NULL` 或 `SET DEFAULT`）的外键引用时。由于事务内部无法更改 pragma，因此之前作为转换的一部分删除旧表时，可能会触发这些动作并静默删除或修改引用行。有关详细信息和解决方法，请参见[外键和事务](https://sqlite-utils.datasette.io/en/stable/python-api.html#python-api-transform-foreign-keys-transactions)。（[#794](https://github.com/simonw/sqlite-utils/issues/794)）
> * [CLI](https://sqlite-utils.datasette.io/en/stable/cli.html) 和 [Python API](https://sqlite-utils.datasette.io/en/stable/python-api.html) 文档现在相互交叉引用：CLI 部分链接到等效的 Python API 功能，Python API 部分链接回相应的 CLI 命令。（[#791](https://github.com/simonw/sqlite-utils/issues/791)）
