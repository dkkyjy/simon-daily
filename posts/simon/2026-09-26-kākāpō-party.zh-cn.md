我昨天为[WeAreDevelopers 北美世界大会](https://www.wearedevelopers.com/world-congress-north-america)做了闭幕主题演讲。作为[一个 STAR 时刻](https://simonwillison.net/2019/Dec/10/better-presentations/)，我决定融入对 2026 年破纪录的[鸮鹦鹉繁殖季节](https://www.doc.govt.nz/news/media-releases/2026-media-releases/kakapo-population-reaches-new-milestone/)的引用。

在我的闭幕幻灯片上，我想庆祝一下，而我看到了一些关于 Claude Opus 5.5 在创建像素艺术动画方面表现出色的讨论。于是我从 Google 图片搜索中收集了三张鸮鹦鹉的照片，并将它们放入 Claude，附带以下提示：

> `这里有一些鸮鹦鹉的照片，只是提醒你它们长什么样`
>
> `我需要你制作一个 HTML 5 画布上的像素艺术动画，展示明显的像素艺术鸮鹦鹉上下跳跃，举办派对，有彩纸之类的——应该有至少 20 只`

这是[对话记录](https://claude.ai/share/43bec0be-a0a3-4737-bfac-34894af34ddc)，这是[生成的页面](https://tools.simonwillison.net/kakapo-party)。相当不错！

我想把它嵌入到 Keynote 演示文稿文件中，所以我下载了 HTML 并告诉本地 Claude Code 会话：

> `帮我制作一个 file:///Users/simon/Downloads/kakapo-party.html 的视频——你需要在浏览器中加载它并点击几次以产生彩纸效果，视频应该长 15 秒`
>
> `不要在前 3 秒内开始点击`
>
> `确保几次点击分布在可点击区域周围`

Claude Code 使用了 Playwright（[对话记录在此](https://gisthost.github.io/?368b481fba654c4fb84d90188da77581/page-001.html)），并生成了这个视频，这正是我最后一张幻灯片所需要的：

以下是它使用的完整 Playwright 脚本，令人欣慰地简短：

```
# /// script
# dependencies = ["playwright"]
# ///
import time
from playwright.sync_api import sync_playwright
W, H = 1280, 720
# 画布填满视口；将点击分散到角落、边缘和中心
clicks = [
     (3.0, 640, 360),    # 中心
     (4.2, 160, 120),    # 左上角
     (5.4, 1120, 120),   # 右上角
     (6.6, 180, 600),    # 左下角
     (7.8, 1100, 600),   # 右下角
     (9.0, 640, 100),    # 顶部中心
     (10.0, 380, 380),   # 左侧中部
     (11.0, 900, 380),   # 右侧中部
     (12.2, 640, 620),   # 底部中心
     (13.2, 640, 300),   # 最终中心
]
with sync_playwright() as p:
    b = p.chromium.launch()
    ctx = b.new_context(viewport={"width":W,"height":H}, record_video_dir="vids", record_video_size={"width":W,"height":H})
    page = ctx.new_page()
    t0 = time.time()
    page.goto("file:///Users/simon/Downloads/kakapo-party.html")
    for t,x,y in clicks:
        time.sleep(max(0, t-(time.time()-t0)))
        page.mouse.click(x,y)
    time.sleep(max(0, 16.0-(time.time()-t0)))
    ctx.close(); b.close()
```
