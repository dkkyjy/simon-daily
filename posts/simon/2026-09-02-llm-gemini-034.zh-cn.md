> * 针对 [Gemini 3.8 Flash](https://blog.google/innovation-and-ai/models-and-research/gemini-models/3-8-flash-and-3-8-flash-cyber/) 的新模型 `gemini-3.8-flash`，支持低、中、高三种思考级别。[#146](https://github.com/simonw/llm-gemini/issues/146)
> * 修复了异步响应未能记录已解析模型版本的问题。感谢 [Charlie Tonneslan](https://github.com/c-tonneslan)。[#137](https://github.com/simonw/llm-gemini/pull/137)

Google 今天发布了 [Gemini 3.8 Flash](https://blog.google/innovation-and-ai/models-and-research/gemini-models/3-8-flash-and-3-8-flash-cyber/)（以及 3.8 Flash Cyber，但后者仅向“受信任的防御者”开放）。

以下是高、中、低三种思考级别的[鹈鹕图片](https://tools.simonwillison.net/markdown-svg-renderer?url=https%3A%2F%2Fgist.github.com%2Fsimonw%2Ff8820ce47db87490734117e9be4984c3)。这是高思考级别的：

作为对比，这里是使用 [Gemini 3.7 Flash 生成的相同鹈鹕图片](https://tools.simonwillison.net/markdown-svg-renderer.html?url=https%3A%2F%2Fgist.github.com%2Fsimonw%2F6779a22d5e7bb6bdf29936f1600a5259)。

我很欣赏 Gemini Flash 的一点是它速度快、成本低，并且在处理 HTML 和 JavaScript 等任务时表现出色。我随意试了一下，提示“用 HTML 给我做个酷炫的东西”，然后[它构建了这个](https://tools.simonwillison.net/markdown-svg-renderer?url=https%3A%2F%2Fgist.github.com%2Fsimonw%2Fb6149a49d327164d67d62c3d12992e48#how-to-use-it)，这确实是一个用 HTML 做的酷炫东西！耗时 13 秒，花费 1.8 美分。

我的 [markdown-svg-renderer 工具](https://tools.simonwillison.net/markdown-svg-renderer) 允许我输入包含 Markdown 的 Gist URL，并将该 Markdown 渲染出来，其中带有围栏代码块的 SVG 会被正确渲染。

我使用 Gemini 3.8 Flash（配合我*非常*基础的 [llm-coding-agent](https://github.com/simonw/llm-coding-agent) 编码代理插件）添加了对 HTML 的支持，因此现在 Markdown 中的任何 HTML 块都会使用沙箱化的 iframe 进行渲染。[这是对话记录](https://gist.github.com/simonw/3e36b98292dfdc1b3baff158faa743f7)。
