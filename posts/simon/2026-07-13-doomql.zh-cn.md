**[DOOMQL](https://github.com/petergpt/doomql)** ([via](https://twitter.com/petergostev/status/2076692164310884468 "@petergostev")) Peter Gostev 使用 GPT-5.6 Sol 构建了它。这非常有趣：

> DOOMQL 始于一个刻意不合理的问题：如果 SQLite 是游戏引擎，而不仅仅是游戏存储数据的地方呢？
>
> 结果是一个小型、原创的类 DOOM 游戏，其中 SQL 控制着移动、碰撞、敌人、战斗、进度以及屏幕上的每一个 RGB 像素。

它实现为一个 Python 终端脚本——我这样尝试运行：

```
cd /tmp
git clone https://github.com/petergpt/doomql
cd doomql
uv run host/doomql.py
```

这是[庞大的 SQL 查询](https://github.com/petergpt/doomql/blob/main/sql/003_render.sql)，它使用递归 CTE 在 SQLite 中实现了完整的光线追踪器。

运行上述脚本会创建一个 `/tmp/doomql/.doomql/doomql.sqlite` SQLite 数据库，你可以像这样使用 Datasette 进行探索：

```
uvx --prerelease=allow  --with datasette-apps datasette \
  /tmp/doomql/.doomql/doomql.sqlite \
  -p 4444 --root --secret 1 --internal internal.db
```

`--with datasette-apps` 选项会安装新的 [Datasette Apps](https://simonwillison.net/2026/Jun/18/datasette-apps/) 插件，该插件支持创建自定义的 HTML+JavaScript 应用，这些应用可以直接在 Datasette 界面中运行 SQL 查询。

我创建了一个新应用，将复制粘贴的提示语粘贴到 Claude 聊天（Fable 5）中，[并告诉它](https://claude.ai/share/c793280c-2ef1-4555-a7c2-31281abfdf78)：

> `构建一个应用，使用 frame_pixels 视图（包含 x, y, r, g, b 列）显示屏幕的当前状态，并每秒刷新一次。`

这让我在 Datasette 内部得到了一个可用的 HTML+JavaScript 应用，它可以在我在终端中玩游戏时反映当前状态。然后我添加了：
