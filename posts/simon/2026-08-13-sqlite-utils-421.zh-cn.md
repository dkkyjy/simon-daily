[发布](/elsewhere/release/)
[sqlite-utils 4.2.1](https://github.com/simonw/sqlite-utils/releases/tag/4.2.1)
—— 用于操作 SQLite 数据库的 Python CLI 工具和库

修复了 [sqlite-utils 4.2](https://simonwillison.net/2026/Aug/13/sqlite-utils/) 中的一个崩溃错误。我引入了如下代码：

```
from typing_extensions import Self
```

结果发现，[typing-extensions](https://pypi.org/project/typing-extensions/) 包没有被列为 `sqlite-utils` 的依赖项——它是由 [dev 依赖组](https://github.com/simonw/sqlite-utils/blob/56dd09702fdb9e899f577ffd51693c1f2176cb08/pyproject.toml#L34-L55) 中的另一个依赖项安装的，但当你直接运行 `uvx sqlite-utils` 时，你不会获得这些依赖项。

作为修复此问题的一部分，我想到了如何运行冒烟测试，以确保即使没有这些开发依赖项，CLI 工具仍然可以工作，该测试可以从项目检出目录中运行：

```
uv run --isolated --no-default-groups sqlite-utils --help
```

`--no-default-groups` 参数阻止它安装默认的 `dev` 组，而 `--isolated` 意味着即使存在包含额外依赖项的 `.venv/` 文件夹，它们也会在 `uv run` 命令执行期间被忽略。
