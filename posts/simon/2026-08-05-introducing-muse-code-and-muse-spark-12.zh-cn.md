**[介绍 Muse Code 与 Muse Spark 1.2](https://research.meta.ai/blog/introducing-muse-code-and-muse-spark-1-2)**（[来源](https://news.ycombinator.com/item?id=49187575 "Hacker News")）更多证据表明，如今任何模型最重要的特性是长序列的智能体工具调用。Meta 为此发布了他们自己的编码智能体！

> Muse Spark 1.2 是 Muse Spark 1.1 的编码聚焦更新，在代码生成、复杂调试、代码库理解以及端到端开发者工作流方面均有改进。在 Muse Spark 1.2 中，我们显著增加了编码任务的训练计算量，同时扩展了训练环境的多样性。该模型在通用智能体等其他关键领域也保持了其优势。[...]
>
> 我们将 Muse Spark 1.2 与 Muse Code 共同训练，以确保模型在配合使用时展现出最佳性能和编码可用性。训练过程包括拒绝采样轨迹以及针对目标、压缩和子智能体的配方优化，同时整合了 Muse Code 工具集以最大化工具链兼容性。[...]
>
> Muse Spark 1.2 在长周期编码任务上进行了广泛训练，包括整个代码库的生成、大型端到端项目以及自动研究。
