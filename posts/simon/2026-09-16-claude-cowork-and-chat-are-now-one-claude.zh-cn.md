# Claude Cowork 和聊天功能现已合二为一

> *摘要：Claude Cowork 和聊天功能现已合二为一*  
> 对于像我这样越来越搞不清 Cowork、Claude 和 Claude Code 之间区别的人来说，这 hopefully 是个好消息：
> 
> 从今天起，Claude Cowork 和聊天功能将合并为一个统一的 Claude。无论是快速提问，还是委托一个中午前截止的报告，Claude 都能接手处理，即使你已合上笔记本电脑。[...]
> 
> 此功能将首先向 Pro 和 Max 套餐用户推出，未来几周将在网页版、桌面版和移动版的 Claude 应用中向这些套餐的新老用户逐步上线。

我想这意味着 Claude 正在成为一个**通用智能体**。这与几周前 OpenAI 将其 Codex 桌面应用更名为 ChatGPT 有异曲同工之妙。

一方面，这省了我一些功夫——我原本打算弄清楚 Cowork 和普通 Claude 之间的界限，并写一篇关于[理解 ChatGPT 工作](https://simonwillison.net/2026/Aug/30/understanding-chatgpt-work/)的后续文章。

但我直觉认为，要搞清楚这在实际功能和界面上到底意味着什么，恐怕还得花不少功夫。
