[llm 0.32.1](https://github.com/simonw/llm/releases/tag/0.32.1)
— Access large language models from the command-line

Fresh installs of LLM stopped working the other day because the OpenAI Python library dropped its usage of `httpx`, and it turned out LLM depended on that library but only installed it via a transitive `openai` dependency.

This dot-release fixes that for the moment by pinning to `openai<3`, and a soon-to-drop 0.33 release will switch from `httpx` to [httpx2](https://github.com/pydantic/httpx2).
