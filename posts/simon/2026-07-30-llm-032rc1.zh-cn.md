[llm 0.32rc1](https://github.com/simonw/llm/releases/tag/0.32rc1)
— 从命令行访问大型语言模型

LLM 0.32 的这个候选版本完成了[从 LLM 0.32a0 开始的工作](https://simonwillison.net/2026/Apr/29/llm/)——它新增了一个[新模式设计](https://llm.datasette.io/en/latest/logging.html#the-message-store)，能够更好地捕捉最新模型系列所返回的提示和响应的细节。

最重要的变化是使用了内容可寻址哈希 ID 来存储消息。这允许在数据库中进行去重，并且意味着 LLM 现在可以表示分叉对话的消息树。

由于涉及重大的模式变更——仅新增表，且旧数据应完全不受影响——建议在升级到候选版本之前备份现有的 `logs.db`：

```
llm logs backup logs-backup.db
```

该候选版本还增加了对 `gpt-5.6-sol`、`gpt-5.6-terra` 和 `gpt-5.6-luna` 的支持。
