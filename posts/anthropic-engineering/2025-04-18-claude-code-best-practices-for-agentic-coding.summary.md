# 一句话摘要

Claude Code是代理编码工具，管理上下文是关键，验证、规划与配置能提升效果。

# 主要观点

1. 上下文窗口填满后性能会下降，需积极管理。
2. 提供可运行的检查（测试/截图）让Claude自行验证。
3. 先探索分析再制定计划，最后才编码实现。
4. 精确指令比模糊提示需要更少的修正。
5. CLAUDE.md文件为每会话提供持久上下文和规则。
6. 使用权限模式、沙箱、钩子和技能减少中断。
7. 用子代理在独立上下文中调查，不污染主会话。
8. 频繁使用/clear清除无关上下文以保持性能。
9. 利用非交互模式在CI管道中自动化并行任务。
10. 避免“厨房水槽”会话，一次聚焦一个目标任务。

# 要点总结

1. 总是给Claude提供明确的验证标准，并让它展示证据。
2. 在复杂任务前先写详细规格，用新会话执行。
3. 将CLAUDE.md保持简短，只包含Claude无法推断的内容。
4. 任务间自觉清除上下文，出错两次后重启更佳。
5. 使用子代理或双模型（写/审）进行独立审查。
