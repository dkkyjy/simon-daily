# 一句话总结
Anthropic推出三个高级工具使用功能，通过动态发现、代码编排和示例改进，显著提升Agent效率和准确性。

# 主要观点
1. 传统MCP工具定义消耗高达55K+令牌，严重挤压上下文空间。
2. Tool Search Tool按需发现工具，仅加载约500令牌，节省85%令牌。
3. 内部测试中Opus 4准确率从49%提升至74%，Opus 4.5从79.5%提升至88.1%。
4. Programmatic Tool Calling让Claude用Python代码编排多个工具调用。
5. 预算检查案例中，中间数据从200KB压缩至1KB结果进入上下文。
6. 复杂研究任务中令牌消耗平均降低37%，从43,588降至27,297。
7. Tool Use Examples通过展示具体用法示例，解决JSON Schema无法表达的隐含约定。
8. 创建工单API中，示例使参数准确率从72%提升至90%。
9. 三个功能可分层使用：先解决最大瓶颈，再按需叠加。
10. 通过启用beta头“advanced-tool-use-2025-11-20”即可使用这些功能。

# 关键收获
1. 优先解决最大瓶颈：工具定义过多用Tool Search，中间数据庞大用PTC，参数错误用示例。
2. 工具命名和描述要清晰准确，以提升搜索发现成功率。
3. Programmatic Tool Calling适合多步并行、数据量大的场景，减少推理延迟和上下文污染。
4. Tool Use Examples应使用真实数据，展示最少、部分和完整三种模式以消除歧义。
5. 推荐将3-5个最常用工具保持加载，其余延迟加载，平衡即时响应与上下文节省。
