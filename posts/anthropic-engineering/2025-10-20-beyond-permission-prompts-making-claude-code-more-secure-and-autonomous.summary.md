# ONE SENTENCE SUMMARY:
Claude Code引入沙箱机制，通过文件系统和网络隔离显著减少权限提示，提升安全性与自主性。

# MAIN POINTS:
1. 沙箱机制减少权限提示并防止注入攻击。
2. 沙箱包含文件系统和网络双重隔离。
3. 内部测试显示减少84%权限提示。
4. 沙箱化bash工具可在定义边界内安全执行。
5. 基于Linux bubblewrap和macOS seatbelt实现。
6. 网络隔离通过代理服务器控制域名访问。
7. 文件系统隔离限制Claude访问指定目录。
8. Claude Code on Web在云端隔离沙箱运行。
9. Git交互通过代理验证令牌、分支和目标。
10. 沙箱运行时已开源供团队构建安全代理。

# TAKEAWAYS:
1. 双重隔离（文件系统和网络）可有效防止AI代理被注入后窃取数据或执行恶意操作。
2. 沙箱减少84%权限提示，既降低审批疲劳又提升开发效率。
3. 沙箱化bash工具基于OS级原语，支持自定义路径和域名，灵活可控。
4. Claude Code on Web将凭证隔离于沙箱之外，即使代码被攻破也能保护用户。
5. 开源沙箱运行时降低了安全门槛，鼓励行业构建更安全的AI代理。
