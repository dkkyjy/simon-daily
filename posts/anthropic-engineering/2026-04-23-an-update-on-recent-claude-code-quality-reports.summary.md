# ONE SENTENCE SUMMARY:
Anthropic发现并修复了Claude Code中三个导致质量下降的独立修改，现已恢复并改进流程。

# MAIN POINTS:
1. 默认推理努力从高改为中导致用户感觉智能下降，已于4月7日回滚。
2. 缓存优化bug导致每轮对话遗忘先前推理，造成重复和奇怪行为。
3. 该bug于4月10日修复，根因是清除思考逻辑错误。
4. 系统提示添加长度限制（25/100词）致编码质量下降3%。
5. 该提示于4月20日回滚，作为Opus 4.7发布的一部分。
6. 三个问题分别影响不同流量，形成不一致退化假象。
7. API和推理层未受影响，问题仅限Claude Code产品。
8. 内部测试和评估最初未能复现问题，因实验与显示改动掩盖。
9. 代码审查工具Opus 4.7发现缓存bug，而4.6未发现。
10. Anthropic将扩大内部公开构建使用、改进系统提示评估与逐步部署。

# TAKEAWAYS:
1. 默认设置应优先用户体验，用户更看重智能而非延迟。
2. 缓存优化需全面测试会话边界，尤其空闲后恢复逻辑。
3. 系统提示变更前需对每个模型进行消融测试和更广评估。
4. 内部测试应使用与用户完全相同的公开构建版本。
5. 重置使用限制并增强透明沟通，以重建用户信任。
