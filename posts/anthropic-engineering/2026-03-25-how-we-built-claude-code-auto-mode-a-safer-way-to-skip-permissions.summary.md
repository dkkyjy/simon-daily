# ONE SENTENCE SUMMARY  
Claude Code auto mode 通过模型分类器在手动审批和无防护之间取得平衡，安全地跳过权限检查。

# MAIN POINTS  
1. Auto mode 通过模型分类器在手动审批和无防护间取平衡。  
2. 两层防御：输入注入探测和输出转录分类器。  
3. 分类器分两阶段：快速过滤和链式推理。  
4. 安全工具白名单避免无害操作被分类器审查。  
5. 评估行动的真实影响而非表面文本。  
6. 用户意图规则只允许明确授权的操作。  
7. 默认阻止删除、外泄、降级安全等危险行为。  
8. 真实流量测试：假阳性率 0.4%，假阴性率 17%。  
9. 适用于跳过权限用户，非高安全场景替代品。  
10. 设计剥离助手文本和工具输出防注入，拒绝并继续机制。

# TAKEAWAYS  
1. Auto mode 显著改善跳过权限模式的安全性。  
2. 两层分类器降低误报并保持高检测率。  
3. 用户可自定义信任域和阻止规则。  
4. 分类器在授权判断上仍有不足，需谨慎使用。  
5. “拒绝并继续”减少误报对任务的影响。
