# ONE SENTENCE SUMMARY  
Anthropic 通过将大脑（Claude 和框架）、手（沙箱）和会话解耦，构建可独立演进的托管代理系统。

# MAIN POINTS  
1. 托管代理把组件虚拟化为会话、框架和沙箱三种抽象接口。  
2. 单容器设计导致“宠物”问题：容器挂掉，整场会话丢失。  
3. 解耦后框架离开容器，容器变成可替换的“牛群”。  
4. 会话持久化日志使框架可重启并从最后事件恢复。  
5. 令牌存储在沙箱之外，防止提示注入窃取凭证。  
6. 会话作为独立于 Claude 上下文的持久化对象，支持按位置检索。  
7. `getEvents()` 接口允许大脑灵活读取或回退事件流。  
8. 多脑模式下按需分配容器，TTFT 中位数降低约 60%。  
9. 统一 `execute(name, input)` 接口支持任意工具或环境。  
10. 元框架设计固定接口，允许框架本身随模型进步而更换。

# TAKEAWAYS  
1. 解耦架构实现组件独立故障恢复和替换。  
2. 将认证令牌与沙箱隔离，提升安全性。  
3. 持久化会话日志支持长期任务和上下文回溯。  
4. 按需容器显著降低首次响应延迟。  
5. 统一工具接口允许灵活扩展多种执行环境。
