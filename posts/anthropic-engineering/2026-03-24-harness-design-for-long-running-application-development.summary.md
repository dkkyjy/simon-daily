# ONE SENTENCE SUMMARY

利用GAN启发的多代理架构（生成器+评估器+规划器）显著提升Claude在长时编码和前端设计中的输出质量。

# MAIN POINTS

1. 长任务代理常因上下文填满而“焦虑”，过早收尾导致质量下降。
2. 上下文重置（完全清空并传递手稿）比压缩更有效，但增加开销。
3. 自我评估偏差：代理总是赞扬自己的输出，需分离生成与评估角色。
4. 主观设计质量可通过四条具体标准（设计、原创、工艺、功能）量化。
5. 评估器使用Playwright MCP实时交互页面进行评分，反馈给生成器迭代。
6. 全栈开发采用三代理：规划器扩展规格，生成器分步实现，评估器QA。
7. 规划器避免过早技术细节，只定义产品上下文和高层设计方向。
8. 生成器与评估器通过文件通信，每轮协商“冲刺合约”明确完成定义。
9. 完整harness（6小时/$200）产出远优于单代理（20分钟/$9），但成本高。
10. 随着模型进步，应重新审视harness，移除不再必要的组件并添加新能力。

# TAKEAWAYS

1. 将生成与评估分离是提升AI复杂任务质量的最有效杠杆之一。
2. 主观标准（如美学）可通过明确、可操作的准则被量化并用于迭代。
3. 上下文重置是处理代理“焦虑”的关键技术，尽管增加了复杂度和成本。
4. 随着模型能力增强，需简化harness结构，只保留真正负载的部分。
5. 评估器需要精心调校（如提供负样本、强化阈值）才能可靠发现缺陷。
