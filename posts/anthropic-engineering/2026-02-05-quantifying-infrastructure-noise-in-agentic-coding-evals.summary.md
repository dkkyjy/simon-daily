# ONE SENTENCE SUMMARY:
基础设施配置差异可导致智能体编码评估分数波动达6个百分点，需标准化报告。

# MAIN POINTS:
1. 终端基准2.0中资源配置差异造成6个百分点差距。
2. 严格资源限制使容器因瞬态峰值被OOM终止。
3. 从严格到无限制，基础设施错误率从5.8%降至0.5%。
4. 3倍以上资源允许代理尝试更耗资源的策略。
5. 无限制相比严格限制成功率提升6个百分点。
6. 不同模型对资源配置的敏感度不同。
7. SWE-bench中5倍RAM仅提高1.54个百分点。
8. 时间、API延迟等因素也引入评估噪声。
9. 建议分离保证分配与硬限制以校准分数。
10. 低于3个百分点的领先应持怀疑态度。

# TAKEAWAYS:
1. 视资源分配为独立实验变量，严格记录与控制。
2. 基准发布应同时指定保证分配和硬限制参数。
3. 2-3分领先可能仅来自更大虚拟机而非能力差距。
4. 校准资源上限至分数差异落入噪声范围可防膨胀。
5. 外部评估者应多次运行取平均以消除噪声。
