## 并行审计的工作原理

当你运行 `/ads audit` 时，6 个专门的代理会同时启动。每个代理处理一个特定领域。它们并行运行，而不是串行，因此跨所有平台的完整审计只需几分钟。

```
/ads audit
├── audit-google (80)
├── audit-meta (50)
├── audit-creative (21+)
├── audit-tracking (8+)
├── audit-budget (24)
└── audit-compliance (18+)
        ↓
统一健康评分（0–100）
```

**6 个并行代理同时分析你的广告账户**

## 评分方式

每个检查项都有一个严重性乘数（严重 5.0x，高 3.0x，中 1.5x，低 0.5x）和一个类别权重。加权公式产生一个 0-100 的健康评分，并附有 A 到 F 的等级。严重发现项主导评分，这意味着单个断裂的转化跟踪设置就会让你的等级崩溃，无论其他一切多么干净。

### 加权评分算法

```
评分 = Σ(通过 × 严重性 × 类别权重) / Σ(总数 × 严重性 × 类别权重) × 100
```

### 类别权重（6 个类别）

| 类别 | 权重 |
|------|------|
| 转化跟踪 | 25% |
| 浪费支出 | 20% |
| 结构 | 15% |
| 关键词 | 15% |
| 广告 | 15% |
| 设置 | 10% |

### 严重性乘数

| 级别 | 乘数 |
|------|------|
| 严重 | 5.0x |
| 高 | 3.0x |
| 中 | 1.5x |
| 低 | 0.5x |

### 示例影响

转化跟踪类别中失败的严重检查项：
影响 = 5.0（严重性）× 0.25（类别）= 1.25 分

## 输出实际看起来什么样

你不会得到一份 60 页的幻灯片。你会得到一份**按预估收入影响排序的、带评分的优先级问题列表**。每个发现项包括：

* 具体问题（例如：“广告系列 X 有 23% 的搜索词浪费——每月 $4,200 的无关点击”）
* 严重性评级（严重/高/中/低）及加权乘数
* 带有逐步说明的精确修复方法
* 预估月度节省额或收入提升
* 标记为“速赢”的 15 分钟内可修复项

仅严重发现项——转化跟踪缺口、预算分配错误、受众重叠——通常就能识别出 **15-30% 的浪费广告支出**。以每月 $50K 的广告预算计算，那就是一条命令发现的 $7,500-$15,000 的节省。
