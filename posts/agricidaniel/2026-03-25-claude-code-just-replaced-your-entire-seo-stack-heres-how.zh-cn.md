我构建了 [claude-seo](https://github.com/AgriciDaniel/claude-seo)，这是一个用于 Claude Code 的开源 SEO 技能包，它运行一次完整的技术审计、内容分析、结构化数据标记检查、核心网页指标评估以及生成式引擎优化——全部通过终端中的一条命令完成。无需浏览器标签页。无需仪表盘。无需信用卡。
在你喊出“又一个 AI 封装器”之前——这不是一个 ChatGPT 提示词。它是由 9 个并行代理协调的 14 个子技能组成的，这些代理会实际爬取你的网站、解析你的 HTML，并给出带有优先级、可操作的修复建议。让我带你了解一下。
## claude-seo 实际做什么
当你在 Claude Code 中运行 `/seo` 并指向你的项目时，以下内容会触发：
* **技术审计代理** - 爬取你的站点地图，检查规范标签、hreflang、robots.txt、重定向链和 404 错误
* **页面优化代理** - 分析标题标签、元描述、标题层级、关键词密度和内部链接
* **结构化数据代理** - 验证现有结构化数据并生成缺失的 JSON-LD（文章、常见问题、操作指南、组织）
* **核心网页指标代理** - 标记阻塞渲染的资源、图片优化机会、CLS 问题和 LCP 瓶颈
* **内容代理** - 评分可读性、检查内容薄弱项、基于搜索结果页面（SERP）分析建议内容缺口
* **GEO 代理** - 针对 AI 搜索引擎（Perplexity、SearchGPT、Gemini）进行优化，采用答案优先格式和引用钩子
* **外链代理** - 分析你的链接档案并识别有害链接
* **本地 SEO 代理** - 检查 NAP 一致性、Google 商家资料优化和本地结构化数据
* **竞争对手代理** - 提取你焦点关键词的排名前十的 SERP 结果，并逆向工程其策略
所有 9 个代理并行运行。对于一个典型的 50 页网站，**完整的审计在三分钟内完成**。试试找一个机构能做到这个。

## 实际命令
以下是实际使用时的样子。你在 Claude Code 中打开你的项目并输入：
```
/seo audit - url https://yoursite.com - focus-keyword "你的目标关键词"
```
输出是一个按影响排序的优先修复列表。不是一份没人读的 47 页 PDF——而是一个 **你可以在终端中直接执行的排名操作列表**。Claude Code 甚至可以为你应用这些修复。发现缺少元描述？它写一个。缺少结构化数据标记？它生成 JSON-LD 并注入到你的页面中。H1 标签在 12 个页面上重复？几秒内修复。

## 每月 300 美元的对比
让我具体说明你替换了什么：
* **Ahrefs（每月 99 美元）** - claude-seo 涵盖了网站审计、内容缺口分析和外链检查。你失去了庞大的外链数据库，但对于大多数中小型网站来说，审计才是关键。
* **Surfer SEO（每月 89 美元）** - 页面优化代理负责内容评分、关键词密度和 NLP 优化。它没有 Surfer 的实时 SERP 相关性数据，但它做了 Surfer 做不到的事：**它实际上可以原地重写你的内容**。
* **Screaming Frog（每月 26 美元）** - 技术审计代理爬取你的网站并捕获相同的问题：死链、重定向链、缺失标签、重复内容。输出也更整洁。
* **Schema Pro（每年 79 美元）** - 结构化数据代理自动生成并验证 JSON-LD。无需 WordPress 插件。

## 没人谈论的 GEO 角度
这正是 claude-seo 与“只是另一个终端里的 SEO 工具”不同的地方。它有一个专门的生成式引擎优化代理。传统的 SEO 工具针对谷歌的蓝色链接进行优化。但 **40% 的 Z 世代现在开始在 AI 工具上搜索，而不是谷歌**。Perplexity、SearchGPT、Gemini——它们从你的内容中获取信息的方式与 Googlebot 不同。
GEO 代理优化你的内容，使其更容易被 AI 搜索引擎引用：答案优先的格式、LLM 可以解析的结构化数据、附带来源的值得引用的统计数据，以及匹配人们在对话式搜索中提问方式的常见问题模块。这就是 2026 年 SEO 的发展方向，而每月 300 美元的工具栈没有一个涵盖这一点。
