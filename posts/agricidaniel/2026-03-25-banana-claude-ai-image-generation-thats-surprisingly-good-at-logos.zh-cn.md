# banana-claude: 出奇擅长 Logo 的 AI 图像生成

**日期:** 2026-03-25 00:00 UTC  
**链接:** https://agricidaniel.com/blog/banana-claude-ai-image-generation  

---

说实话：我构建 banana-claude 是为了解决一个无聊的问题。我需要博客文章的题图以及用于内容推广的社交媒体图像，而我厌倦了打开 Canva 或在单独的浏览器标签页里操作 Midjourney。我希望在终端内就能生成图像，通过斜杠命令触发，并与我的内容工作流集成。  
**我没想到的是，它在 Logo 方面竟然真的很好。**  
不是那种“AI 做的 Logo 看起来和其他 AI Logo 一样”的好。是真正的好。那种好到客户看到概念图就说“对，就是这个方向”，而且第一轮就通过。这让我很惊讶，我认为值得探讨一下原因。  
## 什么是 banana-claude？  
banana-claude 是一个 Claude Code 技能，它使用 Google 的 Gemini 模型生成图像。你输入 `/banana` 加上你想要的内容描述，它就会生成图像。表面上很简单。  
但有趣的部分是“创意总监模式”。它不会直接把你的提示词传给图像模型（那样会产生我们都已经习惯的、千篇一律的过度处理风格），**banana-claude 有一个中间层来对生成过程进行艺术指导。** 它分析你的需求，考虑构图、色彩理论、排版位置和视觉层次，然后构建一个优化后的提示词，从而产生显著更好的结果。  
可以把它理解为：对插画师说“给我画个 Logo”与先向创意总监简要说明，再由创意总监向插画师传达的区别。最终输出的质量差距非常明显。  
为什么叫“banana”？老实说，我需要一个简短好记、并且在 GitHub 上可用的名字。banana-claude 就这么定了。有时候最好的工程决策就是那些你不需要过度思考的决策。  
## 创意总监模式的实际工作原理  
当你触发创意总监模式时（这是默认模式，你需要主动退出），后台会发生以下步骤：  
1. **意图分析** – banana-claude 判断你要求的是哪种视觉类型：照片、插画、Logo、图标、图表、社交图像等。每种类型都有不同的优化策略。这一分类步骤至关重要，因为引导 Logo 的提示技巧与引导照片完全不同。  
2. **风格映射** – 根据意图，它会选择合适的风格参数。Logo 会得到干净的线条、有限的色调以及可缩放性考虑。博客题图会得到氛围照明和编辑式构图。社交图像会得到粗体文字放置和针对平台的比例。这些风格映射是我经过大约 3 周的测试构建出来的，生成了大约 500 张图片，以找到每个类别中能稳定产出高质量结果的参数。  
3. **提示工程** – 你随意的描述会被转化为结构化的提示词，包含关于构图、负空间、色彩关系和技术约束的具体指令。这就是魔法发生的地方——**好提示词和优秀提示词之间的输出质量差距约为 10 倍。** 提示工程还会加入负面约束：“无渐变”、“无投影”、“无库存照片风格”——这些正是让 AI 图像看起来明显是 AI 生成的东西。  
4. **生成** – 优化后的提示词发送给 Gemini 的图像生成 API。  
5. **质量检查** – banana-claude 根据原始意图评估输出。如果不符合要求（比如比例错误、构图杂乱、风格不匹配），它会调整参数重新生成。评估使用一个评分标准：构图平衡、色彩和谐、文字可读性（如果适用）以及与被检测意图的风格一致性。  
（质量检查步骤大约增加 5 秒生成时间。我曾考虑为了速度而移除它，但命中率的提升太过显著——大约减少了 40% 的重新生成需求。）

## Logo 的意外发现  
我是在为自己项目生成素材时注意到 Logo 质量的。我需要为正在构建的一个工具快速做一个 Logo 概念，于是运行了 `/banana creative director: minimalist logo for an SEO automation tool, think clean tech aesthetic`，结果……居然真的能用。  
不是作为最终 Logo——没有任何 AI 工具能取代品牌设计师完成最终交付物。但作为概念？作为设计简报的起点？**它产出的概念，人类设计师需要探索 2-3 小时才能达到。**  
我认为原因是 Gemini 的训练数据与创意总监模式的风格约束相结合。当你对模型说“极简 Logo”，然后提示工程加上“单一颜色、几何形状、可缩放到 16px 图标、干净的负空间、无渐变”，你就消除了大多数让 AI Logo 看起来像 AI Logo 的失败模式。约束起到了关键作用。无约束的生成会产生千篇一律的结果。高度约束的生成则会产生专注、可用的结果。  
我系统地测试了这一点。相同的 Logo 简报，用创意总监模式生成 50 次，不用则生成 50 次。**使用创意总监模式，34/50（68%）可作为概念起点；未使用时，只有 8/50（16%）。** 提示工程层将命中率提升了 4 倍。这正是这个工具存在的全部理由。

## 使用场景（我实际生成的内容）  
以下是我一周内用 banana-claude 生成的内容：  
* **博客题图** – 本站的每篇文章都有一张用 banana-claude 生成的题图。抽象、编辑风、匹配深色主题。每张图大约 15 秒。我生成 3 个选项，选最好的一张，所以每篇博客题图的总时间不到一分钟。  
* **社交媒体图像** – LinkedIn 帖子、Twitter/X 卡片、社区公告。banana-claude 知道平台尺寸，所以我只需要指定“linkedin post”，它就会处理比例。对于 AI 营销中心，我每周生成 5-7 张社交图像。  
* **OG 图像** – 分享链接时显示的预览图。作为 claude-blog 发布工作流的一部分自动生成。无需手动步骤——发布一篇文章，就得到一张 OG 图像。  
* **Logo 概念** – 为新的项目或客户提案快速探索。不是最终 Logo，但提供强有力的起点。我曾在 3 次客户演示中使用了 banana-claude 的 Logo 概念，每次客户都选择了其中一个作为进一步发展的方向。  
* **广告创意** – 用于 Google Ads 广告系列的展示广告图像。当 claude-ads 需要广告组的视觉素材时，它会调用 banana-claude。它从一个简单的简报中生成多个尺寸变体（300x250、728x90、160x600）。  
**与其他工具的集成才是让它变得实用而非新奇的关键。** banana-claude 不是一个独立图像生成器，需要时你才去访问它。它是更大工作流中的组件。claude-blog 自动调用它生成题图。claude-ads 调用它生成广告创意。其他场景我手动调用。  
## 与其余技术栈的集成  
banana-claude 的设计目标是不仅供人类调用，也供其他技能调用。它的定位如下：  
* **claude-blog** – 发布新文章时，claude-blog 会自动触发 banana-claude，根据文章标题和内容摘要生成题图和 OG 图像。无需手动步骤。生成的图像与网站视觉语言匹配，因为我调整了风格映射，使其生成深色主题、抽象风格、符合 #0A0A0A 审美观的视觉内容。  
* **claude-ads** – 创建展示广告活动时，claude-ads 通过 banana-claude 生成广告创意的变体。它每个广告组生成 3-5 个选项，针对目标尺寸进行优化。创意会融入广告的标题和行动号召，并根据风格映射的文字放置规则进行定位。  
* **手动使用** – `/banana` 用于快速的一次性生成。我每天使用 4-5 次，用于社交内容、演示幻灯片以及随机的视觉需求。  
技能之间的通信通过 Claude Code 的标准工具接口进行。banana-claude 暴露其生成函数，其他技能像调用任何工具一样调用它。**这种可组合性正是为什么我把所有东西构建成独立技能，而不是一个单一的巨型工具。** 查看所有部分如何连接，请参考[我的 AI 营销自动化栈概述](/blog/ai-marketing-automation-stack)。  
## 局限性（实话实说）  
banana-claude 不会取代你的设计团队。具体来说：  
* **图像中的文字** 仍然时好时坏。Gemini 在这方面有所改善，但文字渲染的正确率大概在 75% 左右。对于带有文字标识的 Logo，预计需要重新生成几次。在文字不重要的图像中（抽象背景、基于图案的设计），这个问题就不存在了。  
* **复杂的插画** 如果涉及特定的空间关系（“站在停在建筑物前面的汽车旁边的人”），可能会出问题。简单的构图效果最好。你添加的元素越多，模型混淆相对定位的可能性就越大。  
* **跨多次生成的品牌一致性** 很难。每次生成是独立的，因此要保持一系列图像的精确风格，需要仔细的提示词。我正在开发一个“风格记忆”功能，用于缓存成功的风格参数并复用它们，但尚未就绪。  
* **最终生产素材** 仍然需要人类设计师。banana-claude 适用于概念、草稿和内容图像——不适用于将印在名片和广告牌上的公司 Logo。输出分辨率足够用于网络，但不适用于印刷。  
（如果有人告诉你他们的 AI 工具完全取代了专业设计师，那么他们要么在撒谎，要么设计标准非常低。）  
## 试试看  
banana-claude 是开源的，使用 MIT 许可证，目前在 GitHub 上有 41 颗星（收录在我的 [2026 年最佳 Claude Code 技能](/blog/best-claude-code-skills-2026) 指南中）。按星数算，它是我较小的仓库之一，但却是我个人最常用的工具之一。Gemini API 费用很低——我每月在图像生成上花费大约 2 美元，覆盖约 200-300 张图像。  
将其安装为 Claude Code 技能，添加你的 Gemini API 密钥，然后运行 `/banana`。从简单的东西开始——一张博客题图或社交图像——看看创意总监模式如何处理。**当它第一次从一行描述中生成出真正不错的东西时，你就会明白为什么我一直用它。**  
如果你用它构建了有趣的东西，或者发现了它的长处（或严重的失败案例），我很想听听。创意总监提示词的最佳改进都来自社区反馈。一位用户发现，添加颜色约束（“仅使用 #E07850 和 #0A0A0A”）可以显著提高品牌一致素材的质量。现在这已经成为了一个内置功能。把你的结果发表在 AI 营销中心，或者在 GitHub 上提 Issue。
