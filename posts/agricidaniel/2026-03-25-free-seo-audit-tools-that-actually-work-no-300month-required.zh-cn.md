## 其他真正值得使用的免费工具

claude-seo 并不是唯一一个免费工具。下面是我每天使用的其他工具，全部 0 美元。

### Google Search Console

**这是现存最被低估的 SEO 工具，而且完全免费。** Google 直接告诉你你的网站在哪些查询中出现，你的点击率，你的平均排名，以及哪些页面有索引问题。大多数人只瞥一眼总览面板就忽略其余内容，这是个错误。

仅 Performance 报告就比大多数付费关键词工具更有价值。按页面、查询、日期范围、国家筛选。关注那些你排在 5-15 位的查询（“触及距离”关键词）。这些页面只需要小幅优化就能跳到第一页。我仅仅通过分析 Search Console 数据、调整标题标签、元描述和内容深度，就把几十个页面从 8-12 位移到了前 5 位。

Coverage（现在叫“Pages”）报告精确地告诉你 Google 能索引和不能索引哪些页面，以及原因。爬取错误、重定向链、noindex 问题——全都在那里。免费。

### Google Lighthouse / PageSpeed Insights

Lighthouse 直接在 Chrome 开发者工具中运行（Ctrl+Shift+I → Lighthouse 标签页），给你核心网页指标得分、可访问性审计、最佳实践检查和 SEO 审计。PageSpeed Insights 是网页版，额外添加了真实世界的 CrUX（Chrome 用户体验报告）数据。

**这些工具衡量的是 Google 实际用于排名信号的内容。** 核心网页指标（LCP、FID/INP、CLS）是已确认的排名因素。如果你付费买了工具检查页面速度却不同时运行 Lighthouse，那你做错了。

专业提示：在无痕模式下运行 Lighthouse，不要开启扩展程序。扩展程序会注入脚本，降低你的性能得分，给你不准确的结果。我曾见过有人因为一个 40 分的性能得分而惊慌，结果在测试时禁用广告拦截器后，得分跳到了 85。

### 丰富结果测试

Google 的[丰富结果测试](https://search.google.com/test/rich-results)可以验证你的结构化数据标记，并精确显示你的页面符合哪些丰富结果条件。FAQ 摘要、操作步骤卡片、产品列表、食谱卡片——如果你的结构化数据有效，该工具会确认；如果无效，它会告诉你具体哪里有问题。

**每次用 claude-seo 审计后，我都会用它来双重检查结构化数据建议。** 这是权威来源，因为它是 Google 自己的验证器。如果它说你的结构化数据有效，那就是有效。

### Screaming Frog（免费版）

Screaming Frog 的免费版每个网站最多爬取 500 个 URL。对于中小型网站来说足够了。它提供完整的技术图景：死链、重定向链、重复标题、缺少元描述、标题层级问题、图片 alt 文本审计等等。

限制是 500 个 URL 的上限。如果你的网站更大，要么使用付费版，要么使用 claude-seo（没有 URL 限制）。不过对于 500 页以下的网站，免费的 Screaming Frog 爬取结合 claude-seo 的 AI 分析，能提供比任何单一付费工具更完整的审计。

## 为什么开源在 SEO 审计中胜出

除了明显的价格优势外，开源 SEO 工具还有三个结构性优势，是付费工具无法比拟的：

**1. 不收集数据。** 当你通过 Ahrefs 或 Semrush 运行审计时，你的 URL 及所有相关数据都会发送到它们的服务器。它们会聚合这些数据（当然是匿名化的）来改进自己的产品和数据库。而当你运行 claude-seo 时，审计是在本地进行的，你的数据保留在你的机器上。对于在 NDA 下审计客户网站的代理机构来说，这一点非常重要。

**2. 可定制性。** 如果 claude-seo 的标题层级检查不符合你团队的 SEO 准则，你可以修改它。如果你想为你的特定 CMS 怪癖添加自定义检查，你可以添加。试试在 Ahrefs 上做同样的事？付费工具是“要么接受，要么放弃”，开源工具是“接受它，然后让它成为你自己的”。

**3. 社区驱动的改进。** claude-seo 已有 47 位贡献者提交了改进、修复和新功能。一个活跃的开源项目其改进速度往往超过商业开发，因为社区比任何公司的 SEO 团队都大。一位德国的用户注意到结构化数据验证缺少对 `SpeakableSpecification` 的支持，于是通过 PR 添加了它。这种小众的改进在付费工具中只有足够多的企业客户抱怨时才会发生。

## 常见问题

### claude-seo 真的是免费的吗？

是的。核心工具采用 MIT 许可证，100% 免费。你需要 Claude Code（需要一个 Anthropic API 密钥或 Claude 订阅），但技能本身不花钱。某些可选集成（如用于关键词数据的 DataForSEO）有自己的 API 费用，但审计功能完全免费，没有限制。

### claude-seo 与 Ahrefs Site Audit 相比如何？

Ahrefs Site Audit 有更多检查项（100+ vs 50+），并且对于非常大的网站（10,000+ 页）有更好的爬取基础设施。claude-seo 有更好的内容分析（AI 驱动 vs 规则驱动）、更好的结构化数据支持，并提供更有可操作性的修复建议。**对于 5,000 页以下的网站，claude-seo 提供相同或更好的审计质量。** 对于拥有数百万页的企业级网站，Ahrefs 的爬取基础设施仍然更优。

### 使用 claude-seo 需要编程经验吗？

你需要习惯打开终端并运行一条命令。仅此而已。实际的命令是 `/seo-audit https://your-site.com`。Claude Code 会处理剩下的一切。如果你能复制粘贴一个 URL，你就能运行 claude-seo 审计。输出是一份结构化的中文报告，而不是需要解读的原始数据。

### 我应该取消 Ahrefs 的订阅吗？

这取决于你用它做什么。如果你主要使用 Ahrefs 进行外链分析和竞争对手研究，那就保留它——没有任何免费工具能与之匹敌。如果你主要用它做网站审计和关键词研究，那就先试用 claude-seo + Google Search Console 一个月，看看是否会怀念什么。我没有。**大多数人每月付 99 美元买一个工具，却只用到了 20% 的功能。** 弄清楚你真正需要的是哪 20%，然后为其余部分寻找免费替代品。
