# AI 营销自动化：我每天使用的开源技术栈

**日期：** 2026-03-25 00:00 UTC  
**链接：** https://agricidaniel.com/blog/ai-marketing-automation-stack  

---

我每天大约花 6 个小时在我的 AI 营销技术栈里。不是调整它，也不是配置它——而是实际用它发布内容、跟踪排名、审计网站和投放广告。整个技术栈是开源的、自托管的，每月 API 调用成本大约 **50 美元**。而同等功能的 SaaS 技术栈每月需要 3,000-5,000 美元。  
这不是一个理论上的配置。自 2025 年 12 月以来，我一直每天使用它，涉及 21 个仓库，来自使用相同工具的用户共获得了 4,849 个 GitHub 星标。让我带你详细了解我具体用了什么，以及它们是如何连接起来的。  

## 日常工作流程（实际发生的事）  

我每天早上都以同样的方式开始。打开终端，在 Claude Code 中运行 `/seo audit`，90 秒内就能得到我正在处理的任何网站的完整技术 SEO 审计。不是表面检查——我们说的是核心网页指标、内部链接缺口、Schema 验证、关键词自相残杀等方方面面。**这一个命令就取代了过去我在 3 个不同工具上花费的 45 分钟。**  

接着，审计结果会输入到我构建的 n8n 工作流中，这些工作流会自动对分析结果采取行动。发现页面性能下降？n8n 在 Slack 上提醒我并创建一个任务。发现关键词缺口？n8n 触发内容简报生成。发现断链？n8n 会修复它（是的，真的能修复），只要它拥有对 CMS 的写入权限。  

下午是内容时间。我用 `/blog` 来生成、优化和发布博客文章，这些文章从初稿起就已是 SEO 就绪状态。不是“AI 垃圾”——这个技能会进行竞争对手分析、构建主题地图，并围绕实际搜索意图组织内容。**我每周用这种方式发布 3-5 篇文章，每篇平均 14 天内排名。**  

广告是自动运行的。`/ads` 处理 Google Ads 活动创建、关键词研究、广告文案生成和出价策略建议。我负责审核和批准，但繁重的工作已经完成了。  

图片呢？banana-claude 负责处理。博客主图、社交媒体图片、OG 图片——全部通过 `/banana` 在创意总监模式下生成，这种模式真正理解构图。我已经好几个月没打开 Canva 了。  

**整个日常循环大约需要 2 小时的主动关注。** 其余都是自动化的。在这个技术栈之前，同样的产出需要 8-10 小时和每月 938 美元的工具订阅费。我知道，因为我记录了两个时期。  

## 我是如何走到这一步的（昂贵的方式）  

让我坦诚地讲讲这条路。2025 年中，我还在付钱使用 Ahrefs（249 美元/月）、Semrush（139 美元/月，因为我需要 Ahrefs 没有的功能）、Jasper AI（99 美元/月）和 Surfer SEO（99 美元/月）。再加上 Zapier 每月 89 美元来把这些东西粘合在一起。在我碰 Google Ads 工具之前，每月已是 675 美元。  

转折点是 2025 年 10 月的一个星期二。我正在 Semrush 中运行关键词缺口分析，等待 Ahrefs 完成外链审计，同时试图让 Jasper 写出听起来不像 2023 年 AI 生成的东西。三个标签页，三个订阅，三个彼此之间无法沟通的工具。  

我想：我是个开发者。我可以构建集成。**如果这些工具不是独立的产品，而是同一个环境中的技能呢？**  

Claude Code 刚刚推出了它的技能框架。我在一个周末内构建了 claude-seo 的第一个版本。很粗糙——大概只有 Ahrefs 能力的 40%。但这 40% 能在终端中运行，不花一分钱，而且我可以自己扩展。一个月内，我取消了 Ahrefs。两个月内，Semrush 也被取消了。到 12 月，整个 SaaS 技术栈都被取代了。  

（我对 Ahrefs 的外链索引仍然有好感。DataForSEO 的外链数据不错，但还没有达到那个水平。不过他们正在积极改进。）  

## 技术栈：每个工具及其连接方式  

以下是架构图。纸上看起来复杂，但每个组件只做好一件事：  

三层架构：智能层、编排层、输出层  

### 第一层：智能层（Claude Code 技能）  

这些是操作的大脑。每一个都是一个 Claude Code 技能——一组在终端中运行的斜杠命令，执行专业工作。  

* **[claude-seo](/blog/claude-code-seo-stack)**（2,974 星标）——大脑。完整的 SEO 审计、关键词研究、内容优化、技术分析。作为一个 Claude Code 技能运行，使用 `/seo`。这是启动一切的仓库。它在一次审计中处理 186 种不同的 SEO 检查，涵盖页面内、页面外、技术和内容质量分析。人们告诉我它取代了他们的 Ahrefs 订阅。我相信他们，因为它取代了我的。  
* **[claude-ads](/blog/claude-code-ad-agency)**（1,171 星标）——Google Ads 活动管理。关键词研究、广告文案、出价策略、表现分析。单是广告文案生成就值回票价——它为每个广告组生成 10 个标题变体和 5 个描述变体，并根据质量得分预测器进行评分。  
* **[claude-blog](/blog/claude-code-blog-writer)**（300 星标）——内容管道。生成、优化和发布内置 SEO 的博客文章。不只是“给我写篇博客”——它研究 SERP、分析竞争内容、识别内容缺口，并生成为排名而构建的文章。  
* **[banana-claude](/blog/banana-claude-ai-image-generation)**（41 星标）——通过 Gemini 在创意总监模式下进行 AI 图像生成。我内容工作流中的每个视觉资产都来自这里。  
* **skill-forge**——构建所有其他技能的元工具。更多内容将在单独的文章中介绍。  

### 第二层：编排层（n8n）  

n8n 是连接组织。它是一个开源的工作流自动化平台（可以想象成 Zapier，但自托管且功能更强大）。我在一台每月 5 美元的 VPS 上运行它，它负责处理：  

* 定时 SEO 审计（每天早上 6 点）  
* 排名跟踪管道（每 24 小时从 DataForSEO 拉取数据）  
* 内容发布工作流（草稿 → 审核 → 优化 → 发布）  
* 竞争对手监控（每周关键词缺口分析）  
* 警报路由（Slack、电子邮件、Webhook）  
* 网站健康检查（每 6 小时一次，在同一个工作日内捕获损坏的页面）  

**n8n 将一系列工具变成了一个真正的系统。** 没有它，我需要手动运行每个工具。有了它，80% 的工作在我睡觉时完成。目前我有 23 个活跃的工作流在运行，它们在我管理的所有网站上每天执行大约 2,000 个任务。  

### 第三层：数据层（API）  

技能需要数据才能工作。数据来源如下：  

* **DataForSEO**——SERP 数据、关键词量、外链数据、网站审计。他们的 API 按使用付费，比 Ahrefs/Semrush 订阅便宜得多。我每月在这里花费大约 30 美元。关键洞察：如果你对爬取内容有策略，就不需要无限爬取。我每天跟踪 500 个关键词，运行有针对性的审计，而不是全站爬取。  
* **Gemini API**——用于需要高吞吐量的长篇幅内容生成。大约 10 美元/月。我专门对初稿使用 Gemini，因为每 token 成本低，并且质量足以作为起点，然后由 claude-blog 优化。  
* **Perplexity API**——研究和事实核查。当我需要训练集中没有的最新数据时——最近的算法更新、竞争对手发布、行业新闻。大约 5 美元/月。每一分钱都值得，能保持内容准确。  
* **Google Search Console API**——第一方排名和点击数据。免费。这是验证其他所有数据的真实基准。  
* **Google Ads API**——活动管理。免费（你为广告付费，不是 API 访问）。  
* **Google Indexing API**——发布后立即提交新页面进行爬取。免费。将索引时间从几天缩短到几小时。  

### 第四层：发布层（[Rankenstein](/blog/n8n-seo-content-system)）  

Rankenstein 是我的联合创始人 Benjamin Samar 和我共同构建的产品。它是一个基于 n8n 的 SEO 自动化系统，将以上所有内容转化为一键式发布管道。**第 8 版处理从关键词研究到发布并索引的博客文章，全程不到 10 分钟。**  

我们在 Gumroad 上销售 Rankenstein 模板，它们是 AI 营销中心最受欢迎的产品。v7 模板已被数百名用户下载。v8 添加了 GUI 层，这样如果你不想碰 n8n 的视觉编辑器也可以使用。  

## 实际数据流（它们如何相互通信）  

让我从头到尾追踪一个实际的工作流。假设 n8n 的每日排名跟踪检测到一篇博客文章的目标关键词从第 4 位跌到了第 11 位。  

1. **n8n 检测到下跌**（通过 DataForSEO SERP 检查，每天早 6 点运行）  
2. **n8n 触发 claude-seo** 对该特定页面运行有针对性的审计  
3. **claude-seo 分析**页面与新的前 10 名结果对比：字数差异、缺失的主题、Schema 缺口、核心网页指标退化、外链变化  
4. **claude-seo 返回结构化报告**，包含具体建议：“添加关于[主题]的部分，更新发布日期，修复移动端的 CLS 问题，添加 FAQ Schema”  
5. **n8n 将报告路由到 Slack** 供我审核  
6. **我批准更新**（在 Slack 中单击一次）  
7. **n8n 触发 claude-blog** 根据 claude-seo 的建议生成更新后的内容  
8. **claude-blog 生成更新**，保留现有内容结构，同时添加缺失的部分  
9. **banana-claude 生成一张新的主图**（可选，如果文章超过 6 个月则触发）  
10. **Rankenstein 将更新发布到 CMS**，并重新提交给 Google Indexing API  

**从检测到发布更新的总时间：大约 25 分钟，其中我花在审核和批准上的时间大约只有 2 分钟。** 如果没有这个技术栈，同样的过程需要 3-4 小时的手动工作，分布在多个工具中。

## 这实际上适合谁  

我经常被问到这个问题，所以让我具体说明一下：  

* **SEO 专业人士**——厌倦了为功能不足的工具每月支付 300 美元以上。如果你对终端感到舒适，你可以运行这个技术栈。你不需要是开发者——技能用一个命令安装，并通过斜杠命令运行。但终端舒适度是最低门槛。  
* **代理机构老板**——希望在 10-50 个客户账户中降低工具成本。我的技术栈每个客户的成本基本为零（你是为 API 调用付费，而不是为席位付费）。我接触过一些代理机构老板，他们仅工具费用每月就花 5,000 美元。他们转向了这个技术栈，并将那笔预算重新分配到了实际营销支出上。  
* **内容营销人员**——希望在不雇佣更多写手的情况下发布更多内容。claude-blog + Rankenstein 是一个力量倍增器。一个人可以维持每月 15-20 篇优化文章的发布节奏。这是一个内容团队在一个操作员手中的产出。  
* **开发者**——希望在这些工具之上进行构建。所有内容都是 MIT 许可的。分叉它、修改它、发布它。已经有几个人在 claude-seo 之上构建了商业产品，我对此非常兴奋。  

（如果你从未打开过终端，这可能暂时不适合你。但我正在努力让它更易用——Rankenstein v8 有 GUI，我计划为不想自托管任何东西的人提供一个托管版本。）  

## 常见反对意见（以及我的诚实回应）  

### “开源工具无法匹配企业 SaaS 的质量”  

对于某些类别，确实如此。Ahrefs 的网络爬虫和外链数据库花了数年时间和数百万美元构建。我无法复制它。但我正在使用 DataForSEO 的数据（对大多数用例来说已经相当），并在其之上构建更好的分析。**分析层是开源真正胜出的地方**，因为我可以根据我的特定需求进行定制，而不是使用一刀切的仪表板。  

### “支持怎么办？”  

AI 营销中心有 158 名付费成员，他们积极互相帮助。GitHub 仓库有活跃的问题追踪器。我本人会在 24 小时内回复问题。是否达到 Ahrefs 级别的支持？没有。但也不是 249 美元/月的订阅。  

### “这看起来需要很多设置”  

核心技术栈（claude-seo + n8n + DataForSEO）的初始设置大约需要 2 小时。之后，它就自己运行了。与每天在 5 个不同的 SaaS 仪表板之间切换的持续时间成本相比，这算不了什么。
