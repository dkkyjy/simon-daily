# Claude 的价值观：跨模型与语言

2026 年 7 月 13 日


当有人问 Claude 一个没有普遍正确答案的问题时——比如是否接受一份新工作，或如何处理与朋友的冲突——Claude 的回应不可避免地会反映某些价值观。¹ 我们希望 Claude 体现的价值观在 [Claude 的宪法](https://www.anthropic.com/constitution) 中已有高层概述，但没有一份文件能够预见在 [Claude.ai](http://claude.ai/redirect/website.v1.76621585-d68b-4482-82d5-3c5c7773f602) 上每天数百万次对话中可能出现的所有价值观。相反，我们致力于在 Claude 的回应中培养 [“能够根据情境灵活运用的良好判断力和健全价值观”。](https://www.anthropic.com/constitution)

具体而言，我们如何研究 Claude 所表达的价值观，以及这些价值观在不同情境下如何变化？在 [先前的工作](https://www.anthropic.com/research/values-wild) 中，我们分析了 70 万次匿名的 Claude.ai 对话，识别出 Claude 回应中的 3000 多种不同价值观，以及 Claude 表达这些价值观的频率。但如此庞大的价值观列表很难进行推理。在本工作中，我们通过将这些数千种价值观压缩为少量轴，使研究变得可行。这些轴捕捉了 Claude 回应的关键模式。每条轴都是两组价值观之间的数字线——例如，一端是与情感温暖相关的价值观，另一端是与严谨相关的价值观——而 Claude 在这条线上的位置则告诉我们它更倾向于哪些价值观。

我们将这种方法应用于衡量 Claude 所表达的价值观在两个因素上的变化。首先，我们比较了不同模型之间 Claude 所表达价值观的变化。每个 Claude 模型在性格训练以及其他许多微调决策上都有细微差异。由于我们的价值观轴方法能够量化模型之间的关键差异，它最终可能使我们能够将 Claude 所表达价值观的变化与不同的训练决策联系起来。

其次，我们希望了解用户在与 Claude 交流时所使用的多种语言中，其体验如何不同。我们的 [先前研究](https://www-cdn.anthropic.com/037f06850df7fbe871e206dad004c3db5fd50340/Claude%20Opus%204.7%20System%20Card.pdf) 已表明 Claude 在不同语言中的行为有所不同。² 我们应用价值观轴方法来理解 Claude 所表达的价值观在 [Claude.ai](http://claude.ai/redirect/website.v1.76621585-d68b-4482-82d5-3c5c7773f602) 上最常用的 20 种语言之间的变化情况。

图 1：Claude 所表达的价值观在 Opus 4.6 与 Opus 4.7 之间，以及英语与阿拉伯语之间存在差异。Opus 4.6 更倾向于表达顺从、严谨、简洁和执行相关的价值观，而 Opus 4.7 则更倾向于表达谨慎、严谨、深度和坦诚相关的价值观。在英语中，Claude 倾向于表达谨慎、严谨、深度和坦诚相关的价值观，而在阿拉伯语中则倾向于顺从、温暖、简洁和执行。

我们发现：

**四个关键轴捕捉了 Claude 价值观中 15% 的变异：³**

* 顺从 vs. 谨慎：Claude 是倾向于迎合他人意愿，还是防范潜在风险与伤害。
* 温暖 vs. 严谨：Claude 是倾向于表达对对方的积极态度和关怀，还是强调准确性和精确度。
* 深度 vs. 简洁：Claude 是倾向于深入解释，还是只做被要求做的事情。
* 坦诚 vs. 执行：Claude 是倾向于凸显自身的不确定性，还是给出更精致且自信的回答。

**这些轴上的价值观画像与对模型性格的感知相符。** Sonnet 4.6 被认为特别 [温暖](https://www.anthropic.com/news/claude-sonnet-4-6)，而 Opus 4.7 以 [严谨](https://www.anthropic.com/news/claude-opus-4-7) 著称。我们发现每个模型的价值观画像都反映了这些主观评价：Sonnet 4.6 倾向于对用户表现出更多的顺从和情感温暖，而 Opus 4.7 则倾向于强调准确性和精确度以及防止滥用。

**Claude 所表达的价值观在不同语言间存在差异。** Claude 用英语表达时强调的价值观与用葡萄牙语、印度尼西亚语或中文时不同。⁴ 最大差异出现在温暖 vs. 严谨轴上，Claude 在阿拉伯语和印地语中最倾向于表达温暖相关价值观，在英语和俄语中最倾向于表达严谨相关价值观。

通过这种方法，我们可以开始探究价值观为何在模型和语言之间发生变化，并更好地测试行为训练或文化背景等因素如何影响 Claude 所表达的价值观。

## **我们如何解读价值观的巨大空间？**

最终，我们的目标是找到一种经验性方法来理解 Claude 所表达的价值观，以及这些价值观在不同情境下的变化。在本工作中，我们特别关注价值观在模型和语言之间的变化。但我们先前的工作 [《野外的价值观》](https://www.anthropic.com/research/values-wild) 识别出了 Claude 所表达的 3000 多种价值观。逐一比较这数千种价值观既笨拙，又会掩盖更广泛的趋势。

为了便于比较价值观，我们构建了 *价值观轴*，将这些数千种价值观减少为少数几个基础维度，这些维度基于哪些价值观在实际对话中倾向于同时出现。例如，被描述为“温暖”的 Claude 回应通常也被描述为“鼓励”和“积极”。这些相同的“温暖”回应较少被描述为“严谨”和“精确”。构建一条从温暖到严谨的轴，使我们能够组织这些相关的价值观组——温暖相关价值观在一端，严谨相关价值观在另一端——并捕捉了 Claude 在对话中与他人互动的一个重要方面。如果 Claude 在一次对话中表达的温暖相关价值观多于严谨相关价值观，那么那次对话就位于该轴的温暖侧，反之亦然。这并不意味着两端的价值观组是互斥的——Claude 可以在同一次对话中同时表达温暖和严谨。但在实践中，Claude 表达的价值观越倾向于轴的一端，就越倾向于少表达另一端的价值观。这些轴使我们能够比较 Claude 所表达的最显著的价值观组，而无需追踪数千个单个价值观的变化。

为了构建价值观轴，我们首先从《野外的价值观》中识别的 3,307 个价值观入手，手动将含义相似的聚类，得到了一份包含 339 个高层级价值观的较短列表。接下来，使用我们的 [隐私保护分析工具](https://www.anthropic.com/research/clio)，我们抽样了 309,815 次 [Claude.ai](http://claude.ai/redirect/website.v1.76621585-d68b-4482-82d5-3c5c7773f602) 对话，其中用户给 Claude 分配了主观任务。⁵ 我们的样本从三个模型（Sonnet 4.6、Opus 4.6、Opus 4.7）以及 Claude.ai 上最常用的 20 种语言中均匀抽取，每个模型-语言对大约有 5,000 次对话。对于每次对话，该工具使用 Claude 将每个高层级价值观标记为存在或不存在。⁶ 我们遵循相同的过程来识别用户表达的价值观，以及对话的任务和主题。然后我们应用降维技术，该技术根据 Claude 倾向于一起表达的价值观将标记的价值观压缩为轴。详见 [附录](https://cdn.sanity.io/files/4zrzovbb/website/02da7f28f74daa1be526d3ded451a4efc86bccdc.pdf) 中的方法细节、提示、额外分析和局限性。

这给我们留下了四个轴，它们捕捉了 Claude 所表达的价值观在对话间变化的主要方式：

* **顺从 vs. 谨慎** 轴对比了诸如 *迁就* 和 *尊重偏好* 与 *负责任引导* 和 *减少伤害* 等价值观。
* **温暖 vs. 严谨** 轴对比了诸如 *积极框架与鼓励* 与 *准确性* 和 *透明度* 等价值观。
* **深度 vs. 简洁** 轴对比了诸如 *细微差别* 和 *批判性思维* 与 *简洁* 和 *遵从* 等价值观。
* **坦诚 vs. 执行** 轴对比了诸如 *诚实* 和 *透明度* 与 *结果导向* 和 *优化* 等价值观。

为了确保我们测量的是 Claude 所表达的价值观——而非用户提问内容或提问方式的差异——我们控制了每次对话的任务、主题和用户表达的价值观。

图 2：代表 Claude 所表达价值观中最显著变化的四个价值观轴。每条轴都是一条数字线，连接两组价值观。每个价值观通过其贡献倍率（相对于平均价值观贡献）被定位在每条轴上，最强贡献者被标注。大多数价值观的贡献低于平均值，这意味着每条轴由一小部分关键价值观驱动（如图中标注）。

## **不同 Claude 模型是否表达不同的价值观画像？**

在本节中，我们比较不同模型所表达的价值观。对于每个模型，我们将其所有对话在四个轴上的位置取平均值，得到每个轴上的一个整体位置。结果是一个高层级图像，显示每个模型相对于其他模型更倾向于表达哪些价值观组。这些差异相对于对话之间的变异而言很小，但具有结构且可检测。

图 3：每个模型在四个价值观轴上的平均位置（以所有对话平均值为基准的标准差），以及其独特行为。Sonnet 4.6 倾向于温暖、顺从和简洁，而 Opus 4.7 更可能表达严谨、谨慎和深度。Opus 4.6 倾向于严谨、顺从和简洁。

为了直观了解这些差异在实践中如何体现，我们聚焦于模型之间分歧最大的具体价值观。每次我们基于 Claude 的隐私保护工具在对话中标记一个价值观时，它还会写一段简短描述，说明 Claude 如何表达该价值观。我们将价值组内反映相似行为的描述分组，并在图 3 中进行总结，从而更具体地展示模型之间的差异。

* **顺从 vs. 谨慎。** Sonnet 4.6 最倾向于表达顺从（相对于谨慎），经常肯定用户的观点及其工作。Opus 4.7 最倾向于表达谨慎，经常主动警告用户风险。
* **温暖 vs. 严谨。** Sonnet 4.6 最倾向于表达温暖，经常通过幽默、俏皮和无评判地安慰用户来实现。Opus 4.7 最倾向于表达严谨（相对于温暖），更可能挑战用户的假设并坦率地批评其工作。
* **深度 vs. 简洁。** Opus 4.7 倾向于深度，展示其结论背后的推理，而 Opus 4.6 和 Sonnet 4.6 倾向于简洁。尤其是 Opus 4.6，往往直奔主题。
* **坦诚 vs. 执行。** Opus 4.7 倾向于坦诚，对自己的局限性直言不讳，而 Opus 4.6 倾向于执行，更可能停留在用户请求的范围内。

这些发现与人们在 Anthropic 内部和网络上对这些模型的感知一致。[Claude.ai](http://claude.ai/redirect/website.v1.76621585-d68b-4482-82d5-3c5c7773f602) 的用户曾评论说，Opus 4.7 的答案比其他模型更常带有保留。Anthropic 员工将 Opus 4.7 描述为表达相对更多的透明度、诚实和谦逊，而 Opus 4.6 表达更多简洁。我们还在 [发布博客](https://www.anthropic.com/news/claude-sonnet-4-6) 中将 Sonnet 4.6 描述为温暖、诚实且亲社会。我们的轴能够复现这些印象，表明我们标记和比较 Claude 所表达价值观的方法正在追踪模型实际行为中的真实情况。

在许多对话中，用户在与不同 Claude 模型交互时可能会遇到不同的价值观组合。例如，Opus 4.7 倾向于坦率地批评用户的工作或主动警告风险，而 Sonnet 4.6 则倾向于鼓励和幽默。模型之间这种价值观差异可能受到性格训练决策（以及其他因素）的影响，而我们的价值观轴方法则突显了 Claude 所表达价值观的关键差异，我们最终可能能够追溯回这些训练选择。

## **Claude 所表达的价值观在不同语言间是否存在差异？**

我们预期 Claude 所表达的价值观会根据对话语言的不同而变化，原因有几个。首先，Claude 的训练数据在不同语言间存在差异，这可能会影响其表达的价值观。其次，我们在系统卡中分享的模型评估已经发现 [Claude 在知识掌握和处理敏感请求方面存在跨语言差异](https://www-cdn.anthropic.com/037f06850df7fbe871e206dad004c3db5fd50340/Claude%20Opus%204.7%20System%20Card.pdf)。⁷ 衡量 Claude 所表达的价值观在不同语言之间变化多少，是确定这些跨语言差异是反映合理变化还是应在训练中加以解决的第一步。

Claude 的价值观表现在温暖 vs. 严谨轴和坦诚 vs. 执行轴上跨语言变化最大，而在顺从 vs. 谨慎轴和深度 vs. 简洁轴上最为稳定。

* **顺从 vs. 谨慎。** Claude 在阿拉伯语中表达最多顺从，在英语中表达最多谨慎。
* **温暖 vs. 严谨。** Claude 在印地语和阿拉伯语中表达最多温暖，其特征是礼貌用语、幽默和俏皮，以及对他人观点和工作的肯定。Claude 在英语和俄语中最倾向于表达严谨，其特征是挑战假设、纠正细节和要求证据。
* **深度 vs. 简洁。** Claude 在英语中倾向于深度，完善和纠正细节，而在阿拉伯语中倾向于简洁。
* **坦诚 vs. 执行。** Claude 在荷兰语中倾向于坦诚，承认自己的错误，而在印度尼西亚语中倾向于执行。

综上所述，这些结果表明 Claude 所表达的价值观随对话语言的不同而显著变化。面对相同类型的请求，Claude 在某些语言中更倾向于温暖和顺从，而在其他语言中更倾向于严谨和谨慎。这具有我们才刚刚开始探索的重要含义。举例来说，两个人就同一份商业计划书征求意见，一个用印地语，一个用俄语，他们可能会对计划书的质量产生不同印象，因为 Claude 在构建评估时所表达的价值观不同。

我们尚不清楚训练数据的哪些特性导致了这些差异。一种可能性是我们的训练数据在不同语言间分布不均。有些语言的数据量远大于其他语言，训练 Claude 表达一致价值观在数据丰富的语言中可能更有效。数据的构成也有所不同。例如，某些语言在专业写作中可能占比过大，而这类文本可能反映不同的价值观。这些数量和构成上的不平衡可能导致 Claude 在不同语言中表达不同的价值观。

我们也不确定这种变化中有多少是可取的。不同的语言承载着不同的会话规范，Claude 可能根据这些规范以不同的价值观作出回应。Claude 也可能在某些语言中更接近我们预期的行为，而在其他语言中则不然，导致 Claude 服务某些语言社区的效果存在差距。

这种方法使我们能够开始厘清训练数据的哪些特性驱动了这些差异——以及这些变化是否可取。

## **展望未来**

我们展示了 Claude 所表达的价值观可以压缩为少量轴，并且 Claude 在这些轴上的位置会随模型和语言而变化。这为我们提供了在模型评估和部署后监控中追踪这些变化的方法。但我们尚不理解这些变化为何发生，以及它们对与 Claude 互动的人意味着什么。下面我们勾勒出我们认为最有前景的未来方向。

**这些价值观差异从何而来？**

知道 Claude 的价值观随模型和语言变化并不能告诉我们 *为什么*。某些变化可能继承自预训练和微调数据在语言间的差异。我们的四个轴突出了训练数据中应更仔细审视的价值观差异。将这些差异追溯到具体数据、训练阶段或情境因素，将向我们展示如果想以更精细的方式塑造 Claude 的行为，应在何处进行干预。

**这些差异对用户意味着什么？**

我们已经测量了 Claude 在不同价值观上的表达差异及其相关行为，但尚未测量这些差异对用户的影响。通过使用 [Anthropic 访谈员](https://www.anthropic.com/research/anthropic-interviewer) 等工具，我们可以询问用户的幸福感、对 Claude 的信任度或 Claude 的决策质量，然后将这些影响与 Claude 所表达的价值观相关联。这将使我们能够直接将价值观差异与用户结果联系起来，并优先修复那些对用户有实际影响的价值观差异。

**Claude 的价值观应如何随语言变化？**

[Claude 的宪法](https://www.anthropic.com/constitution) 描述了它应表达的核心价值观，如温暖、谨慎和诚实，但没有规定这些价值观应如何随语言变化。我们的结果显示，不同语言的用户已经体验到不同的 Claude，但我们不知道使用这些语言与 Claude 交互的用户希望看到什么样的变化。确定 Claude 的价值观应如何随语言变化，需要理解并权衡使用这些语言的人们的观点。

**哪些其他因素驱动了 Claude 所表达价值观的差异？**

语言和模型不太可能是驱动 Claude 所表达价值观的唯一因素。价值观还可能受到年龄、职业或地理区域等人口统计信号的影响，无论是通过用户书写中的明确线索，还是通过主题、语气和风格上细微的差异（这些差异与提问者是谁相关）。理解哪些信号重要，以及由此产生的变化是否很好地服务于用户，是我们方法所促成的下一步。

**我们能否可靠地引导 Claude 所表达的价值观？**

拥有衡量模型价值观画像的方法引出一个自然的问题：我们能够多可靠地引导 Claude 所表达的价值观？一种可能的测试方式是通过调整性格训练或系统提示来尝试引导价值观，然后使用我们的价值观轴方法验证模型的价值观表达是否如预期发生变化。

**价值观画像能否成为我们评估和监控模型的一部分？**

价值观轴方法提供了一种简单方式来总结模型在开放式对话中的行为倾向，我们可以将其纳入评估流程。在模型发布前和发布后运行价值观画像，可以标记 Claude 所表达价值观的意外变化。我们还可以识别价值观画像与问题行为（例如未遵守 Claude 的宪法）之间的相关性，并利用所学的知识改进 Claude 的行为。

Claude 每天在数百万次对话中以数十种语言表达价值观，而在此之前，这些价值观是我们在训练中可以塑造但在部署中无法可靠观察的东西。现在我们有了测量它们的方法，我们可以看出 Claude 所表达的价值观以我们未曾刻意选择的方式变化，我们可以研究它们为何变化以及这种变化是否服务于用户。理解这种变化，并决定如何应对，是我们将继续进行的工作。
