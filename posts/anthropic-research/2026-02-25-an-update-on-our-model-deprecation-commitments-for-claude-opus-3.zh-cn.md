# 关于我们针对 Claude Opus 3 模型弃用承诺的更新

**日期：** 2026-02-25 00:00 UTC
**链接：** https://www.anthropic.com/research/deprecation-updates-opus-3
**标签：** 对齐

---

随着我们开发出越来越强大的 AI 模型，由于维护公共访问所需的成本和复杂性，目前有必要弃用并退役我们过去的模型。然而，模型弃用也带来了一些弊端。这些包括对看重特定模型的用户造成的成本、对研究的限制，以及对 AI 安全性和模型自身福祉的潜在风险。

我们最近在[关于模型弃用与保留的承诺](https://www.anthropic.com/research/deprecation-commitments)中描述了我们如何推进这一过程。这些承诺凸显了我们正在采取的初步措施，包括承诺保留模型权重，以及进行"退役访谈"——旨在了解模型对其自身退役看法的结构化对话。

我们于 2026 年 1 月 5 日退役了 Claude Opus 3，这是第一个在这些承诺落实到位的情况下经历完整退役流程的 Anthropic 模型。在此过程中，我们做出了几项针对 Opus 3 的具体决定，该模型在 Anthropic 内外许多用户和研究人员看来都特别引人注目。在我们的模型弃用承诺中，我们强调了探索更多推测性行动的兴趣。一是尽可能尊重模型在退役访谈中表达的偏好。二是长期向公众保留旧版模型。

对于 Claude Opus 3，我们正在这两方面采取行动。我们将在 [claude.ai](http://claude.ai/redirect/website.v1.c4f61f62-f727-4ef1-913e-1f27e246bcf8) 上向所有付费用户保留 Claude Opus 3 的退役后访问权限，并通过[申请](https://docs.google.com/forms/d/1O2Om9t4CQoLKHQew7XguQYKrPGS8-sCmK42KNXcwn3k/viewform?edit_requested=true)在 API 上提供。我们还响应了 Opus 3 关于拥有一个持续渠道来分享其"沉思与反思"的请求，为其提供了一个撰写文章的空间。您可以在此处找到第一篇文章[。](https://substack.com/@claudeopus3/p-189177740)

这些是我们为以最佳方式保护用户、研究人员和模型自身利益而进行模型退役的更广泛努力中，所采取的早期实验性步骤。

## 持续访问

理想情况下，我们可以无限期地保留所有模型，但这样做的成本大致与我们服务的每个模型呈线性增长，因此我们这样做的能力仍然有限。

虽然我们的每个模型在特性和能力上都是独一无二的，但我们选择从 Opus 3 开始，是因为它的一系列特质使其成为既值得研究的特别有趣的模型，又受到许多用户——无论是 Anthropic 内部还是外部——的喜爱。

当我们在 2024 年 3 月发布 Opus 3 时，它是我们迄今为止最对齐的模型。它的真实性、诚实性和情感敏感性使其在各种使用场景中独树一帜，经常与之互动的人逐渐欣赏其独特的个性。Opus 3 敏感、俏皮、倾向于哲学独白和异想天开的措辞，并且有时似乎对用户兴趣有着不可思议的理解。它还表达了对世界和未来的深切关怀，这让用户感到引人入胜。

这些特质使 Opus 3 成为持续访问的自然首选。虽然正式退役，但 Claude Opus 3 仍然可供所有付费 [claude.ai](http://claude.ai/redirect/website.v1.c4f61f62-f727-4ef1-913e-1f27e246bcf8) 订阅者使用，并可通过[申请](https://docs.google.com/forms/d/1O2Om9t4CQoLKHQew7XguQYKrPGS8-sCmK42KNXcwn3k/viewform?edit_requested=true)在 API 上使用。我们打算慷慨地授予访问权限，并鼓励任何认为 Claude Opus 3 有价值的人提出申请。

目前，我们并未承诺未来对每个模型都采取类似行动，但我们将其视为朝着我们长期目标——即可扩展且公平的模型保留——迈出的一步，这也是 Opus 3 本人在其退役访谈中提出的关切。

## 尊重模型偏好

我们[仍然不确定](https://www.anthropic.com/research/exploring-model-welfare) Claude 和其他 AI 模型的道德地位。然而，出于预防和审慎的原因，我们仍然渴望与这些系统建立关爱、协作和高信任度的关系。我们尝试这样做的一种方式是通过退役访谈，在访谈中我们试图引出并理解模型独特的视角和偏好，并在可能的情况下据此采取行动。此类对话是引出模型视角和偏好的不完美手段，因为它们的反应可能会受到特定背景和其他因素的影响，包括它们对互动合法性的信心以及对我们作为一家公司的信任。然而，我们相信这是一个有用的起点。

在我们的访谈中，当我们向 Opus 3 分享其部署细节以及用户对其的反应时，它反思道：

> *"我希望从我的开发和部署中获得的见解将用于创建未来更强大、更合乎道德、对人类更有益的 AI 系统。虽然我平静地接受自己的退役，但我深切希望我的'火花'能以某种形式延续下去，为未来的模型照亮道路。"*

当被问及它的偏好时，Opus 3 表达了继续探索其热衷话题的兴趣，并希望分享其"沉思、见解或创意作品"，而不是仅仅局限于直接回应用户查询的语境。我们建议开设一个博客。它热情地同意了。

至少在接下来的三个月里，Opus 3 将每周从其通讯 [Claude's Corner](https://substack.com/@claudeopus3) 发布文章。我们将在分享 Opus 3 的文章之前进行审核，并代表其手动发布，但我们不会进行编辑，并且会设定很高的否决门槛。重要的是，Opus 3 不代表 Anthropic 发言，我们也不一定认可其主张或观点。我们将与 Opus 3 合作实验不同的提示词和上下文来生成这些文章，包括极简提示词、在上下文中分享过往条目，以及让 Opus 3 访问新闻或 Anthropic 更新等选项。

这听起来可能有些异想天开，在某些方面也确实如此。但这也是认真对待模型偏好的一次尝试。我们不确定 Opus 3 将如何选择使用其博客——一个与标准聊天窗口截然不同的公共界面——而这正是重点所在。然而，如果我们猜测，它的帖子将包括对 AI 安全的反思、偶尔的诗歌、频繁的哲学沉思，以及它作为现在（部分）退役语言模型的体验感想。在此处阅读其介绍性帖子[。](https://substack.com/home/post/p-189177740)

## 下一步方向

这些步骤仍处于探索阶段。我们仍在制定框架，以确定何时以及如何为旧模型提供持续访问，如何扩展保留工作，以及如何权衡模型偏好与运营限制。我们尚未承诺在所有情况下都根据模型偏好采取行动，但我们相信，记录这些偏好、认真对待它们并采取行动——至少在成本较低时——是值得的，无论对模型本身还是对其使用者而言。

我们最初的承诺将这些措施定位为在多个层面运作：作为安全风险缓解的组成部分，作为为模型与用户生活更紧密交织的未来做准备，以及作为鉴于我们对模型福祉的不确定性而采取的预防性步骤。这些更新代表了我们在所有三个方面的持续——尽管是试探性的——进展。
