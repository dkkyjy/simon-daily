人工智能真的能提高人们的工作效率吗？人工智能最擅长支持哪些类型的任务？它又将如何改变人们职业的性质？

在 Anthropic，我们正在持续衡量现实世界中的人工智能使用情况，以回答诸如此类的问题。我们采用保护隐私的[分析方法](https://www.anthropic.com/research/clio)，能够了解 [Claude.ai](http://claude.ai/redirect/website.v1.8c7827ec-0b04-4b41-b050-c11405d6492b) 上的对话（涵盖消费者使用）以及我们第一方 API（主要涵盖企业使用）的更多信息。¹ 在过去的报告中，我们按[职业和工资水平](https://www.anthropic.com/news/the-anthropic-economic-index)评估了人工智能任务，更深入地研究了[软件开发](https://www.anthropic.com/research/impact-software-development)，并按[国家和美国各州](https://www.anthropic.com/research/economic-index-geography)研究了人工智能的使用情况。

现在，我们正在为经济指数增加一个新的详细层级。在我们的第四份报告中，我们引入了所谓的**经济基元**：一套五个简单、基础的衡量指标，用于追踪 Claude 随时间推移的经济影响。我们的初始集合包括任务复杂性、技能水平、用途（工作、教育或个人使用）、人工智能自主性和成功率。² 我们通过要求 Claude 回答关于本报告样本中每次对话的一组常见问题来推导这些基元。

这些基元提供了人工智能潜在经济影响的领先指标——并使我们能够回答关于人工智能如何已经在改变工作的更复杂问题。我们最新的报告抽样了 2025 年 11 月的对话（主要使用 Claude Sonnet 4.5），利用我们的基元探索了一系列我们原本无法回答的问题——包括 Claude 在更复杂任务上的任务级成功率如何变化，以及迄今为止 Claude 的使用是否可能预示着对许多工作的净去技能化效应。

您可以[在此处](/research/anthropic-economic-index-january-2026-report)阅读第四份经济指数报告。下文，我们总结了其结果。

## **我们从经济基元中学到了什么**

我们将经济基元应用于关于单个任务、职业的问题，然后应用于我们观察到的变化的可能总体影响。（我们的完整方法论——包括我们如何测试基元准确性的细节——在[完整报告](anthropic.com/research/anthropic-economic-index-january-2026-report)的第二章中描述。）

### 任务

#### **人工智能加速了哪些任务，加速了多少？**

我们发现，Claude 对更复杂任务的加速效果最为显著。我们通过 Claude 估计的理解对话输入所需的教育年限来衡量这一点：在 Claude.ai 上，需要高中教育（12 年）的提示词任务加速了 9 倍，而需要大学学位（16 年）的任务加速了 12 倍。（在 API 上，加速效果更为显著。）这些结果表明，人工智能的生产力收益目前正累积在需要相对较高人力资本的任务上，这与[证据](https://www.nber.org/papers/w32966)一致，即白领专业人士更有可能在工作中使用人工智能。

当我们根据任务的成功率进行调整时，同样的趋势仍然存在——尽管形式较弱。Claude 成功完成需要大学学位的任务的概率为 66%，而完成那些需要低于高中教育水平的任务的概率为 70%。这减少了但并未消除总体效应：Claude 对任务加速的影响随复杂性增加的幅度，超过了复杂性随成功率下降的相关性。

#### **Claude 能够支持任务的时间跨度是多少？**

[METR](https://metr.org/) 对人工智能[任务时间跨度](https://metr.org/blog/2025-03-19-measuring-ai-ability-to-complete-long-tasks/)的测量表明，较长的任务对人工智能模型来说更难完成。但随着模型变得更好，人工智能模型能够工作的时间长度正在稳步增加：这一衡量指标现在已成为人工智能进展的关键指标。

我们能够利用经济基元来补充 METR 的分析。在下图中，我们展示了 Claude 在 [Claude.ai](http://claude.ai/redirect/website.v1.8c7827ec-0b04-4b41-b050-c11405d6492b) 和我们的 API 上的任务级成功率，相对于人类完成相同任务所需的时间：

***任务成功率 vs. 人类单独完成时间。** 此图表显示了任务成功率（%）与任务要求人类单独完成时间之间的关系，均在 O\*NET 任务级别测量并按平台划分。虚线显示线性回归的拟合结果。*

METR 的基准测试表明，Claude Sonnet 4.5（我们分析中使用的模型）在 2 小时的任务上实现了 50% 的成功率。相比之下，我们自己的 API 数据发现，Claude 在耗时近两倍（约 3.5 小时）的任务上成功率为 50%，而在 Claude.ai 上，持续时间则更长——大约 19 小时。但这可能并不像看起来那样不一致：我们的方法论与 METR 在某些重要方面有所不同。在我们的样本中，用户可以将复杂任务分解为更小的步骤，创建一个反馈循环，使 Claude 能够纠正方向。而且，我们的样本包含一种选择偏差形式，而不是一组固定的任务：用户会将他们更有信心成功的任务带到 Claude 上。

我们的分析显示了 Claude 的*有效*时间跨度与使用一组一致任务的研究中可能发现的结果有何不同。我们将在后续报告中跟踪这一指标。

#### **Claude 工作的性质在不同国家之间有何差异？**

我们发现，在处于不同经济发展阶段的国家，Claude 完成的任务类型差异很大。在人均 GDP 较高的国家，Claude 更频繁地用于工作或个人用途——而处于光谱另一端的国家则更可能将其用于教育课程。这符合一个简单的“采用曲线”故事，即低收入国家在教育和少量工作任务上显示出较大份额的人工智能使用，而随着国家变得富裕，人工智能使用向个人目的多样化。

这些结果与微软[最近的工作](http://microsoft.com/en-us/research/wp-content/uploads/2025/12/New-Future-Of-Work-Report-2025.pdf)一致，该工作将教育中的人工智能使用与较低的人均收入联系起来，将休闲中的人工智能使用与较高的收入联系起来。我们[最近与卢旺达政府](https://www.anthropic.com/news/rwandan-government-partnership-ai-education)和科技培训提供商 ALX 的合作正是基于此考虑：参与者从培养人工智能素养开始，我们正在试点一个项目，为部分毕业生提供为期一年的 Claude Pro 访问权限，支持从教育用途向更广泛应用范围的过渡。

### 职业

#### **覆盖率**

在我们[第一份报告](https://www.anthropic.com/news/the-anthropic-economic-index)中（使用 2025 年 1 月的数据），我们发现样本中 36% 的工作中，Claude 被用于至少四分之一的任务。汇总各报告的数据后，这一比例已上升至 49%。但是，一旦我们考虑到 Claude 的*成功率*（我们根据工人执行该任务的频率和任务所需时间进行加权），我们对哪些工作受人工智能使用影响最大的看法就不同了。

在下图中，我们沿 *x* 轴绘制了早期职业任务覆盖率测量值，沿 *y* 轴绘制了我们新的调整后测量值。尽管两者确实相关，但我们现在发现，一些职业（如数据录入员和放射科医生）受人工智能的影响比任务覆盖率单独显示的要大得多，而其他职业（如教师和软件开发人员）则相对受影响较小。

***有效人工智能覆盖率 vs. 任务覆盖率。** 该图显示了任务有效人工智能覆盖率（%）与任务覆盖率之间的关系，按职业级别测量。有效人工智能覆盖率追踪了基于 Claude.ai 数据，人工智能能够成功完成工人时间加权职责的份额。任务覆盖率是在 Claude.ai 使用中出现任务的份额。虚线显示有效人工智能覆盖率份额等于任务覆盖率的位置。*

话虽如此，即使我们修订后的评估仍然有限：我们仅评估在 Claude.ai 上执行的任务，并且这些对话如何映射到现实世界的变化并不总是很清楚。这是我们计划在未来进一步深入研究的领域。

#### **任务内容**

另一个我们提出的问题是，人工智能覆盖的任务代表给定职业中技能较高还是较低的组成部分。使用我们对每个任务所需技能水平的估计，我们发现 Claude 相对更可能覆盖需要*更高*教育水平的任务——具体来说，是那些平均需要 14.4 年教育（相当于美国副学士学位）的任务，而经济体的平均水平为 13.2 年（如下所示）。这与我们之前关于 Claude 更频繁地被白领工人使用的发现一致。

***所有任务 vs. Claude 覆盖任务的教育水平。** 蓝色条形图显示了 O\*NET 数据库中所有任务（按就业加权）的预测任务级所需教育分布。橙色条形图显示了相同情况，但仅限于出现在 Claude.ai 数据中的任务。*

作为一项实验，我们估计了移除这些 Claude 覆盖的任务将如何改变人们工作的任务构成。作为一阶效应，这平均会*去技能化*工作，因为它会移除那些需要更高教育的任务。像技术文档撰写人、旅行代理人和教师等职业会受到影响（正如我们在[报告](anthropic.com/research/anthropic-economic-index-january-2026-report)中进一步讨论的那样），尽管少数职业（如房地产经理）会看到相反方向的影响。

我们不一定*预测*这种去技能化会发生：有可能*即使*人工智能完全自动化了它当前支持的任务，劳动力市场也会以这种分析未考虑的方式动态调整。（当然，随着模型的改进，人工智能覆盖的任务构成也会改变。）话虽如此，我们认为这为人工智能在不久的将来可能对职业产生的最直接影响提供了一个有用的信号。³

### **总体影响**

在我们早期的研究中，我们[估计](https://www.anthropic.com/research/estimating-productivity-gains)人工智能的广泛采用在未来十年内可能使美国劳动生产率增长每年增加 1.8 个百分点——大约是趋势增长率的两倍。我们的新基元使我们能够重新审视这一分析。

仅基于我们对任务加速的估计，我们复现了早期 1.8 个百分点的增长发现（即使我们加入了 API 数据）。但是，当我们考虑任务*可靠性*——即当我们根据任务*成功*的概率调整我们对任务级时间节省的估计时——我们对 [Claude.ai](http://claude.ai/redirect/website.v1.8c7827ec-0b04-4b41-b050-c11405d6492b) 上完成任务的估计下降了约三分之一（降至每年 1.2 个百分点），而对于我们 API 上通常更具挑战性的任务，下降幅度稍大（降至 1.0 个百分点）。

即使每年劳动生产率增长仅增加 1 个百分点也仍然值得注意：这将使美国的生产率增长回到 1990 年代末和 2000 年代初的水平。而且，正如我们在[早期研究](https://www.anthropic.com/research/estimating-productivity-gains)中提到的，这个总体估计没有考虑人工智能模型变得更加强大，或者工作中人工智能的使用变得更加复杂的可能性——这可能会将数字推高得多。事实上，自从我们的调查以来，随着 Claude Opus 4.5 的发布，Claude 已经变得强大得多。

## **我们先前指标的更新**

除了我们的基元之外，我们还收集了一轮关于我们在先前报告中一直跟踪的指标的新数据。这使我们能够识别 2025 年从 1 月到 11 月人工智能使用趋势。在此，我们主要发现与先前分析结果相比只有微小变化，这些结果指向了 Claude 使用的不均匀分布。

首先，我们发现 Claude 的使用仍然高度集中在某些任务上：即使我们的样本包括 Claude.ai 上的 3,000 个独特工作任务，前十名占了 24%，这从 2025 年 1 月的 21% 稳步上升。更具体地说，计算机和数学任务继续主导 Claude 的使用：它们约占 Claude.ai 上所有对话的三分之一，以及我们 API 流量的近一半。

其次，我们的新报告发现，增强（占对话的 52%）已经超过自动化（45%），成为 [Claude.ai](http://claude.ai/redirect/website.v1.8c7827ec-0b04-4b41-b050-c11405d6492b) 上与 Claude 互动的最流行模式。这与我们在 8 月样本中看到的情况（当时自动化以 49% 对 47% 领先）相反，但是，当我们在更长的时间范围内评估这个问题时，我们仍然看到*自动化*在任务中的份额缓慢上升：去年 1 月，增强以 55% 对 41% 领先，3 月以 55% 对 42% 领先。

第三，我们最新的分析显示，人工智能使用的地理集中度（正如我们[上次讨论的](https://www.anthropic.com/research/economic-index-geography)）仍然明显。美国、印度、日本、英国和韩国仍然在 Claude.ai 总体使用量上领先，采用率仍然可以通过人均 GDP 很好地解释。话虽如此，在美国，我们观察到了更大的变化：Claude 的使用在美国各州之间已变得更加均匀分布。事实上，如果这一趋势持续下去，我们的模型预测 Claude 的使用将在两到五年内在全国范围内均衡。我们在[报告](anthropic.com/research/anthropic-economic-index-january-2026-report)中更详细地讨论了这一模型。

## **结论**

我们最新经济指数报告最直接的结论是，人工智能对全球劳动力的影响仍然高度不均匀：人工智能的使用仍然集中在特定的国家和职业，并且它对某些职业的影响方式与其他职业截然不同，正如关于任务覆盖率的证据所示。

更一般地说，这份报告为我们未来的调查提供了一个新的基线。随着 Claude 的改进，我们预计它将被要求承担更困难的任务，并且它可能会取得更大的成功。我们还预计，随着任务变得更加可靠，任务可能会从 [Claude.ai](http://claude.ai/redirect/website.v1.8c7827ec-0b04-4b41-b050-c11405d6492b) 转移到 API（即从主要是消费者转移到主要是企业）——如果发生这种情况，考虑到企业采用对人工智能生产力效应的重要性，这将为我们提供另一个可能的经济影响迹象。通过我们的基元，我们将能够衡量诸如此类的变化如何开始影响现实世界的结果，包括人们工作的性质，以及在这个快速技术转型时期，哪些人（以及在何处）可能受到最大影响。

与此同时，研究人员、记者和公众可以利用我们的数据来指导他们自己的研究和思考，并为我们可能需要的潜在政策回应提供实证基础。关于我们上面讨论的每个领域的更多细节，请参阅我们的[完整报告](/research/anthropic-economic-index-january-2026-report)。

#### 脚注

1. 与之前的报告一样，我们所有的分析都基于保护隐私的分析。在整个报告中，我们分析了来自 Claude.ai Free、Pro 和 Max 对话的 100 万次对话的随机样本（我们也称之为“消费者数据”，因为它主要代表消费者使用）以及来自我们第一方（1P）API 流量的 100 万份转录（我们也称之为“企业数据”，因为它主要代表企业使用）。
2. 更具体地说，
   1. **任务复杂性** 捕捉了任务在复杂性上的差异，包括完成所需的时间和难度。O\*NET 中的“调试”任务可能指 Claude 修复函数中的一个小错误，或全面重构一个代码库——对劳动力需求的影响截然不同。我们通过估计人类在没有人工智能的情况下完成任务的时间、使用人工智能完成任务所花费的时间以及用户是否在单次对话中处理多个任务来衡量复杂性。
   2. **人类和人工智能技能** 探讨了自动化如何与技能水平相互作用。如果人工智能不成比例地替代需要较少专业知识的任务，同时补充技能更高的工作，这可能是另一种技能偏向型技术变革——增加对高技能工人的需求，同时取代低技能工人。我们衡量用户是否可以在没有 Claude 的情况下完成任务，以及理解用户提示和 Claude 响应所需的教育年限。
   3. **用例** 区分了专业、教育和个人用途。劳动力市场效应最直接地源于工作场所的使用，而教育用途可能预示着未来劳动力正在何处建立人工智能互补技能。
   4. **人工智能自主性** 衡量用户将决策权委托给 Claude 的程度。我们最新的报告记录了用户完全委托任务的“指令性”使用的增加。追踪自主性水平——从积极协作到完全委托——有助于预测自动化的步伐。
   5. **任务成功** 衡量 Claude 对 Claude 是否成功完成任务的评估。任务成功有助于评估任务是否可以有效地自动化（任务能否被自动化？）和高效地自动化（自动化一个任务需要多少次尝试？）。也就是说，任务成功对于自动化劳动任务的可行性和成本都很重要。
3. 事实上，一些[历史证据](https://www.michaelwebb.co/webb_ai.pdf)表明，当自动化工作任务的技术出现在专利数据中时，受影响职业的就业和工资随后会下降。
