# ONE SENTENCE SUMMARY

Project Glasswing利用AI模型已发现超一万个高危漏洞，但修补速度成为网络安全新瓶颈。

# MAIN POINTS

1. 与约50合作伙伴用Mythos发现超一万个高危漏洞。
2. Cloudflare找到两千漏洞且假阳性率低于人类。
3. 修补漏洞速度成为新瓶颈，平均需两周打补丁。
4. 扫描超1000个开源项目估计6202个高危漏洞。
5. 已验证高危漏洞中90.6%真实，62.4%被确认。
6. 模型在UK AISI测试中首次完成端到端网络攻击。
7. 维护者请求放慢披露速度因修补不堪重负。
8. 建议加快补丁部署并强化多因素认证等控制。
9. 发布AI安全工具及扫描工具给合格客户。
10. 与OpenSSF合作支持维护者处理漏洞报告。

# TAKEAWAYS

1. 软件开发者应立即缩短补丁周期以降低风险。
2. 网络防御者需加强多因素认证和日志审计等基本控制。
3. 利用AI扫描工具可大幅提升漏洞发现效率。
4. 开源维护者需要更多资源来应对漏洞报告洪流。
5. 业界必须合作开发更强安全防护防止AI模型滥用。
