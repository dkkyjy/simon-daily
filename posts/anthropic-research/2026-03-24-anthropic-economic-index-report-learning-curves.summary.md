# ONE SENTENCE SUMMARY:  
Anthropic报告显示Claude使用正从编码转向更广泛任务，长期用户通过经验获得更高成功率。

# MAIN POINTS:  
1. Claude.ai任务前10占比从24%降至19%，使用分散化。  
2. 编码任务从Claude.ai迁移至API，自动化趋势增强。  
3. 低薪个人查询（如体育、天气）占比上升，平均任务价值下降。  
4. 美国各州使用趋同放缓，国家间差距反而扩大。  
5. 用户根据任务复杂度选择Opus模型，高薪任务使用更多。  
6. 有6个月经验用户成功率高出4个百分点。  
7. 高经验用户更多用于工作、复杂任务和迭代协作。  
8. 新用户更多用于个人和低复杂度查询。  
9. API中出现销售自动化、市场交易等新兴用例。  
10. 早期高技能用户获益更多，可能加剧技能不平等。

# TAKEAWAYS:  
1. 学习效应证实：长时间使用AI能显著提升任务成功率。  
2. 模型选择反映用户对智能成本与效益的理性权衡。  
3. 早期采用者偏向高价值工作，可能扩大技能差距。  
4. 全球AI采用不平等持续，低收入国家落后更严重。  
5. 从编码到多任务扩展，AI正渗透更多普通职业。
