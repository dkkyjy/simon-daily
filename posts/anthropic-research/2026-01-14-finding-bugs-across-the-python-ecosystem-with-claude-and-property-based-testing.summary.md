# ONE SENTENCE SUMMARY:
代理使用Claude和属性测试自动发现NumPy、SciPy等Python库中的数百个bug，部分已被修复。

# MAIN POINTS:
1. 代理通过推理代码属性并编写基于属性的测试来发现bug。
2. 属性测试验证通用性质，而非特定输入。
3. 代理使用Hypothesis框架自动生成测试输入。
4. 在对984份bug报告的人工审查中，56%为有效。
5. 通过评分排名，86%的高分报告为有效。
6. 回顾循环减少误报，例如移除try-catch后才发现bug。
7. 已发现numpy.random.wald返回负数等实际Bug。
8. aws-lambda-powertools中slice_dictionary重复返回第一个分块。
9. 某些报告因语义复杂被标记为预期行为。
10. 代理能有效从函数名、文档等上下文推断应成立的属性。

# TAKEAWAYS:
1. 将LLM与属性测试结合，可高效发现传统测试遗漏的边界情况。
2. 自省循环和评分机制显著降低误报率，提高实用价值。
3. LLM擅长从代码上下文推断高级语义属性，适用于复杂库测试。
4. 自动补丁生成是未来方向，但需完全指定正确性属性。
5. 此方法可用于主动查找漏洞，在部署前预防安全问题。
