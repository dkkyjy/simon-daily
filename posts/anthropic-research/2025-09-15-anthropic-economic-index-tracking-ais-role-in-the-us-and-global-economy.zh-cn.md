夏威夷的旅行规划、马萨诸塞州的科学研究以及印度的网络应用程序开发。表面上看，这三项活动几乎毫无共同之处。但事实证明，它们正是 Claude 在这些地方*最具有代表性*的特定用途。

这并不意味着这些是*最受欢迎*的任务：软件工程在全球几乎所有州和国家中仍然遥遥领先。相反，这意味着马萨诸塞州的人比其他地方的人更有可能向 Claude 寻求科学研究方面的帮助——或者，举例来说，巴西的 Claude 用户似乎对语言特别热衷：他们使用 Claude 进行翻译和语言学习的频率比全球平均水平高出约六倍。

这些是我们第三份 [Anthropic 经济指数报告](http://anthropic.com/research/anthropic-economic-index-september-2025-report) 中发现的统计数据。在这最新一期报告中，我们扩大了记录人工智能采用早期模式的努力，这些模式正开始重塑工作和经济。我们衡量了 Claude 在不同方面的使用差异……

* **…在美国境内：** 我们首次提供了关于人工智能使用如何在美国各州之间差异的详细评估。我们发现，各州的经济构成决定了哪些州人均使用 Claude 最多——而且令人惊讶的是，使用率最高的州*并非*那些编程占主导地位的州。
* **…在不同国家之间：** 我们的新分析发现，各国对 Claude 的使用与收入密切相关，并且使用率较低国家的人们比使用率较高国家的人们*更频繁*地使用 Claude 来自动化工作。
* **…随时间变化：** 我们将最新数据与 [2024年12月至2025年1月](https://www.anthropic.com/news/the-anthropic-economic-index) 和 [2025年2月至3月](https://www.anthropic.com/news/anthropic-economic-index-insights-from-claude-sonnet-3-7) 的数据进行了比较。我们发现，“指令式”自动化任务的比例从27%急剧增加到39%，表明人工智能的职责（以及用户的信任）在迅速增加。
* **…以及商业用户：** 我们现在纳入了来自 Anthropic 第一方 API 客户（除了 [Claude.ai](http://claude.ai/redirect/website.v1.8c7827ec-0b04-4b41-b050-c11405d6492b) 用户之外）的匿名数据，使我们能够首次分析企业的互动。我们发现，API 用户使用 Claude 自动化任务的可能性显著高于消费者，这表明重大的劳动力市场影响可能即将到来。

我们在下方总结了[该报告](http://anthropic.com/research/anthropic-economic-index-september-2025-report)。此外，我们还设计了一个[互动网站](http://anthropic.com/economic-index)，您可以在其中自行探索我们的数据。您首次可以搜索 [Claude.ai](http://claude.ai/redirect/website.v1.8c7827ec-0b04-4b41-b050-c11405d6492b) 在美国各州和我们追踪的所有职业中的使用趋势和结果，了解人工智能在您居住地或与您从事类似工作的人群中是如何被使用的。最后，如果您希望在我们的分析基础上进行构建，我们已将数据集[公开提供](https://huggingface.co/datasets/Anthropic/EconomicIndex)，以及我们之前经济指数报告的数据。

## **地理分布**

我们已扩展 Anthropic 经济指数，纳入了地理数据。下面我们将介绍关于 Claude 在不同国家和美国各州使用情况的发现。

### 不同国家之间

美国使用 Claude 的频率远高于任何其他国家。印度位居第二，其次是巴西、日本和韩国，各自所占份额相近。

按全球 Claude.ai 使用份额计算的主要国家。

然而，这些国家的人口规模差异巨大。为了考虑到这一点，我们根据各国占世界劳动人口的比例调整了其 Claude.ai 的使用份额。这便得到了我们的 **Anthropic 人工智能使用指数**，即 AUI。AUI 大于1的国家，其 Claude 的使用频率高于我们根据其劳动年龄人口所预期的水平，反之亦然。

在我们的 Anthropic 人工智能使用指数上得分最高的二十个国家。

从 AUI 数据中，我们可以看到，一些小型、技术先进的国家（如以色列和新加坡）相对于其劳动年龄人口而言，在 Claude 的采用率方面处于领先地位。这可能在很大程度上可以用收入来解释：我们发现人均 GDP 与 Anthropic 人工智能使用指数之间存在强相关性（人均 GDP 每增加1%，AUI 相应增加约0.7%）。这说得通：最常使用 Claude 的国家通常也拥有强大的互联网连接，以及以知识工作而非制造业为导向的经济。但这确实引发了一个关于经济分化的疑问：以往通用目的技术，如电气化或内燃机，既带来了巨大的经济增长，也导致了世界各地生活水平的[大分化](https://www.aeaweb.org/articles?id=10.1257/jep.11.3.3)。如果人工智能的影响在较富裕国家最为显著，那么这种通用目的技术可能会产生类似的经济影响。

各国人均 Claude 使用量与人均收入呈正相关。（坐标轴采用对数刻度。）

### 美国境内的模式

人均 GDP 与人均 Claude 使用量之间的关联在美国各州之间也同样成立。事实上，在美国境内，使用量随收入的增长比跨国比较更为迅速：美国境内人均 GDP 每增加1%，人口调整后的 Claude 使用量相应增加1.8%。话虽如此，在美国境内，收入对使用量的解释力*低于*跨国比较，因为总体趋势内的方差要大得多。也就是说，除了收入之外，其他因素必定更能解释人口调整后使用量的变化。

还有什么能解释这种采用率差距呢？我们最好的猜测是各州经济构成的差异。美国 AUI 最高的是哥伦比亚特区（3.82），在那里，Claude 最频繁使用的任务包括编辑文档和搜索信息，以及其他与特区知识工作相关的任务。类似地，编码相关任务在加利福尼亚州（AUI 总体排名第三的州）尤为常见，而金融相关任务在纽约州（排名第四）尤为常见。¹ 即使在人口调整后 Claude 使用率较低的州，如夏威夷，其使用也与经济结构密切相关：夏威夷的人们请求 Claude 协助旅游相关任务的频率是美国其他地区的两倍。我们的[互动网站](http://anthropic.com/economic-index) 包含许多其他类似的统计数据。

美国各州相对于其劳动年龄人口的 Claude 采用率。

## **Claude 使用趋势**

自2024年12月以来，我们一直在追踪人们如何使用 Claude。我们使用一种[保护隐私的分类方法](https://www.anthropic.com/research/clio)，将匿名对话记录分类到由 O\*NET（美国政府的职业与任务分类数据库）定义的任务组中。² 通过这样做，我们可以分析自去年以来人们交给 Claude 的任务发生了怎样的变化，以及人们选择的协作方式——即他们选择对 Claude 的工作施加多少监督和输入——也发生了变化。

### 任务

自2024年12月以来，计算机和数学类用途在我们的分类中一直占主导地位，约占对话的37-40%。

但很多情况已经发生了变化。在过去九个月中，我们看到“知识密集型”领域持续增长。例如，教育教学任务增长了超过40%（从所有对话的9%增加到13%），而物理与社会科学相关任务的份额增加了三分之一（从6%增加到8%）。与此同时，传统商业任务的相对频率有所下降：管理相关任务从所有对话的5%下降到3%，商业与金融运营相关任务的份额减半，从6%降至3%。（当然，从绝对数量来看，每个类别中的对话数量仍然显著增长。）

Claude 使用随时间的变化，显示科学和教育任务的增长。

总体趋势存在波动，但总体而言，随着一个国家人均 GDP 的增长，Claude 的使用从计算机和数学职业组的任务*转移*，转向多样化的其他活动，如教育、艺术与设计；办公室与行政支持；以及物理与社会科学。比较下面第一个图表中的趋势线与其余三个图表：

随着我们从低采用率国家转向高采用率国家，Claude 的使用似乎转向更多样化的任务组合，尽管总体模式存在波动。

话虽如此，软件开发仍然是我们追踪的每个国家中最常见的用途。美国的情况类似，尽管我们的样本量限制了我们对采用率变化如何影响任务组合进行更详细的探索。

### 交互模式

正如我们[之前](https://www.anthropic.com/news/the-anthropic-economic-index)讨论过的，我们通常区分涉及*自动化*（人工智能在用户输入最少的情况下直接产出工作）和*增强*（用户与人工智能协作完成任务）的任务。我们进一步将自动化细分为*指令式*和*反馈循环*交互，其中指令式对话涉及最少的人类交互，而在反馈循环任务中，人类将现实世界的结果反馈给模型。我们还将增强细分为*学习*（请求信息或解释）、*任务迭代*（与 Claude 协作）和*验证*（请求反馈）。

自2024年12月以来，我们发现指令式对话的份额急剧上升，从27%增至39%。其他交互模式（特别是学习、任务迭代和反馈循环）的份额因此略有下降。这意味着，自动化（49.1%）首次总体上变得比增强（47%）更为普遍。一个可能的解释是，人工智能正在迅速赢得用户的信任，并越来越多地负责完成复杂的工作。

这可能是模型能力提升的结果。（在2024年12月，当我们首次为经济指数收集数据时，Claude 的最新版本是 Sonnet 3.6。）随着模型在预测用户需求和产出高质量工作方面变得更好，用户可能更愿意在首次尝试时就信任模型的输出。

自动化似乎随着时间的推移而增加。

也许令人惊讶的是，在人均 Claude 使用量较高的国家，Claude 的用途趋向于增强，而使用率较低国家的人们则更倾向于自动化。在控制了所讨论的任务组合后，人均 Claude 使用量每增加1%，与自动化率大约降低3%相关。类似地，人均 Claude 使用量的增加与*远离*自动化（如下表所示）相关，而非趋向自动化。

我们尚不确定这是为什么。这可能是因为每个国家的早期采用者感觉更舒适地让 Claude 自动化任务，也可能归因于其他文化和经济因素。

人均 Claude 使用量较高的国家倾向于以更具协作性的方式使用 Claude。

## **企业**

使用与 [Claude.ai](http://claude.ai/redirect/website.v1.8c7827ec-0b04-4b41-b050-c11405d6492b) 对话相同的[保护隐私的方法论](https://www.anthropic.com/research/clio)，我们已开始对 Anthropic 部分第一方 API 客户的交互进行抽样，这是一项首创的分析。³ API 客户（通常是企业和开发者）使用 Claude 的方式与通过 [Claude.ai](http://claude.ai/redirect/website.v1.8c7827ec-0b04-4b41-b050-c11405d6492b) 访问的用户截然不同：他们按 token 付费，而非固定月费订阅，并且可以通过自己的程序发出请求。

这些客户对 Claude 的使用尤其集中在编码和行政任务上：我们样本中44%的 API 流量映射到计算机或数学任务，而 [Claude.ai](http://claude.ai/redirect/website.v1.8c7827ec-0b04-4b41-b050-c11405d6492b) 上这一比例为36%。（事实上，大约5%的 API 流量专门集中于开发和评估人工智能系统。）这被教育相关职业（API 中占4%，而 [Claude.ai](http://claude.ai/redirect/website.v1.8c7827ec-0b04-4b41-b050-c11405d6492b) 上占12%）以及艺术与娱乐（5%对8%）对话比例的降低所抵消。

我们还发现，我们的 API 客户使用 Claude 进行任务自动化的频率远高于 [Claude.ai](http://claude.ai/redirect/website.v1.8c7827ec-0b04-4b41-b050-c11405d6492b) 用户。我们 API 对话中有77%显示出自动化模式，其中绝大多数是指令式的，而只有12%显示出增强模式。在 [Claude.ai](http://claude.ai/redirect/website.v1.8c7827ec-0b04-4b41-b050-c11405d6492b) 上，比例几乎持平。这可能具有重大的经济意义：过去，任务自动化与大规模经济转型以及重大生产力提升相关联。

在 [Claude.ai](http://claude.ai) 与 API 上使用 Claude 进行增强和自动化的对比。

最后，鉴于 API 使用是按使用量付费的，我们还可以探索任务成本（由它们消耗的 token 数量差异引起）的差异是否会影响企业选择“购买”哪些任务。在此，我们发现价格与使用之间存在*正*相关：成本较高的任务类别往往使用更频繁，如下表所示。这向我们表明，对于企业而言，基础模型能力以及模型产生的经济价值比完成任务本身的成本更为重要。

## **结论**

经济指数旨在提供关于人工智能如何影响人们工作和经济的早期、实证性评估。到目前为止，我们发现了什么？

在我们本报告涵盖的每一项衡量指标中，人工智能的采用似乎都极不均衡。高收入国家的人们更可能使用 Claude，更可能寻求协作而非自动化，并且更可能追求编码之外的广泛用途。在美国境内，人工智能的使用似乎受到当地经济中主导产业的强烈影响，从科技到旅游业。而企业比消费者更倾向于赋予 Claude 代理权和自主权。

除了不均衡这一事实之外，尤其值得注意的是，在过去九个月中，[Claude.ai](http://claude.ai/redirect/website.v1.8c7827ec-0b04-4b41-b050-c11405d6492b) 对话中的指令式自动化已变得更为普遍。人们使用 Claude 的性质显然仍在被定义中：我们仍在集体决定我们对人工智能工具有多大信心，以及我们应该赋予它们多少责任。然而，到目前为止，看起来我们正变得越来越适应人工智能，并愿意让它代表我们工作。我们期待随着时间的推移重新审视这一分析，看看随着人工智能模型的改进，用户的选择会在哪里——或者，实际上，*是否*——稳定下来。
