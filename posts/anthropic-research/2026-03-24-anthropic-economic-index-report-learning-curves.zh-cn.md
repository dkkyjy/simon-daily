Anthropic 经济指数利用我们的隐私保护数据分析[系统](https://www.anthropic.com/research/clio)来追踪 Claude 在整个经济中的使用情况。这是我们努力尽早了解人工智能经济影响的一部分，以便研究人员和政策制定者有充足的时间做好准备。

这份最新报告研究了2026年2月 Claude 的使用情况，建立在我们的[上一份报告](https://www.anthropic.com/research/anthropic-economic-index-january-2026-report)（使用了2025年11月的数据）中引入的经济原语框架之上。我们的样本覆盖了2月5日至2月12日，即 Claude Opus 4.5 发布三个月后，并与 Claude Opus 4.6 的发布同期。

我们首先记录了与之前报告相比使用情况的变化：增强率——即人工智能补充用户能力的协作互动——在 Claude.ai 和 API 流量中均略有上升。在 Claude.ai 中，使用情况多样化，上个月前10项任务占总使用量的份额低于2025年11月。由于这种多样化，Claude.ai 中的平均对话所涉及的任务工资[略低于](https://cdn.sanity.io/files/4zrzovbb/website/f065d6e6f92c65df8244042c83d48872ea308c3a.pdf)之前的报告。

然后，我们聚焦于决定 Claude 对劳动力市场和更广泛经济影响的一个重要因素：Claude 采用中的学习曲线。我们提供的证据表明，长期用户已经形成了能够更好地利用 Claude 能力的习惯和策略。事实上，我们记录到，经验更丰富的用户不仅尝试更高价值的任务，而且在对话中更有可能获得成功的回应。

#### **自我们上次报告以来发生了什么变化**

在第一章中，我们重新审视了2026年1月发布的上一份[经济指数报告](https://www-cdn.anthropic.com/096d94c1a91c6480806d8f24b2344c7e2a4bc666.pdf)中的发现。我们发现：

* **Claude.ai 上的用例多样化。** 编码任务继续从 Claude.ai 中的增强型使用迁移到我们第一方 API 流量中更自动化的工作流程。¹ 在本报告中，Claude.ai 的使用更加分散：2月份前10项任务占总流量的19%，低于11月份的24%。尽管如此，本样本中几乎所有任务都至少出现在我们之前的样本中一次。约49%的工作岗位中，至少有四分之一的任务使用了 Claude 完成。
* **Claude 的采用扩展到低工资任务。** 随着用例的多样化，在 Claude 上完成的工作的平均经济价值——以相关职业的美国工人工资衡量——略有下降。这从机制上看是由于围绕体育、产品比较和家庭维护的个人查询的增加。这种模式符合标准的"采用曲线"故事，即早期采用者偏爱特定的高价值用途（如编码），而后期采用者则承担更广泛的任务。
* **全球使用的不平等持续存在。** 使用仍然高度集中：前20个国家占所有人均使用量的48%，高于45%，凸显了全球采用方面的持续差距。然而，美国境内的人均 Claude 使用量持续趋同：自我们上次报告以来，使用量最高的10个州所占份额从40%下降到38%。

#### 学习曲线

经济指数中的一个核心发现是，Claude 的早期采用非常不均衡：Claude 在高收入国家、美国境内知识工作者更多的地方以及相对较小的一组专业任务和职业中被更密集地使用。

一个重要问题是，采用的不平等将如何决定人工智能的惠益将在何处以及向何人累积。例如，如果有效使用人工智能需要互补的技能和专业知识——正如我们在[上一份报告](https://www-cdn.anthropic.com/096d94c1a91c6480806d8f24b2344c7e2a4bc666.pdf)中所论证的——并且如果这些技能可以通过使用和实验获得，那么早期采用的好处可能是自我强化的。

在第二章中，我们调查了用户如何塑造他们从 Claude 中获得的价值：他们如何将模型能力与手头任务相匹配，以及使用模式和结果如何随着平台上的经验而变化。

* **模型选择与任务相匹配。** 我们表明，用户选择我们最智能的模型类别 Opus 来处理通常在劳动力市场上获得更高工资的任务。例如，在付费的 Claude.ai 用户中，Opus 在编码任务中的使用率比平均水平高4个百分点，在与辅导相关的任务中使用率比平均水平低7个百分点。对于 API 用户而言，这种模型切换的幅度大约是其两倍。
* **使用时间越长，成功率越高。** 总体而言，最有经验的 Claude 用户更频繁地将其用于高等教育任务，而较少用于个人用例。例如，使用 Claude 6个月或更长时间的用户，其个人对话减少了10%，其输入中反映的教育水平提高了6%。最引人注目的是，这一高使用时长群体的对话成功率高出10%，这种关联不能通过他们的任务选择、原籍国或其他因素来解释。虽然这可能反映了早期采用者的成熟度，但也可能是"干中学"的证据，即人们通过经验学会了更好地使用 Claude。

## 自我们上次报告以来发生了什么变化

### Claude.ai 中用例的多样化

我们首先考察 Claude 被要求执行的任务类型。我们使用我们的[隐私保护系统](https://arxiv.org/abs/2412.13678)，该系统允许我们在聚合层面描述行为，而无需透露单个对话记录的内容。我们从 [Claude.ai](https://cdn.sanity.io/files/4zrzovbb/website/f065d6e6f92c65df8244042c83d48872ea308c3a.pdf)（我们的面向消费者的网页产品）和我们的第一方 API（面向开发者的、用于将 Claude 集成到产品和流程中的界面）中分别抽样了100万次对话。²

编码仍然是我们平台上最常见的用途，与计算机和数学职业相关的任务占 Claude.ai 对话的35%（见[附录](https://cdn.sanity.io/files/4zrzovbb/website/a3cdcd9e67c3c4c51440429dd016cacba514b35b.pdf)）。³ 然而，在2025年11月至2026年2月期间，Claude.ai 上的用例变得更加分散：前10个最常见的 O\*NET 任务从对话的24%下降到仅19%（图1.1）。

这种集中度的下降部分反映了编码任务从 Claude.ai 迁移到我们的第一方 API，其中 Claude Code 已占抽样流量的大部分。Claude Code 的代理架构将编码工作拆分为更小的 API 调用，这些调用被标记为不同的任务。因此，虽然编码在 API 总流量中的份额有所增长，但它分布在许多任务类别中，而不是集中在少数几个类别中。结果，尽管编码活动大量涌入，API 中的任务集中度大致保持平稳。

***图1.1：按平台和时间划分的前10项任务的使用份额，Claude.ai 和第一方 API。**按平台和报告版本划分，分配给十个最普遍的 O\*NET 任务的对话份额。*

这种代码从 Claude.ai 的迁移并不是导致集中度下降的唯一因素。部分下降是由于两个时期之间用例组合的变化。课程作业从对话的19%下降到12%，而个人使用从对话的35%上升到42%。课程作业下降的部分原因可以解释为，在我们的样本期间，学生处于寒假的国家/地区的学术日历。⁴ 与此同时，大约从2月份开始增加的注册量带来了更多随意的 AI 用户。

***图1.2：2025年11月和2026年2月 Claude.ai 上的工作、个人和课程作业使用情况。**在 Claude.ai 上被识别为工作、个人或课程作业相关的对话份额。*

虽然 Claude 的工作任务变得更加多样化，但几乎所有任务之前都出现在我们的数据中。在我们之前的报告中，我们注意到49%的工作岗位中，至少有四分之一的任务使用了 Claude 完成。在这次数据提取中，这个累积估计值几乎没有变化（[附录](https://cdn.sanity.io/files/4zrzovbb/website/a3cdcd9e67c3c4c51440429dd016cacba514b35b.pdf)图 A.2）。我们本次报告的数据显示，新颖的 O\*NET 任务比之前的报告少得多。

自我们第一份报告以来，我们将对话分为五种交互类型之一——指令型、反馈循环、任务迭代、验证和学习——我们将它们归为两个更广泛的类别：自动化和增强。⁵ 图1.3显示，Claude.ai 中的增强略有增加。这是由验证和学习模式的轻微上升驱动的。在[附录](https://cdn.sanity.io/files/4zrzovbb/website/a3cdcd9e67c3c4c51440429dd016cacba514b35b.pdf)图 A.3中，我们显示第一方 API 数据中的自动化急剧下降。

***图1.3：协作模式份额，Claude.ai。**Anthropic 经济指数报告中 Claude.ai 的协作模式频率。*

我们的 API 平台继续获得相对较高的计算机和数学任务份额（按工作类别划分的使用份额显示在[附录](https://cdn.sanity.io/files/4zrzovbb/website/a3cdcd9e67c3c4c51440429dd016cacba514b35b.pdf)中）。自2025年8月以来，该类别任务在 API 中的份额增加了14%，在 Claude.ai 中下降了18%。正如我们在关于[劳动力市场影响](https://www.anthropic.com/research/labor-market-impacts)的报告中所指出的，我们预计这种从 Claude.ai 到 API 的迁移可能预示着相关工作岗位的工作将发生更迫在眉睫的转变。Claude.ai 中与管理职业相关的任务增加（从流量的3%增加到5%）来自分析任务（例如，准备投资备忘录）和回答客户问题的混合。

衡量 Claude 上任务组合变化的另一种方法是查看任务平均价值的变化，我们将其定义为执行该任务的美国工人的平均时薪（图1.4）。⁶ Claude.ai 中任务价值的这一估计值从49.3美元略微下降至47.9美元，主要是由于简单事实性问题（例如，体育赛事结果、天气）的增加以及编码向 API 转移而减少。正如我们在[上一份报告](https://www.anthropic.com/research/anthropic-economic-index-january-2026-report)中提到的，我们在 Claude 上看到的任务通常需要更高的教育水平。该图显示，这些任务的工资也往往高于美国全国平均水平。

***图1.4：不同版本和平台间平均任务价值的变化。**该图使用 O\*NET 框架来估算在 Claude.ai 和第一方 API 上执行的任务的美元价值。任务价值估算为执行该任务的工人的平均时薪。*

虽然变化轻微，但上一份报告和当前报告之间几个原语的变化反映了 Claude.ai 上任务复杂性的类似下降。人类输入所需的平均受教育年限从12.2年下降到11.9年，用户授予了 AI 更多自主权，人类单独完成任务所需的时间减少了约2分钟。一个变化表面上朝着相反的方向：Claude 执行的任务被认为在没有 AI 的情况下人类完成的难度略低。

### 新兴的自动化模式

随着任务迁移到 API，它们可能更容易受到自动化的影响。API 工作流程更可能是指令型的，对人机协同的需求更少。在[上一份报告](https://cdn.sanity.io/files/4zrzovbb/website/a42bc3fc08283562f08fd8bdee8f6f9a3d506e87.pdf)中，我们强调了客户服务任务，包括例如针对支付和账单问题的自动化支持，在 API 数据中很普遍。这些导致了客户服务代表观察到更高的暴露度——Claude 被记录在自动化工作流程中执行了他们很大一部分任务，因此随着 AI 的扩散，这些工作可能更有可能发生变化。

我们重点介绍两个在2月份比三个月前出现频率更高的 API 工作流程，它们在我们最新样本中的份额至少翻了一番：⁷

* **业务销售与外展自动化：** 销售赋能生成、B2B 潜在客户资格研究、客户数据丰富、冷邮件起草。
* **自动化交易与市场运营：** 监控市场或头寸、提出具体投资建议、告知交易者市场状况及相关任务。

### 重新审视地理趋同

在我们之前的报告中，我们注意到 Anthropic AI 使用指数（AUI）——根据地理区域的劳动年龄人口进行调整——在美国各州之间迅速趋同：最初人均使用量较低的州显示出更快的采用速度。

图1.6的左面板显示，这种趋同在我们最新的数据中仍在继续，但速度较慢。从2025年8月到2026年2月，前五个州的人均使用量份额从30%下降到24%。自2025年8月以来，基尼系数有所下降，尽管趋同速度已经放缓。当我们更新[上一份报告](https://www-cdn.anthropic.com/096d94c1a91c6480806d8f24b2344c7e2a4bc666.pdf)中的估计值时，我们发现按照这个速度，各州将在5-9年内达到大致相等的人均使用量，而不是2-5年。⁸

## 学习使用 AI

在本章中，我们关注反映人们如何部署和学习使用 AI 的两个使用特征：模型选择和长期用户的习惯。

首先，我们通过研究人们何时选择我们性能最佳的模型类别 Opus，来揭示对智能的需求。关于 AI 用户如何在不同的模型之间进行选择、权衡速度、性能和成本，我们知之甚少。如果用户正在根据手头任务进行调整，我们应该会看到 Opus 集中在更困难、更高价值的工作上。

接下来，我们研究使用情况如何根据使用时长而有所不同，发现在不同时间注册的用户之间存在差异。这揭示了学习曲线：有经验的用户会随着时间的推移变得更好吗？他们的使用方式有何不同？我们发现了与"干中学"一致的证据。高使用时长用户不仅在对话中取得了更大的成功，他们还更多地与 Claude 协作，将更具挑战性的任务带给 Claude，并且更有可能将 Claude 用于工作目的以及更广泛的任务。

### 模型选择

不同的 Claude 模型类别（Haiku、Sonnet 和 Opus）在成本、速度和性能方面提供了权衡。Opus 类别的模型使用最多的 token，擅长处理复杂任务，但在我们的 API 上每个 token 的价格更高。如果用户意识到这一点并注意成本和用量限制，他们应该将他们最复杂和最有价值的任务交给 Opus，同时为更简单的任务选择其他模型。这大致就是我们在数据中观察到的情况。

下面的图2.1显示，对于可以访问所有模型类别的付费 Claude.ai 账户，55%的计算机和数学任务（如编写软件代码）使用 Opus，而教育任务中这一比例为45%。技术用户可能会注意到性能提升并主动切换掉默认的 Sonnet。或者，注重效率的用户可能会学会对更简单的任务使用 Sonnet，以避免达到用量限制。与此相关，这里的差异可能反映了大多数教育任务对 Sonnet 来说已经相当容易，或者学生更可能注意用量限制。

***图2.1：模型选择与职业领域。**该图显示了付费 Claude.ai 用户根据任务所在的职业领域，选择 Opus 类别模型的频率差异。在本样本中，总体使用量的51%是 Opus，而计算机和数学任务中为55%（+4.4个百分点）。*

下面的图2.2以更细粒度的方式显示了这一点。当用户执行与高薪*工作*相关的任务时，他们更频繁地使用 Opus。例如，在 Claude.ai 上，34%的软件开发人员任务涉及 Opus，而辅导任务中只有12%。总体而言，对于任务的每增加10美元时薪，Claude.ai 用户使用 Opus 的对话份额增加1.5个百分点。第一方 API 流量对任务复杂性的反应要大得多。其斜率大约是前者的两倍，任务价值每增加10美元，Opus 份额增加2.8个百分点。部署程序化工作流程的用户可能比网页用户更有理由在模型之间切换。

***图2.2：模型选择与职业。**该图显示了用户根据任务关联的职业选择 Opus 类别模型的频率。每个点代表一个职业（x轴）及其 Opus 份额（y轴）。左面板显示 Claude.ai 用户，右面板显示第一方 API 用户。*

### 学习曲线

第一个 Claude 模型于2023年3月发布。从那时起，Claude.ai 和 API 上的用户群迅速增长。我们最新的样本包含各种用户，有些是在第一个 Claude 版本发布时就注册的，有些则是在我们测量他们使用情况的前一天才注册的。一个人使用 Claude 的时长如何影响他们与它的互动体验？⁹

表2.1显示了低使用时长用户和高使用时长用户之间的差异，其中后一组定义为至少在6个月前注册 Claude 的用户，而低使用时长用户则是其他所有人。¹⁰ 高使用时长用户更有可能使用 Claude 来迭代他们的工作，并且通过指令型使用模式委派更大责任的可能性要小得多。他们使用 Claude 工作的可能性高出7个百分点，并且使用 Claude 执行往往需要更高教育水平的任务。最后，他们的使用在某些任务上不那么集中。对于高使用时长组，前10个 O\*NET 任务占使用量的份额略低（20.7%对比22.2%）。

有几个因素可以解释这种在快速发展的通用技术用户群中出现的模式。高使用时长用户是自我选择的，这里的差异可能反映了稳定的特征。例如，他们可能是计算机程序员，更可能是早期采用者。此外，存在固有的幸存者偏差：在我们的数据提取前一年注册的用户可能从他们的使用中看到了积极的结果。我们没有观察到一年前注册但不再使用 Claude 的用户。

这些发现反映了我们在经济原语报告中看到的情况：收入较低、教育程度较低的国家在某些情况下反而显示出更复杂的使用。最早的采用者通常有高价值的技术用例。在采用率低得多的较贫穷国家，这些早期采用者仍然主导着用户群。

当 AI 扩散到更广泛的人口比例时，更随意的使用就会出现。事实上，在请求集群中，平均使用时长最高的任务包括：AI 研究、git 操作、修改手稿和初创公司融资。平均使用时长最低的任务具有更简单的工作流程，如写俳句、查看体育比分和推荐派对食物。¹¹

#### 经验效应

我们在下面的图2.4中进一步探讨了这些关系，使用日志级别数据来精细控制对话的特征。在顶部面板中，规范（1）显示了一个简单的双变量回归，以任务成功作为结果变量，以长期使用时长指标作为预测变量。成功是 Claude 对对话是否成功的评估，[在我们之前的报告中描述过](https://www-cdn.anthropic.com/096d94c1a91c6480806d8f24b2344c7e2a4bc666.pdf)。该图显示，长期使用时长用户获得成功对话的可能性高出约5个百分点。

这可能反映了高使用时长用户更善于提示。但如果这反映的是他们带给 Claude 不同的任务——那些更可能成功的任务呢？

在规范（2）中，我们加入了特定 O\*NET 任务和请求集群的固定效应。这相当于在相同狭义定义的任务内比较高使用时长和低使用时长用户，而不是跨任务比较。例如，我们有一个名为"为特定公司执行企业财务分析、估值和建模"的请求集群。固定效应比较该集群内的高使用时长和低使用时长用户，同样在每个其他集群内也是如此。只有当平均而言，长期使用时长用户在这些任务内比较中更成功时，我们才会观察到正的系数。这种控制在一定程度上缓和了效应，使其接近3个百分点。

***图2.4：经验与成功之间的关联。**该图显示了将我们的二元成功度量指标对高使用时长指标进行回归的结果，并加入了越来越严格的控件。系数以百分点给出，须状线给出95%置信区间。"任务固定效应"表示 O\*NET 任务和请求集群的固定效应。完整控件增加了模型、用例和国家固定效应。*

最后，我们询问这种关系是否受到高使用时长用户选择不同模型、使用不同语言交流、拥有不同用例或在不同国家注册的影响。该回归产生了略高的高使用时长影响，表明在完全控制下，成功率高出4个百分点。

这些结果表明，高使用时长用户在他们的 Claude 对话中取得了更大的成功，并且这不是由于语言或正在执行的任务等简单因素造成的。一个有趣的可能解释是，这些用户更好地学会了如何从 AI 中提取他们想要的东西。对这些平台的熟练程度可能是成功的关键决定因素，并且似乎随着经验而增长。

## 讨论

本报告重新审视了我们用于追踪 Claude 使用情况的核心指标，并首次分析了模型选择和成功率。自2025年8月以来，第一方 API 的使用变得更加集中，前10个 O\*NET 任务现在占流量的33%，高于28%。另一方面，自2025年11月的数据以来，Claude.ai 的任务已经多样化。低使用率州之间的更快采用在美国继续，尽管速度比上一份报告慢。低采用率国家则略微落后。

通过这份报告，我们可以开始描绘各种经济原语是如何变化的。课程作业作为使用份额的一部分下降了，而个人对话增加了。我们还注意到 Claude.ai 中提示的总体复杂性略有下降，Claude.ai 中的对话显示出不太复杂的输入和更短的估计完成时间。

总体而言，Claude 被用于高价值、复杂的工作，这些工作并不广泛代表美国经济。但随着用户群的增长，报酬较低的任务在流量中的份额略有增加。任务的平均价值——以与这些任务相关的职业中工人的估计工资衡量——自我们第一份报告以来在 Claude.ai 上有所下降，而在 API 用户中则有所上升。在这两个界面上，用户将他们最复杂的任务带给我们更强大的模型类别 Opus。这种转变在 API 客户中更为强烈。

经验更丰富的用户倾向于以更具协作性的方式、出于更多与工作相关的原因、在更复杂的任务中使用 Claude，并且取得了更大的成功。这反驳了我们去年提出的一个假设，即自动化使用可能更典型于经验丰富、成熟的用户；相反，我们发现最先进的用户更有可能与 Claude 进行迭代。这也与"干中学"一致：一个人花在使用 AI 上的时间越多，他就越能有效地利用它。

当然，另一种解释是，这些结果是由队列效应或幸存者偏差驱动的。早期采用者可能更具技术性。继续使用 Claude 的人可能是那些拥有 Claude 特别擅长处理的任务的人。但是，经过仔细控制的回归排除了这种混杂因素的简单版本，例如长期使用时长用户带来了不同类型的任务。随着时间的推移，我们将能够更清晰地将队列效应和幸存者偏差与"干中学"区分开来。

这些观察到的成功率差异可能会加剧劳动力市场的不平等。经济学家长期以来一直注意到[技能偏向型技术变革](https://www.aeaweb.org/articles?id=10.1257/0022051026976)的潜力：创新提高了高技能工人的工资，同时压低了其他人的工资。我们在本报告中的分析确定了一个渠道，通过这个渠道，这种技能偏向型转型可能已经在展开：拥有高技能任务的早期采用者与 Claude 的互动比后来的、技术性较弱的采用者更成功。这些早期采用用户可能同时是[最暴露](https://www.anthropic.com/research/labor-market-impacts)于 AI 驱动的颠覆性影响，并且在这些初始的、增强性的采用浪潮中受到 AI 帮助最大的群体。
